# 29 面试问答（深度版）

> 本文目标：每道题给出"加分答法"——不仅回答是什么，还带源码位置与机制推导，展示"系统读过源码"。

## 1. 概念题（深度版）

### Q1：TileLang 是什么？
**加分答法**：基于 TVM TIRX 的 tile 级 GPU 语言，用 eager builder 把 Python DSL 翻译成 IR，经 ~40 个自研 pass（布局推断/软件流水线/lower_tile_op）生成接近手写 CUDA 的 kernel。与 Triton 最大区别：IR 栈（TVM vs MLIR）与 pass 可定制性。

### Q2：和 TVM 什么关系？
**加分答法**：复用 TVM 的 IR、Pass 框架（CreatePrimFuncPass）、tvm_ffi；自研 DSL、tileop、pass、CUDA codegen。是"站在 TVM 肩膀上做 tile 优化"。

### Q3：和 Triton 区别？
**加分答法**：见 `18`。布局系统本质不同（TileLang 显式表达式 vs Triton GF(2) 矩阵）。

## 2. 原理题（深度版）

### Q4：JIT 编译链？
**加分答法**：`kernel(a,b)` → JITKernel.__call__ → adapter.func → KernelCache.cached(key) → miss → lower() → CUDAPassPipelineBody → device_codegen → target.build.tilelang_cuda → tilelang_callback_cuda_compile(nvcc) → .so。缓存键含 IR脚本+args+target+configs+版本+lib指纹。

### Q5：Pass 流水线？
**加分答法**：CUDAPassPipelineBody（cuda/pipeline.py:145）执行 12+ pass。以 InjectSoftwarePipeline 为例：多缓冲（shape 前插 num_stages）、三段式（prologue/body/epilogue）、cp.async commit/wait（ptx_commit_group/wait_group），稳态 wait = num_stages-1。

### Q6：布局推断？
**加分答法**：Layout = input_size + forward_index。Fragment 加 forward_thread。推断流程：漂浮→FullyReplicated → kStrict → kCommon BFS → kFree 最小寄存器搜索（Union-Find）。冲突报 "Get different layout"。

### Q7：m16n8k16 fragment？
**加分答法**：C 每线程 4 元素（16×8/32），映射公式 `row=8*(local%4//2)+thread//4, col=8*(local//4)+(thread%4)*2+local%2`。A 每线程 8 元素。与 PTX mma 寄存器布局一致。

## 3. 实践题（深度版）

### Q8：如何调优 GEMM？
**加分答法**：do_bench 测速 → Roofline 判断瓶颈 → autotune 搜 block/threads/stages → get_kernel_source 检查 mma/cp.async/__syncthreads → 与 cuBLAS 对比。

### Q9：编译失败排查？
**加分答法**：dump IR 定位 pass → 读 Layout(...)/Fragment(...) 错误文本 → 检查 fragment 是否都参与 tileop。典型错误 "can not be inferred correctly" 来自 layout_inference.cc:422。

### Q10：性能比 cuBLAS 慢？
**加分答法**：查 5 信号（mma/cp.async/向量化/syncthreads/launch_bounds），无 mma 说明没走 tensor core，无 cp.async 说明流水线没生效。

## 4. 深挖题（深度版）

### Q11：为什么 fragment layout 对 gemm 关键？
**加分答法**：mma 指令要求 A/B/C 元素按固定模式分布在 32 线程寄存器。layout 编码该分布。错误 layout → 数据错位或无法生成 mma。布局推断用 Forward/Inverse 保证一致。

### Q12：给 TileLang 加算子怎么做？
**加分答法**：4 处：Python 原语 + tileop 语义 + C++ `TIR_REGISTER_TL_TILE_OP` + LowerTileOp 处理 + codegen。

### Q13：缓存为何失效？
**加分答法**：KernelCache 键含 IR 脚本哈希、示例 args repr、target、backend、pass_configs、版本、可选 libtilelang.so 指纹。改 C++ 需要 lib 指纹参与（env.should_use_kernel_cache_lib_stamp）。

### Q14：swizzle 如何工作？
**加分答法**：128B 用 xor8x8(c,s)，8 行同列访问分散到 8 个 bank。手算验证（见 `19` 表格）。

## 5. 场景题

### Q15：RTX 4090 写 fp16 GEMM 思路？
**加分答法**：2D block 网格 + shared A/B + fragment C + T.Pipelined(stages≥2) + T.gemm（自动选 mma.sync for SM89）+ 写回。autotune 优化。

### Q16：如何验证正确性？
**加分答法**：torch/cuBLAS 参考 + assert_close + 小 shape + profiler.assert_allclose。
