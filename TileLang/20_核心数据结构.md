## 1. Layout 的数学定义

### 1.1 数据结构（已确认，`src/layout/layout.h:46-139`）
```cpp
class LayoutNode {
  Array<PrimExpr> forward_index_;  // 逻辑坐标 → 物理坐标 的表达式
  Array<PrimExpr> input_size_;     // 逻辑坐标各维范围
};
```

**核心概念**：Layout 是"逻辑坐标 → 物理坐标"的**多输出函数**。
- `forward`（`layout.cc:591-619`）：把占位符 `_i0, _i1...` 代入实参求值。
- `inverse`（`layout.cc:961-964`）：经 `DetectIterMap` + `InverseAffineIterMap` 构造反向 Layout（要求双射）。

### 1.2 例：2D 行主序 layout
`MakeLinearLayout`（`gemm_layouts.cc:582-598`）：
```cpp
PrimExpr linear_index = 0;
for (int i = 0; i < ndim; i++) {
  PrimExpr stride = 1;
  for (int j = i+1; j < ndim; j++) stride = stride * shape[j];
  linear_index = linear_index + iter_vars[i]->var * stride;
}
return Layout(iter_vars, {linear_index});
```
即 `Layout([16,16], lambda i,j: i*16 + j)`。

## 2. Fragment 的数学定义（深度）

### 2.1 数据结构（`layout.h:155-216`）
```cpp
class FragmentNode {
  Range thread_range_;        // 线程范围 [0, thread_extent)
  PrimExpr forward_thread_;   // 逻辑坐标 → 线程号
  PrimExpr replicate_size_;   // 复制维大小
};
```

### 2.2 核心设计（`layout.cc:966-999`）
如果 `forward_index` 为空，就**从 `forward_thread_` 反解出线程内局部下标**：
```cpp
Array<arith::IterSplitExpr> splits =
    DivideUnusedIterators({forward_thread}, iter_vars, analyzer);
return MakeFlattenedExpression(splits);
```
即"每个元素 = 线程号 + 线程内局部下标"是可逆分解。

## 4. LayoutInference 完整算法（深度）

`BufferUseDefCollector::Run`（`layout_inference.cc:316-464`）：

```
step0: 漂浮 fragment（不在任何 tileop 内访问的）→ FullyReplicated（:352-362）
step1: 每个 op 跑 kStrict 推断（:365）
step2: BFS 队列 kCommon 推断（:374）
step3: InferInFreeMode 放宽到 kFree（:378）
step4: 别名传播 + Reshape（:382-419）
最后: 检查所有 fragment 有布局（:422-429）
```

### InferLevel（`src/op/operator.h:85-89`）
```cpp
enum class InferLevel { kFree=0, kCommon=1, kStrict=2 };
```

### kFree 最小寄存器搜索（`layout_inference.cc:1012-1167`）
- Union-Find 把共享 fragment 的 op 连成连通分量。
- 每个成员 op 作根尝试推断。
- 计算所有 fragment 的 `OutputShape()` 乘积（寄存器数），选最小。

## 5. Swizzle 数学（深度）

### 三级 XOR swizzle（`gemm_layouts.cc:442-528`）
- 128B：`xor8x8`（3 bit）
- 64B：`xor4x4`（2 bit）
- 32B：`xor2x2`（1 bit）

### 选择逻辑（`MakeGemmABLayout` :823-847）
```cpp
if (mat_continuous % (vector_size * 8) == 0) return MakeFullBankSwizzleLayout2D(...);   // 128B
else if (... % (vector_size * 4) == 0) return MakeHalfBankSwizzleLayout2D(...);          // 64B
else if (... % (vector_size * 2) == 0) return MakeQuarterBankSwizzleLayout2D(...);       // 32B
else return MakeGemmABLayoutPadded(...);
```

## 6. CuTe layout 关系（深度）

`src/layout/cute_layout.*` 是独立 CuTe 风格 IR（`cute::Layout{shape, stride}`，列主序）：
- `LayoutFromTileLang`（cute_layout.cc:1892）：恢复 affine layout。
- `ComposedLayoutFromTileLang`（:1977）：恢复 Swizzle∘offset∘Layout，供 TMA。
- `Sw<b,m,s>`（`cute_layout.h:33-96`）：`apply(x) = x ^ ((x & yyy_mask) >> s_shift)`。

**128B/64B/32B ↔ Sw<3,4,3>/Sw<2,4,3>/Sw<1,4,3>**（cute_layout.h:70-73）。
