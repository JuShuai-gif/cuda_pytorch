## 3. 任务二：C++ pass（完整模板，深度）

`src/transform/` 下新建 `my_pass.cc`：
```cpp
#include <tvm/ir/transform.h>
#include <tvm/tir/transform.h>
// 头文件以 layout_inference.cc 实际包含为准

namespace tvm {
namespace tirx {
namespace transform {

tvm::transform::Pass MyPass() {
  auto pass_func = [=](PrimFunc f, const IRModule &m, const PassContext &ctx) {
    std::cerr << "[MyPass] func: " << f->GlobalVar() << "\n";
    return f;
  };
  return CreatePrimFuncPass(pass_func, 0, "tl.MyPass", {});
}

TVM_FFI_STATIC_INIT_BLOCK("tl.transform") {
  refl::GlobalDef().def("tl.transform.MyPass", MyPass);
}

}  // namespace transform
}  // namespace tirx
}  // namespace tvm
```

**关键点（深度）**：
1. 命名空间：`tvm::tirx::transform`（TileLang 自己的，不是 `tvm::tir::transform`）。
2. `CreatePrimFuncPass(func, opt_level, name, required_passes)`。
3. `TVM_FFI_STATIC_INIT_BLOCK("tl.transform")` 与 Python 的 `init_ffi_api("tl.transform", ...)` 对应。
4. `src/transform/*.cc` 被 CMake `file(GLOB)` 收集 → **无需改 CMakeLists**。

验证：
```bash
pip install -e . --no-build-isolation
python -c "
from tilelang.transform import _ffi_api
mod2 = _ffi_api.MyPass()(mod)   # 应打印 [MyPass]
"
```

## 4. 任务三：新算子（深度）

新算子需要 4 处配合：

3. **C++ 算子**：`src/op/my_op.cc` `TIR_REGISTER_TL_TILE_OP`。
4. **降级**：`src/transform/lower_tile_op.cc` 的 `ParseOperator` 处理 + codegen。

## 6. 常见坑

1. 命名空间错（`tir` vs `tirx`）。
2. FFI 注册名与 Python 不对应。
3. pass 必须返回新 IRModule（不可变）。
4. 断言不要带副作用（C++ 风格）。
