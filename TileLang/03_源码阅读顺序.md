## 2. 路线一：从前端追底层（端到端编译链）

### 阶段 1.1：DSL 层（tilelang/language/）
- 读：`kernel.py`（T.Kernel）、`loop.py`（T.Parallel/Pipelined/serial）、`copy_op.py`、`gemm_op.py`、`allocate.py`。
- 验证：写一个最小 vector add，`get_kernel_source()` 看生成代码。
- 里程碑：能解释 `T.Parallel` 如何变成循环。

### 阶段 1.2：eager builder（tilelang/language/eager/）
- 读：`builder.py` 如何维护 `current_ir`，`ast/ir.py` 定义哪些节点。
- 验证：`TL_ENABLE_DUMP_IR=1` 看 `T.Kernel` 生成的初始 IR。
- 里程碑：理解"Python 语句 → IR 语句"的映射。

### 阶段 1.3：lower 主流程（tilelang/engine/）
- 读：`lower.py` 的 `lower`(:297) `lower_to_host_device_ir`(:259) `device_codegen`(:249)。
- 验证：断点或打印，看调用顺序。
- 里程碑：能说出 host/device IR 分离的时机。

### 阶段 1.4：pass 流水线（tilelang/cuda/pipeline.py + src/transform/）
- 读：`pipeline.py:145` 的 pass 序列，逐个 pass 去 `src/transform/` 找实现。
- 验证：`TL_ENABLE_DUMP_IR` 对比相邻 pass 输出。
- 里程碑：能列出 12+ 个 pass 并说出各自作用（见 `08` 深度版表格）。

### 阶段 1.5：codegen（src/cuda/codegen/）
- 读：`codegen_cuda.cc` 的 `VisitStmt_(ForNode)`(749) `VisitStmt_(BufferStoreNode)`(5287) `Finish()`(640)。
- 验证：`get_kernel_source()` 对照 IR 反查。
- 里程碑：能读懂生成 CUDA 的每个结构。

### 阶段 1.6：nvcc 编译与缓存（tilelang/engine/lower.py:101 + tilelang/cache/）
- 读：`tilelang_callback_cuda_compile`、`KernelCache._generate_key`(kernel_cache.py:241)。
- 验证：清缓存重编译，观察耗时差异。
- 里程碑：能解释缓存键的每个组成。

## 3. 路线二：从示例追底层（最快上手）

```
examples/gemm/example_gemm.py
  → T.gemm → tileop/gemm/gemm_base.py (gemm_mma.py:111 _gemm_ssr)
  → tl.tileop.gemm → src/op/gemm.cc:262
  → GemmNode::Lower → tl.gemm.lower (tileop/gemm/__init__.py:18)
  → registry.py resolve_gemm_impl → GemmMMA.lower()
  → codegen_cuda.cc → tl::mma_sync<> → CUTE PTX
```

阶段任务：
1. 跑通 `example_gemm.py`，改 `block_M/N/K`/`threads`/`stages` 观察性能。
2. 读 `gemm_mma.py` 的 `_gemm_ssr`（K 内循环 + ldmatrix + mma）。
3. 读 `mma_macro_generator.py` 的 `mma_atom`（:587）。
4. `get_kernel_source()` 看 `mma.sync` / `ldmatrix.sync`。
5. 用 `@autotune` 找最优参数。

## 6. 阅读原则（深度版）

1. **以 08 的 pass 表为骨架**：每条路线最终都落到 pass 上。
2. **以 dump_ir 为验证工具**：改任何东西都 dump 看差异。
3. **以测试为真相**：`testing/python/transform/test_tilelang_transform_*.py` 记录了 pass 的精确行为（如 pipeline 的 stage 数组 `[0,0,2]`），比注释可信。
4. **C++ 命名空间注意**：TileLang 的 pass 在 `tvm::tirx::transform`，与 TVM 的 `tvm::tir::transform` 不同。
