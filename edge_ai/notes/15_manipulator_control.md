# 机械臂实时控制性能优化

## 1. 机械臂运动学基础

### 1.1 正运动学：从关节角到末端位姿

机械臂的正运动学（Forward Kinematics, FK）解决"已知各关节角度，求末端执行器在基座坐标系下的位姿"的问题。标准做法是使用 **Denavit-Hartenberg (DH) 参数**。

每个关节 i 由 4 个 DH 参数定义：

| 参数 | 含义 | 类型 |
|------|------|------|
| a_i | 连杆长度（沿 x_i 方向） | 常量 |
| α_i | 连杆扭转角（绕 x_i 旋转） | 常量 |
| d_i | 关节偏移（沿 z_{i-1} 方向） | 旋转关节为常量 |
| θ_i | 关节角度（绕 z_{i-1} 旋转） | 变量 |

相邻关节的齐次变换矩阵为：

```
T_i = Rot(z, θ_i) · Trans(0,0,d_i) · Trans(a_i,0,0) · Rot(x, α_i)
```

展开为 4×4 矩阵：
```
T_i = [ cosθ_i  -sinθ_i·cosα_i   sinθ_i·sinα_i   a_i·cosθ_i ]
      [ sinθ_i   cosθ_i·cosα_i  -cosθ_i·sinα_i   a_i·sinθ_i ]
      [ 0        sinα_i           cosα_i           d_i        ]
      [ 0        0                0                1          ]
```

末端位姿：**T_0_N = T_1 · T_2 · ... · T_N**

**实时性能考量**：对于 N 关节机械臂，正运动学需要 N 次 4×4 矩阵乘法。在 1kHz 控制周期中，这部分开销通常在微秒级，不是瓶颈。

### 1.2 KUKA iiwa 7 轴示例（简化 DH）

| 关节 | a(m) | α(rad) | d(m) | θ |
|------|------|--------|------|---|
| 1 | 0 | -π/2 | 0.36 | θ₁ |
| 2 | 0 | π/2 | 0 | θ₂ |
| 3 | 0 | π/2 | 0.42 | θ₃ |
| 4 | 0 | -π/2 | 0 | θ₄ |
| 5 | 0 | -π/2 | 0.40 | θ₅ |
| 6 | 0 | π/2 | 0 | θ₆ |
| 7 | 0 | 0 | 0.126 | θ₇ |

7 轴机械臂具有运动学冗余（末端 6-DOF 位姿由 7 个关节决定），这意味着同一个末端位姿对应无穷多组关节角。这种冗余允许避障、避奇异、优化力矩等次目标任务。

## 2. 数值逆运动学

### 2.1 解析 IK vs 数值 IK

| 特性 | 解析 IK | 数值 IK |
|------|---------|---------|
| 求解速度 | O(1)，极快（<1μs） | O(n²)∼O(n³)，迭代收敛 |
| 通用性 | 仅适用于满足 Pieper 准则的构型 | 适用于任意构型 |
| 实现难度 | 需要几何推导，每种臂不同 | 统一框架，换 DH 即可 |
| 冗余处理 | 困难 | 自然支持零空间优化 |
| 实时性 | 完全确定 | 需保证迭代次数上限 |

大多数工业机械臂（6-DOF）满足 Pieper 准则（后三轴交于一点），可以使用解析 IK。但 7-DOF 冗余臂、人形机器人等必须使用数值 IK。

**数值 IK 的核心思想**：将 IK 转化为优化问题——最小化当前末端位姿与目标位姿之间的误差，使用梯度下降类方法迭代求解。

### 2.2 Newton-Raphson 方法

基于雅可比矩阵的伪逆：

```
Δθ = J⁺(θ_k) · e(θ_k)
θ_{k+1} = θ_k + Δθ
```

其中 e(θ) = [Δp; Δω] 是位姿误差（6×1），J(θ) 是 6×N 几何雅可比矩阵，J⁺ 是 J 的伪逆。

**伪逆计算**：对于 N>6 的冗余臂，J 是"胖矩阵"（行满秩时 rank=6），伪逆 J⁺ = Jᵀ(J Jᵀ)⁻¹。

**NR 的问题**：在奇异点附近，J 的行秩下降，J Jᵀ 接近奇异，伪逆产生巨大的关节速度跳变，导致不安全的运动。

### 2.3 Damped Least Squares (DLS)

引入阻尼因子 λ 来抑制奇异点附近的关节速度：

```
Δθ = Jᵀ (J Jᵀ + λ²I)⁻¹ e
```

等价于最小化 ||JΔθ - e||² + λ²||Δθ||²——在跟踪精度与关节速度之间做权衡。

**λ 的自适应策略**：
- 远离奇异点（σ_min 大）：λ 取小值（如 0.01），优先跟踪精度
- 接近奇异点（σ_min 小）：λ 增大（如 1.0），优先稳定性
- 典型实现：λ² = λ₀² · (1 - σ_min/σ_threshold)²，当 σ_min < σ_threshold 时启动

**SVD 形式的 DLS**：
```
J = U Σ Vᵀ
Δθ = V · diag(σᵢ/(σᵢ²+λ²)) · Uᵀ · e
```
每个奇异值 σᵢ 被"阻尼"为 σᵢ/(σᵢ²+λ²)，最大值为 1/(2λ)（当 σᵢ=λ 时）。

### 2.4 雅可比转置方法

最简化的方法：Δθ = α · Jᵀ · e（α 为步长标量）。不需要矩阵求逆，计算量极小，但收敛速度慢，仅适用于粗定位或实时性要求极高但精度要求不高（如视觉伺服）的场景。

### 2.5 收敛性分析

典型 7 轴机械臂的 IK 收敛：
- 一般位姿：3～5 次迭代收敛到 0.1mm/0.1° 精度
- 接近奇异点：8～15 次迭代
- 远离可达空间（不可达目标）：不会发散但会收敛到最近可达位姿（DLS 的优良特性）

每步迭代需计算 FK + Jacobian + SVD/Cholesky，7-DOF 约 30～50μs（优化后的 C++ 实现）。在 0.3ms 内完成 6 次迭代是可行的。

## 3. 轨迹规划

### 3.1 关节空间 vs 笛卡尔空间规划

| 维度 | 关节空间规划 | 笛卡尔空间规划 |
|------|-------------|----------------|
| 计算量 | 低（不需要 IK） | 高（每个插补点需 IK） |
| 路径形状 | 关节线性，末端弧形 | 末端直线/圆弧 |
| 奇异性 | 天然避免关节奇异 | 路径可能经过奇异点 |
| 碰撞检测 | 困难 | 直观 |
| 实时场景 | 点到点运动（PTP） | 连续路径（焊接、涂胶） |

### 3.2 梯形速度曲线（Trapezoidal Profile）

三段式：**加速段 → 匀速段 → 减速段**。

给定位移 D、最大速度 V_max、最大加速度 A_max：

```
判断是否能达到 V_max：
  D_min = V_max² / A_max  （刚好达到 V_max 即减速的最小位移）
  若 D ≥ D_min：三段式（加速→匀速→减速）
  若 D < D_min：三角波形（无匀速段），V_peak = √(D·A_max)
```

**优缺点**：实现简单，计算量极小。但加速度不连续（在段切换处跳变），导致 jerk 无限大，引起机械振动。

### 3.3 S 曲线（Jerk-Limited Profile）

七段式：**加加速度→匀加速→减加速度→匀速→加减速→匀减速→减减速**。

限制 jerk（加加速度）值 J_max，使加速度连续变化：

```
段 1 (T₁): jerk = +J_max, 加速度从 0 → A_max
段 2 (T₂): jerk = 0,      加速度保持 A_max
段 3 (T₃): jerk = -J_max, 加速度从 A_max → 0
段 4 (T₄): jerk = 0,      速度保持 V_max
段 5 (T₅): jerk = -J_max, 加速度从 0 → -A_max
段 6 (T₆): jerk = 0,      加速度保持 -A_max
段 7 (T₇): jerk = +J_max, 加速度从 -A_max → 0
```

**S 曲线的代价**：比梯形多 4 个时间段判断，计算略复杂。但振动减少 60%～80%，对高速高精度应用是必需的。

### 3.4 在线插补的实时约束

在 1kHz 控制周期中，每个周期需要：
1. 根据当前时间 t 计算轨迹上的目标位置/速度/加速度
2. 将目标位置送入 IK 求解器得到目标关节角
3. 将目标关节角送入 PID 控制器

所有计算必须在 **1ms 内完成**。实际时间预算：
- 轨迹插补：<5μs（查表或解析公式）
- IK：<300μs（6 次 DLS 迭代）
- PID ×7：<10μs
- 余量：~685μs 用于通信、状态更新、安全检测

### 3.5 多点样条插值

通过 N 个路径点（via-points）的平滑插值通常使用三次样条。给定路径点位置 p_k 和对应时间 t_k：

```
s_k(t) = a_k + b_k·τ + c_k·τ² + d_k·τ³
其中 τ = t - t_k,  τ ∈ [0, Δt_k]
```

边界条件：位置连续 + 速度连续 + 起止速度已知。解三对角线性方程组（O(N)），预计算系数，实时采样 O(1)。

## 4. 实时关节控制闭环

### 4.1 1kHz 控制回路结构

```
┌──────────┐    θ_target    ┌──────────┐    τ_cmd    ┌──────────┐    τ_actual
│ 轨迹生成  │ ────────────→ │ PID 控制  │ ─────────→ │ 关节电机  │ ──────────→
│ (100Hz)  │               │ (1kHz)   │            │ (Plant)  │
└──────────┘               └──────────┘            └──────────┘
                                  ↑                      │
                                  │      θ_actual        │
                                  └──────────────────────┘
```

- **外环（100Hz）**：轨迹规划 + IK（感知→决策）
- **内环（1kHz）**：PID 控制（执行）
- **共享状态**：无锁原子变量传递目标关节角，避免外环阻塞内环

### 4.2 PID 控制器设计

每个关节独立 PID：

```
τ = K_p · e(t) + K_i · ∫e(t)·dt + K_d · de(t)/dt + τ_ff
```

**抗积分饱和**：对积分项做**钳位**（clamping）。当控制器输出饱和时停止积分累积，防止积分器"windup"导致超调。

**前馈力矩 τ_ff**：由逆动力学模型根据目标加速度和当前状态计算。前馈可以显著减少跟踪延迟——PID 单独控制有 ~10ms 相位滞后，加入前馈可降至 <1ms。

### 4.3 错过控制周期的后果

在 1kHz 硬实时系统中：
- 1 次错过：关节力矩输出延迟，位置误差增大 ~0.1°（视速度）
- 连续 5 次错过：位置误差累积到 0.5°～1°，可能触发安全停机
- 连续 10 次错过：系统进入紧急制动模式

因此"零错过"是硬实时控制的基本要求。这意味着 **P99 控制循环时间必须 < 1ms**。

## 5. 性能优化要点

### 5.1 矩阵求逆开销

7×7 矩阵求逆在 DLS IK 中占计算量的 ~70%：
- 朴素高斯消元：O(n³) = 343 FLOPs，实际约 2μs
- Cholesky 分解（利用对称正定性）：O(n³/6) ≈ 57 FLOPs，实际约 0.5μs
- SVD（Jacobi 迭代）：需要多次 Jacobi 扫描（每次扫描 n(n-1)/2 次 Givens 旋转），10 次扫描约 200μs

**结论**：对于 DLS，使用 Cholesky 分解解 (JᵀJ+λ²I)x = Jᵀe 是最优选择。

### 5.2 避免动态内存分配

实时控制循环中绝对禁止 `malloc`/`new`：
- 预分配所有工作数组（静态大小已知，如 7-DOF 固定）
- 使用栈上的 `std::array` 或固定大小数组
- 矩阵运算使用固定维度（模板参数）避免 heap 分配
- 日志使用无锁环形缓冲区 + 后台线程

### 5.3 感知与控制的速率匹配

```
感知（相机/LiDAR）：30Hz (33ms/帧)
   ↓ 目标位姿更新
控制（IK+PID）：1000Hz (1ms/周期)
   ↓ 关节力矩输出
电机驱动器：20000Hz (50μs/周期)
```

速率不匹配的经典处理：
- **零阶保持**：控制环使用最新可用目标（可能有 33ms 滞后）
- **一阶外推**：根据前两帧目标位姿预测当前目标（减少滞后至 ~5ms）
- **双缓冲原子交换**：感知线程写入后台缓冲，完成后原子交换指针，控制线程始终读前台缓冲

### 5.4 无锁共享状态

```cpp
// 双缓冲：感知写入 write_buf，控制读取 read_buf
struct TargetState {
    double joint_targets[7];
    double timestamp;
};
std::atomic<TargetState*> read_buf;
TargetState buf_a, buf_b;
// 感知线程完成计算后：
TargetState* old = read_buf.load();
// 写入另一个缓冲...
read_buf.store(&buf_b);
```

原子指针交换延迟 < 1ns，相比互斥锁减少了 1000 倍同步开销。

## 6. 实际案例：7 轴机械臂 IK 收敛在 0.3ms 内

某工业 7 轴机械臂控制器的实测数据：

| 指标 | 数值 |
|------|------|
| IK 算法 | DLS + Cholesky |
| 平均迭代次数 | 4.2 次 |
| P50 收敛时间 | 0.18ms |
| P99 收敛时间 | 0.29ms |
| 最坏情况（近奇异） | 0.48ms（12 次迭代） |
| 1kHz 周期预留 | 1ms × 70% = 0.7ms 给 IK |
| 异步目标更新率 | 100Hz（感知线程独立） |
| 控制抖动 (P99) | 12μs |
| 错过周期率 | 0 / 10⁶ cycles |

关键优化手段：
1. Cholesky 替代 SVD（减少 4 倍计算量）
2. 自适应 λ（正常 λ=0.01，近奇异 λ=0.5）
3. 预分配所有矩阵，零堆分配
4. 双缓冲原子交换替代互斥锁
5. CPU 核心隔离 + SCHED_FIFO 实时调度
6. 大页内存锁定，禁止 page fault

**核心教训**：机械臂实时控制的瓶颈不在"峰值算力"，而在"最坏情况确定性"。P99 比平均值重要 100 倍。
