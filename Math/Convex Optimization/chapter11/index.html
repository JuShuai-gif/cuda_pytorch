第十一章 内点法

概述

本章讨论内点法 (Interior-Point Methods)——求解带不等式约束凸优化问题的最强大通用方法。核心思想：对数障碍+中心路径+牛顿法。MOSEK/Gurobi/ECOS/SCS的核心引擎。

关键概念速查

对数障碍 -log(-f_i) = "软墙"

接近边界则惩罚趋于无穷。自和谐则牛顿法常数步收敛。比硬约束数值稳定

中心路径 x*(t) = "渐近线"

t从小到大：从内部安全点逐渐逼近边界最优解。每步离最优不超过m/t

原始-对偶 = "障碍法2.0"

同时更新x和lambda。一步牛顿改善原+对偶可行。比纯障碍快2-5倍

O(sqrt(m)*log 1/eps)迭代

m=约束数,eps=精度。迭代随sqrt(m)增长。100约束约30次牛顿。实践中更少

🎤 面试高频问题 & 工程落地陷阱

Q: 内点法求解失败最常见的3个原因及修复？
A: 1)数值病态(条件数>1e12)→加Tikhonov正则(1e-8*I到Hessian)或换求解器。2)初始点不在严格内部→Phase I先找可行点(CVXPY自动处理)。3)迭代不收敛→增大mu(减少外层迭代)、换初始点、检查约束是否矛盾。

Q: 为什么LP用内点法，深度学习用SGD？
A: LP: n~10^3-10^6, 需要高精度(1e-8), 目标准确→内点法最优。DL: n~10^6-10^11, 随机目标(数据流), 低精度即可(泛化)→SGD最优。两者没有"谁更好",只是不同场景的不同选择。

Q: DCO层(cvxpylayers)是什么？为什么重要？
A: 将凸优化求解器(PyTorch版)嵌入神经网络计算图→前向:解QP/SOCP→输出;反向:通过KKT矩阵隐函数微分计算梯度(无需展开迭代!)。应用:端到端MPC控制器训练、约束满足生成模型、结构化预测。

📖 多层公式解读 —— 对数障碍 -log(-fᵢ(x)) 的自和谐性与选择原理
第1层：为什么是log

log barrier在u→0⁻时增长速度为O(log(1/|u|))。这个增长速度恰好满足自和谐条件|φ′′′(u)|≤2φ′′(u)^{3/2}→牛顿法在常数步内收敛→与维度无关。

第2层：为什么不用1/u

用1/u→φ′′(u)=2/u³, φ′′′(u)=-6/u⁴。自和谐性不成立→远离边界时惩罚太小(Hessian接近奇异),靠近边界时惩罚太大(Hessian病态)→牛顿法需要很多步。

第3层：工程类比

log barrier = "渐进式约束"。在机器人安全探索中,离障碍物远时-log(d)几乎为零(不影响目标);靠近时逐渐增大;紧贴时→∞(绝对不能穿越)。这比硬约束(突然截断)安全得多。

11.1 不等式约束凸优化问题

标准形式 (Boyd 11.1)
$$\text{minimize } f_0(x) \quad \text{s.t. } f_i(x) \le 0\;(i=1,\ldots,m),\; Ax = b$$

$f_i$凸且二阶连续可微。$f_i(x)\le0$是"墙"——不能穿越。核心挑战：不等式约束定义了可行域的边界，单纯无约束方法会"撞墙"。

11.2 对数障碍函数与中心路径

对数障碍 (Boyd 11.2.1)
$$\phi(x) = -\sum_{i=1}^m \log(-f_i(x))$$

$x$接近边界($f_i(x)\to0^-$)时$\phi(x)\to\infty$——形成"软墙"。障碍问题：$\min t f_0(x) + \phi(x)$ s.t. $Ax=b$。$t>0$是精度参数。

为什么是log而不是别的函数

$-\log(-u)$在$u\to0^-$时的增长速度恰好让内点法具有最优的理论性质——自和谐性。如果用$1/(-u)$或$1/(-u)^2$，算法会慢得多或数值不稳定。log barrier是Nesterov和Nemirovsky在1980年代证明最优的选择。

中心路径数值例：min x^2 s.t. x>=1

障碍：$\min t x^2 - \log(x-1)$。一阶条件：$2t x - 1/(x-1)=0$。$x^*(t)=0.5+\sqrt{0.25+1/(2t)}$。t=0.1: x*=2.79(远离边界)；t=1: x*=1.37；t=10: x*=1.048(逼近)；t->inf: x*->1(最优!)

机器人安全探索：-log(d)=碰撞惩罚=人工势场法的最优版本(自和谐!)；中心路径=安全裕度从保守到激进的平滑过渡；安全RL=障碍法软约束

11.3 中心路径

定义与性质 (Boyd 11.2.2)

$\{x^*(t)\mid t>0\}$是光滑曲线——中心路径。关键性质：$f_0(x^*(t))-p^*\le m/t$。即每增加$t$一个因子$\mu$，对偶间隙缩小$\mu$倍。从中心路径可提取对偶可行点：$\lambda_i^*(t)=-1/(t f_i(x^*(t)))$。

11.2.1 对数障碍函数的梯度与Hessian (Boyd 11.2.1)

代数推导

$\phi(x)=-\sum \log(-f_i(x))$。梯度：$\nabla\phi = -\sum (1/f_i) \nabla f_i$。Hessian：$\nabla^2\phi = \sum (1/f_i^2) \nabla f_i \nabla f_i^T - \sum (1/f_i) \nabla^2 f_i$。第一项正半定(外积)，第二项负半定。总Hessian正定→$\phi$凸。

11.3 障碍方法完整流程 (Boyd 11.3)

参数选择与收敛

中心步骤：用等式约束牛顿法求解$\min t f_0(x)+\phi(x)$ s.t. $Ax=b$。从上一轮$x$开始(warm start)→通常20-30步牛顿法收敛。

更新t：$t:=\mu t$。$\mu=10-20$。$\mu$太小→外层迭代多；太大→内层牛顿法步数多。$\mu\approx15$是经验最优。

停止准则：$m/t < \varepsilon$→停止。$\varepsilon=10^{-6}$(中等精度),$10^{-9}$(高精度)。

11.3.3 收敛性分析 (Boyd 11.3.3)

理论保证

总牛顿步数$\le O(\sqrt{m} \cdot \log(1/\varepsilon))$。$m$=不等式约束数，$\varepsilon$=精度。对LP(100约束,$10^{-6}$精度)：$\sqrt{100}\cdot\log(10^6)=10\cdot13.8\approx138$次牛顿步。实践中更少(30-50步)。

11.4 可行性与Phase I方法 (Boyd 11.4)

如何找到初始严格可行点

Phase I：引入松弛变量$s\ge0$，$\min s$ s.t. $f_i(x)\le s, Ax=b$。若最优值=0→可行；若>0→不可行(约束矛盾)。Phase I的解作为Phase II的初始点。

工程实践

CVXPY自动处理Phase I。如果问题不可行，CVXPY返回'infeasible'。调试：逐个移除约束找出矛盾源头。常见原因：数值误差导致约束过紧→加微小松弛($10^{-8}$)。

11.4 障碍方法

算法流程
  1. 给定严格可行$x$，$t=t^{(0)}>0$，$\mu>1$，$\epsilon>0$
  2. 中心步骤：用牛顿法求解$\min t f_0(z)+\phi(z)$ s.t. $Az=b$
  3. 更新：$x:=x^*(t)$
  4. 停止？若$m/t<\epsilon$则返回$x$
  5. 增大t：$t:=\mu t$，回到步骤2

外层迭代次数=$O(\log_\mu(m/(\epsilon t^{(0)})))$（对数级）。内层牛顿法通常20-30步。总复杂度$O(\sqrt{m}\log(1/\epsilon))$次牛顿迭代。实践中LP通常20-50步收敛。

11.5 原始-对偶内点法

改进版 (Boyd 11.7)

同时更新原变量$x$和对偶变量$\lambda,\nu$，而不是先完全解屏障问题再更新$t$。一步牛顿法同时改善原始可行性和对偶可行性。

优势：比纯障碍法快2-5倍，对初始点不敏感。SDPT3/SeDuMi/MOSEK核心引擎。

实时MPC=内点法20步牛顿每毫秒；DCO层=cvxpylayers嵌入PyTorch(可微!)；GPU内点10-100x加速(cuSOLVER稀疏Cholesky)。安全RL=障碍法软约束。
🧭 反面清单 — 什么时候"不要"用凸优化
  • 问题本质非凸且不可凸化：神经网络训练、组合优化(TSP)。凸松弛只给下界，需启发式/全局求解器。
  • 目标/约束无法显式写出：黑盒、仿真驱动 → 用贝叶斯优化/进化算法。
  • 需要整数解：凸优化给连续解，整数约束破坏凸性 → 用 MILP/分支定界。
  • 实时性要求极端但问题巨大：可能需专用一阶法或牺牲精度。
  • 误判凸性：把非凸问题当凸求解会得到错误的"最优"。先验证凸性(Hessian、保凸运算)再上凸求解器。

正面信号：能写成 $\min$ 凸函数 s.t. 凸不等式 + 仿射等式，且满足 Slater → 放心用凸优化，享受全局最优保证。

📕 补充 (11.4) — 可行性与第一阶段方法 (Phase I)

内点法需要一个严格可行起点。Phase I 通过求解辅助问题来找它：$\min_{x,s}\ s$ s.t. $f_i(x)\le s,\ Ax=b$。

若最优 $s^\*<0$ → 找到严格可行点（进入 Phase II 求解原问题）；若 $s^\*>0$ → 原问题不可行；$s^\*=0$ → 在可行边界。辅助问题总有易得的初始点(把 $s$ 取得足够大)。这套"先判可行、再求最优"的两阶段流程是完整内点求解器的标准结构。
