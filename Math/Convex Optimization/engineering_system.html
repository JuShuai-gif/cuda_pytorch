第六章 逼近与拟合 — Approximation & Fitting

6.1 范数逼近 — min||Ax-b||

数学定义

$$\min_x \|Ax-b\|$$ A是数据矩阵(m×n)，b是观测值(m×1)，x是参数(n×1)。选择不同范数=选择不同逼近策略。
L2: ||r||_2 = sqrt(sum r_i^2) — 高斯噪声最优，解析解 x*=(A^TA)^{-1}A^Tb
L1: ||r||_1 = sum|r_i| — 拉普拉斯噪声最优，产生稀疏残差
Linf: ||r||_inf = max|r_i| — 最坏情况最优，Chebyshev逼近

几何直觉

L2想"平均照顾"每个点→被异常值拉偏。L1允许某些点完全对齐(零残差)→异常值几乎不影响。Linf保证每个点的偏差都不超过最优值→"公平对待"。

2.0 Norm balls
CVXPY实现
import cvxpy as cp, numpy as np
A = np.random.randn(100, 20); b = np.random.randn(100)
x = cp.Variable(20)

# L2 (QP)
cp.Problem(cp.Minimize(cp.norm(A@x-b, 2))).solve()
# L1 (LP) — robust to outliers
cp.Problem(cp.Minimize(cp.norm(A@x-b, 1))).solve()
# Linf (LP) — Chebyshev
cp.Problem(cp.Minimize(cp.norm(A@x-b, 'inf'))).solve()
四大工程系统映射
🤖 机器人SLAM回环检测：min||位姿约束残差||。L2用于视觉SLAM(高斯噪声)；L1用于鲁棒SLAM(错误回环)。传感器标定=L2最小化重投影误差。
🧠 深度学习VLA行为克隆loss=L2(连续动作)或交叉熵(离散)。L1正则用于模型剪枝→边缘部署。知识蒸馏=L2匹配教师-学生logits。
⚡ HPCQR分解在GPU上用cuSOLVER。分布式ADMM分解L1问题。通信带宽约束=Linf逼近保证每节点不超上限。
🏗 体系结构Cache miss惩罚=Huber损失(小miss用L2精确，大miss用L1鲁棒)。GPU occupancy优化=min||配置-峰值||。
工程中什么会出错

L2的陷阱：一个离群点毁掉整个解。金融flash crash→L2回归全部偏移。修复：先用L1筛异常点，再用L2精修。或直接用Huber(M=1.345)。

面试问题

Q: 为什么L1产生稀疏解L2不？A: L1的次梯度在0处是区间[-1,1]→最优解可以精确为0。L2的梯度与|x|成正比→只能趋于0永不为0。几何上：L1球的尖角在坐标轴上→解落在轴上→稀疏。

一句话总结

选择范数=选择对误差的度量哲学。L2(均值/高斯)、L1(中位数/拉普拉斯)、Linf(中距/均匀)。CVXPY中一行切换。

6.3 正则化 — min||Ax-b||+gamma*||x||

定义

Ridge(L2): 解析解(A^TA+gamma*I)^{-1}A^Tb。LASSO(L1): 无解析解但产生稀疏—自动特征选择。Elastic Net: 组合两者。

CVXPY：弹性网

cp.Problem(cp.Minimize(loss+reg)).solve()
工程映射

🧠 DL VLA剪枝：训练时加L1正则→50-90%权重变零→推理时稀疏矩阵乘法→边缘GPU实时运行。
🤖 MPC：L1正则控制输入→稀疏控制(只在关键时刻动作)→节能。
🏗 编译器优化pass选择—满足正确性约束下最小化pass数量(L0→L1凸松弛)。

面试

Q: Ridge vs LASSO: 何时用哪个? A: n>>p: Ridge(特征都重要需防过拟合)。p>>n: LASSO(特征数超样本数，唯一选择)。需要可解释性: LASSO(自动选特征)。

6.4 鲁棒逼近 — 当A不确定时

定义

min_x sup_{A in A_set} ||Ax-b||。A不确定→最小化最坏情况残差。域随机化的数学基础。Huber损失=小误差L2+大误差L1的平滑混合。

工程映射

🧠 DL VLA：模型在仿真环境变化(光照/纹理/动力学)下训练→最坏情况鲁棒→部署时不因环境变化失败。

第七章 统计估计 — Statistical Estimation

7.1 MLE — 最大似然估计

核心原理

$$\hat{x}_{ML} = rg\max_x \log p_x(y)$$ 噪声分布→损失函数：Gaussian→L2(||Ax-b||^2)；Laplace→L1(||Ax-b||_1)；Logistic→交叉熵。MLE告诉你损失函数该长什么样。

CVXPY：逻辑回归(VLA行为分类)
X=np.random.randn(200,10); y=(X@np.array([1,0.5,-0.3,0,0,0.2,0,0,0,0])+0.1*np.random.randn(200)>0).astype(float)
beta=cp.Variable(10); log_like=cp.sum(cp.multiply(y,X@beta)-cp.logistic(X@beta))
cp.Problem(cp.Maximize(log_like)).solve()
工程映射

🤖 机器人SLAM：IMU偏置估计=高斯MLE=Kalman滤波。视觉特征匹配RANSAC(L1思想)+光束平差(L2精修)。
🧠 VLA：动作token预测=交叉熵MLE。探索策略熵正则化=最大化策略熵。
⚡ HPC：Roofline模型拟合=从benchmark估计memory bandwidth和peak flops。

面试

Q: 为什么MLE而不是直接最小二乘? A: MLE从第一性原理推导损失—告诉你损失函数"应该长什么样"。假设高斯→MLE=L2;假设拉普拉斯→MLE=L1。用L2只是习惯，用MLE是理解。

7.2 MAP — 最大后验 = MLE + 先验

定义

$$\hat{x}_{MAP}=rg\max[\log p_x(y)+\log p(x)]$$ p(x)是先验—你看数据前对x的信念。-log p(x)就是正则化项! Laplace先验→L1正则; Gaussian先验→L2正则。

工程映射

🤖 Kalman滤波=MAP特例：预测步=先验，更新步=似然。
🧠 BayesNN变分推断=ELBO最小化KL(q||p)→凸子问题。
🏗 分支预测器=MAP—历史跳转数据(似然)+静态分析先验(大部分分支不跳)。

第九章 无约束最小化 — Unconstrained Minimization

9.1 下降方法 — x_{k+1}=x_k+t_k*Delta_x_k

框架

Delta_x_k是搜索方向(grad_f^T*Delta_x<0)。回溯线搜索(Armijo)：从t=1反复折半直到下降够。alpha=0.3, beta=0.8是常用参数。

-0.90
工程映射

🤖 IK：每步=雅可比伪逆→关节更新。实时<1ms→最多3-5次迭代。
🧠 DL：SGD/Adam/AdamW。VLA训练用AdamW(解耦weight decay)。
⚡ HPC：Nesterov加速→O(1/k)→O(1/k^2)。cuDNN算法选择=梯度调优。
🏗 编译优化：pass排序=黑箱优化→贝叶斯优化(代理模型≈二阶信息)。

GD vs Newton: 何时用什么?

GD：n>10000—每次O(n)便宜，但需要数千步。峡谷地形走Z字—慢。Newton：n<5000—每次O(n^3)贵，但10-20步收敛。用曲率信息避免Z字。实践：先GD靠近，再切L-BFGS(拟牛顿，O(mn)存储)。

9.2 牛顿法 — Delta_x = -H^{-1}*grad_f

算法

阻尼阶段(lambda>eta)：线性收敛，需线搜索。纯阶段(lambda<=eta)：步长=1，二次收敛—||x_{k+1}-x*|| <= C||x_k-x*||^2。误差每次迭代平方缩小!

CVXPY幕后
# 求解器内部(KTT系统):
# [[H, A^T], [A, 0]] * [dx; nu] = [-g; 0]
# 稀疏Cholesky分解→牛顿步。典型LP:20-40次迭代,每次<1ms
牛顿法何时失败?

Hessian奇异/病态：→加阻尼(H←H+lambda*I, Levenberg-Marquardt)。远离最优：二阶近似差→先GD再切Newton。n>5000：用L-BFGS(存m=10-20步梯度差)或共轭梯度。

第十章 等式约束最小化

10.1 KKT系统 — [[H,A^T],[A,0]]*[dx;nu]=[-g;0]

定义

min f(x) s.t. Ax=b的牛顿步。dx必须在A的零空间(A*dx=0)—保持在约束子空间内。nu是对偶变量("约束力")。

手写牛顿 vs CVXPY
# CVXPY (一行):
x=cp.Variable(2); cp.Problem(cp.Minimize(cp.sum_squares(x)),[cp.sum(x)==1]).solve()
# 手写Newton (n=2,p=1):
x=np.array([0.5,0.5]); A=np.ones((1,2)); b=np.array([1.])
for _ in range(3):
    H=2*np.eye(2); g=2*x
    KKT=np.block([[H,A.T],[A,np.zeros((1,1))]])
    dx_nu=np.linalg.solve(KKT,np.concatenate([-g,[0.]]))
    x+=dx_nu[:2]
print(x) # -> [0.5, 0.5] 牛顿法一步收敛!
工程映射

🤖 MPC：每步QP的KKT系统。p(预测步)<🧠 DL：BatchNorm统计约束(均值=0,方差=1)=等式约束→反向传播隐式满足。
⚡ HPC：GPU稀疏KKT用cuSOLVER Cholesky→10-100x加速。通信约束=等式(发送=接收)。

10.2 消元法 — p远小于n时的杀手锏

Schur补消元

消去dx: (A H^{-1} A^T)nu = -A H^{-1} g。先解p×p系统→回代dx。复杂度O(n^3/p)。p=1时加速~p^2倍!

MPC加速

n=100状态,p=10预测步。直接KKT:O(110^3)。消元:O(100^3/10)=O(100k)→约1000倍加速! OSQP能在<1ms内求解MPC的QP。

第十一章 内点法 — Interior-Point Methods

11.1 对数障碍 — phi(x)=-sum log(-f_i(x))

障碍法核心

min t*f0(x)+phi(x) s.t. Ax=b。t增大→"软墙"变薄→逼近原问题。log barrier自和谐→牛顿法常数步收敛!

0.10 Central path
手写障碍法 vs CVXPY
# CVXPY:
x=cp.Variable(); cp.Problem(cp.Minimize(x**2),[x>=1]).solve() # -> 1.0

# 手写障碍法:
x,t,mu=2.0,0.1,10.0
for _ in range(8):
    for _ in range(20): x-= (2*t*x-1/(x-1))/(2*t+1/(x-1)**2)
    t*=mu
print(f"x*={x:.6f}") # -> 1.000000
四大系统映射

🤖 安全RL：障碍法=约束MDP安全探索。log barrier防策略进入危险状态。
🧠 DL VLA：DCO层=cvxpylayers将QP嵌入PyTorch(可微!)→端到端训练。
⚡ HPC：GPU内点法=MOSEK在A100上求解10000变量SDP秒级。cuSOLVER稀疏Cholesky核心。
🏗 编译优化：寄存器分配整数规划→SDP松弛(PSD锥)→内点法求解→投影回整数。

内点法何时失败?

1.无严格可行点(Slater不满足)→可能无数值解。2.条件数>10^12→Hessian病态→需预处理。3.mu太大(t跳太多)→牛顿法需很多步→反而慢(mu=10-20最佳)。4.初始点不在内部→需Phase I方法先找可行点。

面试问题汇总

Q: 内点法vs单纯形法? A:内点法迭代~O(sqrt(n)log(1/eps))—随规模增长慢。单纯形法最坏指数。n>10^5时内点法更快。
Q: Hessian不正定? A:加阻尼H←H+lambda*I;或切梯度下降。
Q: 如何选求解器? A: LP→Gurobi; QP→OSQP; SOCP→ECOS/MOSEK; SDP→SDPT3/MOSEK; 无约束→L-BFGS(scipy)。

11.2 中心路径 — {x*(t) | t>0} 光滑渐近线

性质

f0(x*(t))-p* <= m/t。每增大t一个因子mu≈10-20，精度提升一个数量级。从中心路径可提取对偶可行点：lambda_i*(t)=-1/(t*f_i(x*(t)))。

工程类比

机器人安全裕度切换—t小=离障碍远(保守)，t大=离障碍近(激进)。中心路径=从保守到激进的最优过渡。安全RL中"约束逐步收紧"对应t逐步增大。

Ch11核心

内点法=障碍法+中心路径+牛顿法。理解它=理解为什么cvxpy代码在几毫秒内求解数千变量问题。工业求解器(MOSEK/Gurobi)的核心引擎。
