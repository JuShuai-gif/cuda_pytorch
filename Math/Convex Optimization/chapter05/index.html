第五章 对偶

对偶是凸优化中最优美也最强大的概念之一。它为每个优化问题（即使是非凸的）构造一个与之相伴的对偶问题，该对偶问题总是凸的。对偶问题的解为原问题提供了下界（弱对偶），且在许多条件下这个下界是紧的（强对偶）。对偶还导出了最优性条件（KKT条件），是理解优化算法收敛性的理论基础。
💻 CVXPY实战：Lagrange对偶：验证对偶间隙
import cvxpy as cp, numpy as np
# 原问题: min x^2 s.t. x >= 1
x = cp.Variable()
primal = cp.Problem(cp.Minimize(x**2), [x >= 1])
primal.solve()
p_star = primal.value  # p* = 1.0

# 对偶: max lambda - lambda^2/4  s.t. lambda >= 0
lam = cp.Variable()
dual = cp.Problem(cp.Maximize(lam - lam**2/4), [lam >= 0])
dual.solve()
d_star = dual.value  # d* = 1.0

print(f"Primal optimum: {p_star:.4f}")
print(f"Dual optimum:   {d_star:.4f}")
print(f"Duality gap:    {p_star - d_star:.2e}")  # 强对偶!

Lagrange对偶的数值验证：原问题和对偶问题的最优值相等(强对偶)。CVXPY自动处理min和max两种方向，对偶问题总是凸的。

5.1 Lagrange对偶函数

📋 中文定义

考虑标准形式的优化问题（不必是凸的）：

$$egin{aligned} ext{minimize} \quad & f_0(x) \ ext{subject to} \quad & f_i(x) \le 0,\; i=1,\ldots,m \ & h_i(x) = 0,\; i=1,\ldots,p \end{aligned}$$

Lagrange函数 $L: \mathbb{R}^n imes \mathbb{R}^m imes \mathbb{R}^p o \mathbb{R}$：

$$L(x, \lambda, u) = f_0(x) + \sum_{i=1}^m \lambda_i f_i(x) + \sum_{i=1}^p u_i h_i(x)$$

其中 $\lambda_i \ge 0$（$\lambda \succeq 0$）是对应不等式约束的Lagrange乘子或对偶变量。

Lagrange对偶函数 $g: \mathbb{R}^m imes \mathbb{R}^p o \mathbb{R}$：

$$g(\lambda, u) = \inf_{x \in \mathcal{D}} L(x, \lambda, u) = \inf_{x \in \mathcal{D}} \left(f_0(x) + \sum_{i=1}^m \lambda_i f_i(x) + \sum_{i=1}^p u_i h_i(x) ight)$$

其中 $\mathcal{D}$ 是所有 $f_i$ 的定义域之交。

🔮 几何直觉

Lagrange对偶函数给原问题加了一个"罚款"项。对不等式约束的违反$\lambda_i f_i(x)$乘以价格 $\lambda_i$，对等式违反 $ u_i h_i(x)$ 也乘以价格 $ u_i$。然后你找所有可行和不可行方案的最低总成本（包括罚款）。

关键直觉：对于可行的 $x$（满足 $f_i(x)\le 0$ 和 $h_i(x)=0$），罚款非正（$\lambda_i \ge 0$），所以 $L(x,\lambda, u) \le f_0(x)$。对所有 $x$ 取 inf 所以 $g(\lambda, u) \le p^*$（最优值）。

✅ 关键性质
  1. $g$ 总是凹的（无论原问题是否凸）——因为它是关于 $(\lambda, u)$ 的仿射函数族（每个 $x$ 对应一个仿射函数 $L(x,\cdot,\cdot)$）的逐点下确界。
  2. 下界性质： $g(\lambda, u) \le p^*$ 对所有 $\lambda \succeq 0, u$ 成立。
  3. 对偶函数提供了原问题最优值的下界。
📘 例5.1 等式约束凸二次最小化 (Boyd)

$\min \frac{1}{2}x^T P x + q^T x$ s.t. $Ax = b$（$P \succ 0$）。Lagrange函数：$L(x,\nu) = \frac{1}{2}x^T P x + q^T x + \nu^T(Ax-b)$。

对 $x$ 最小化得 $x^* = -P^{-1}(q + A^T \nu)$。代入得对偶函数：

$$g(\nu) = -\frac{1}{2}(q + A^T \nu)^T P^{-1}(q + A^T \nu) - b^T \nu$$

对偶问题是无约束凹最大化，可解析求解。

🧠 一句话总结

$g(\lambda, u)=\inf_x(f_0(x)+\sum\lambda_i f_i(x)+\sum u_i h_i(x))$ 是对偶函数。它总是凹的且 ≤ 原问题最优值。

5.2 Lagrange对偶问题

📋 中文定义

Lagrange对偶问题(Lagrange dual problem)是寻找原问题 $p^*$ 的最佳下界：

$$\begin{aligned} \text{maximize} \quad & g(\lambda, \nu) \\ \text{subject to} \quad & \lambda \succeq 0 \end{aligned}$$

对偶问题的最优值记为 $d^* = \sup_{\lambda \succeq 0, \nu} g(\lambda, \nu)$。

对偶问题总是凸的：最大化凹目标函数 $g$，受限于凸约束 $\lambda \succeq 0$（即 $-g$ 凸最小化，$\lambda \succeq 0$ 是凸的半空间约束）。

弱对偶性(Weak duality)： $d^* \le p^*$。即使原问题非凸，对偶也给出有意义的下界。

强对偶性(Strong duality)： $d^* = p^*$。通常需要约束品性(constraint qualification)来保证。

🔮 几何直觉

对偶问题相当于"最大化原问题最优值的下界"。弱对偶总是成立，但强对偶（对偶间隙为零）在凸优化中通常成立。

Slater条件（充分条件）：如果原问题是凸的且存在严格可行点（对所有不等式约束 $f_i(x) < 0$），则强对偶成立。

对偶的意义在于：将有约束问题转化为无约束问题（对内层 $\inf_x$ 通常可解析求解），然后最大化一个凹函数。

📘 Slater条件 (Boyd §5.2.3)

对凸优化问题，如果存在 $x \in \text{relint}\,\mathcal{D}$ 使得：

$$f_i(x) < 0,\; i=1,\ldots,m,\qquad Ax = b$$

则强对偶成立。对于不等式约束中有仿射函数的，严格条件可放宽（只需非严格）。

注意：强对偶可能在原问题非凸时也成立（虽然有违直觉），但这不常有。

弱对偶：$d^* \le p^*$（永远成立）。
强对偶：$d^* = p^*$（需要约束品性，对凸问题通常满足）。
对偶间隙：$p^* - d^* \ge 0$，零间隙 → 强对偶。
📖 公式解读 — 弱对偶 $d^* \le p^*$ 和强对偶 $d^* = p^*$ 的区别？
  • $p^*$ = 原问题最优值： 在你实际能做的事情（可行方案）中，最低的代价是多少。
  • $d^*$ = 对偶问题最优值： 在"放松"了约束（允许罚款）后，你能拿到的最大下界。
  • 弱对偶 $d^*\le p^*$（永远成立）： 对偶永远给出原问题的一个安全的低估。就像你估算了工程最低成本是 100 万——你实际花的肯定 ≥100 万。
  • 强对偶 $d^*=p^*$（需要条件）： 低估恰好是真实值！这在凸优化中通常成立（Slater条件保证）。这意味着你可以求解对偶问题（总是凸的！）来间接得到原问题的最优值。
  • Slater条件的通俗翻译： 存在一个点 $x$，使得所有不等式约束都严格成立（$f_i(x)<0$）。这意味着约束不是"紧贴"着的，问题"有空间"。没有严格可行点 → 可能出现对偶间隙。
  • 为什么重要： 对偶把一个有约束的（可能非凸）问题转化为无约束的凹最大化——这在计算上友善得多。对偶变量 $\lambda_i^*$ 还给出约束的影子价格。
📖 公式解读 — Lagrange 函数 $L(x,\lambda,\nu) = f_0(x) + \sum\lambda_i f_i(x) + \sum\nu_i h_i(x)$ 到底在做什么？
  • 拆解每一项： $f_0(x)$ 是原始成本。$\lambda_i f_i(x)$ 是"违反第 $i$ 个不等式约束的罚款"（$\lambda_i\ge0$ 是罚款单价）。$\nu_i h_i(x)$ 是"违反第 $i$ 个等式约束的罚款"（可正可负）。
  • 通俗类比： 你是承包商，$f_0$ 是工程成本。合同要求 $f_i(x)\le0$（如工期≤100天）——每超过一天罚款 $\lambda_i$。$h_i(x)=0$ 是硬性技术参数必须恰好满足——偏离即罚。
  • 为什么 $\lambda_i\ge0$： 因为 $f_i(x)\le0$，如果你违反约束 $f_i(x)>0$，罚款应为正。如果你满足约束 $f_i(x)<0$，罚款应为负（实际是奖励）。所以"罚款单价"必须非负。
  • 对偶函数 $g(\lambda,\nu)=\inf_x L$： 你在做最坏打算——不管承包商选什么 $x$，你取最低的总成本。这个最低总成本就是你（对偶方）能拿到的钱的下界。
  • 数值例子： $\min x^2$ s.t. $x\ge1$。重写为 $1-x\le0$。$L(x,\lambda)=x^2+\lambda(1-x)$。$\inf_x L$：对 $x$ 求导 $2x-\lambda=0 \to x=\lambda/2$。代入：$g(\lambda)=\frac{\lambda^2}{4}+\lambda(1-\frac{\lambda}{2})=\lambda-\frac{\lambda^2}{4}$。
📘 例5.2 注水算法 (Water-filling) (Boyd)

$\min -\sum_{i=1}^n \log(\alpha_i + x_i)$ s.t. $x \succeq 0,\; \mathbf{1}^T x = 1$（$\alpha_i > 0$）。通过 KKT 条件得到解析解：

$$x_i^* = \max\{0, \nu - \alpha_i\}$$

其中 $\nu$ 由 $\sum x_i^* = 1$ 确定。这被称为注水解(water-filling)——在通信信道容量分配和信息论中非常经典。

📘 例5.3 熵最大化 (Boyd)

$\max -\sum x_i \log x_i$ s.t. $Ax \preceq b,\; \mathbf{1}^T x = 1$。对偶问题为：

$$\max -b^T \lambda - \log\sum_{i=1}^n \exp(-a_i^T \lambda)$$

这是无约束凸问题（log-sum-exp 函数是凸的）。对偶将指数级数的约束转化为易处理的无约束最大化。

📘 例5.4 可分离函数的等式约束最小化 (Boyd)

$\min \sum_{i=1}^n f_i(x_i)$ s.t. $a^T x = b$。Lagrange函数 $L(x,\nu) = \sum f_i(x_i) + \nu(a^T x - b)$。对 $x$ 最小化分解为 $n$ 个独立的一维问题：$\inf_{x_i}(f_i(x_i) + \nu a_i x_i)$。对偶函数 $g(\nu)$ 是这些一维最优值的和减去 $\nu b$。

📘 例5.5 无约束几何规划对偶 (Boyd)

$\min \sum_{k=1}^{K_0} c_k e^{a_k^T y}$（GP的凸形式）。通过变量替换 $x_i = e^{y_i}$ 转化为凸问题。对偶是无约束凹最大化问题。

📘 例5.6 范数逼近问题的对偶 (Boyd)

$\min \|Ax - b\|$（无约束，任意范数）。Lagrange对偶给出：$\max -b^T z$ s.t. $\|A^T z\|_* \le 1$（其中 $\|\cdot\|_*$ 是对偶范数）。原问题和对偶问题通过范数对偶性相关联。

🧠 一句话总结

对偶问题 = 最大化下界。弱对偶永远成立，强对偶在凸优化中通常成立（Slater条件保证）。

5.3 几何解释

📋 几何定义

定义集合 $\mathcal{G} = \{(f_1(x),\ldots,f_m(x),h_1(x),\ldots,h_p(x),f_0(x)) \mid x \in \mathcal{D}\} \subseteq \mathbb{R}^{m+p+1}$。

令 $\mathcal{A} = \mathcal{G} + (\mathbb{R}^m_+ \times \{0\} \times \mathbb{R}_+)$（即允许不等式约束$f_i$增大）。$p^* = \inf\{t \mid (u,v,t) \in \mathcal{A},\; u=0,\; v=0\}$。

对偶函数 $g(\lambda,\nu)$ 对应 $\mathcal{A}$ 的一个支撑超平面的截距：超平面 $\lambda^T u + \nu^T v + t = g(\lambda,\nu)$ 支撑 $\mathcal{A}$。

强对偶等价于 $\mathcal{A}$ 在其边界 $(0,0,p^*)$ 处有非垂直的超平面。

🔮 几何直觉

对偶的几何解释是将原问题"嵌入"到一个高维集合 $\mathcal{A}$ 中。$p^*$ 是 $\mathcal{A}$ 在 $(u,v)=(0,0)$ 处的"最低点"。对偶变量 $(\lambda,\nu)$ 定义了一个支撑超平面，其对偶函数值 $g(\lambda,\nu)$ 是该超平面在 $(0,0)$ 处的截距。

强对偶 = 在 $(0,0,p^*)$ 处存在支撑超平面。这是分离定理的一个直接应用。

🧠 一句话总结

对偶的几何本质：用支撑超平面近似目标值。弱对偶 = 所有支撑超平面在下方；强对偶 = 存在恰好触碰到边界点的支撑超平面。

5.4 鞍点解释

📋 中文定义

Lagrange函数的鞍点(saddle-point) $(x^*,\lambda^*,\nu^*)$ 满足：

$$L(x^*, \lambda, \nu) \le L(x^*, \lambda^*, \nu^*) \le L(x, \lambda^*, \nu^*)$$

对所有 $x \in \mathcal{D}, \lambda \succeq 0, \nu$ 成立。

即 $(x^*,\lambda^*,\nu^*)$ 是 $L$ 的鞍点：在 $(\lambda,\nu)$ 方向上最大化，在 $x$ 方向上最小化。

鞍点定理： $(x^*,\lambda^*,\nu^*)$ 是鞍点 $\iff$ $x^*$ 是原问题的最优解，$(\lambda^*,\nu^*)$ 是对偶问题的最优解，且强对偶成立（对偶间隙为零）。

🔮 几何直觉

鞍点的名字来自马鞍的形状：沿一个方向是谷（最小化），沿另一个方向是峰（最大化）。在优化中，$x$ 是"谷"的方向（囚徒想逃脱 → 最小化总代价），而 $\lambda$ 是"峰"的方向（执法者想要最大惩罚 → 最大化对偶函数）。

这解释了"零和博弈"和优化问题的对偶性之间的深层联系。

🧠 一句话总结

鞍点 = 原-对偶最优解对 + 强对偶。Lagrange函数在鞍点处沿原变量方向最小、沿对偶变量方向最大。

🔧 四大工程系统映射
🤖 机器人机器人最优控制：KKT条件③(互补松弛)=接触力只在接触时非零(LCP)。④(稳定性)=目标梯度被约束梯度平衡→没有可行下降方向→最优。MPC每步QP的KKT系统用稀疏Cholesky求解。
🧠 深度学习DL训练收敛：SGD+动量→KKT条件的随机近似。学习率=步长，梯度=方向。训练停滞=KKT条件近似满足(梯度≈0)→局部最优(可能不是全局)。
⚡ HPC分布式ADMM：对偶分解把全局问题分解为子问题。每个节点解局部子问题(原始)，交换对偶变量。KKT条件在固定点处全局满足。NCCL通信=交换对偶变量。
🏗 体系结构编译优化pass排序：每个pass=约束(保持语义等价)。最优pass序列=满足所有约束的最优排序。KKT给出哪些pass是必需的(活跃约束→lambda>0)。

5.5 最优性条件 (KKT条件)

📋 中文定义

Karush-Kuhn-Tucker (KKT) 条件是凸优化问题最优性的充要条件（在适当约束品性下）：

  1. 原始可行性： $f_i(x^*) \le 0,\; h_i(x^*) = 0$
  2. 对偶可行性： $\lambda_i^* \ge 0$
  3. 互补松弛性： $\lambda_i^* f_i(x^*) = 0,\; \forall i$
  4. 稳定条件： $\nabla f_0(x^*) + \sum_i \lambda_i^* \nabla f_i(x^*) + \sum_i \nu_i^* \nabla h_i(x^*) = 0$

对于凸优化问题，若满足 Slater 条件，KKT 条件是 $x^*$ 为最优解的充要条件。

🔮 几何直觉

KKT 条件 = 无约束优化的梯度为零条件推广到有约束情形。稳定条件表示目标函数的负梯度可以通过约束函数的正梯度组合表示——在最优解处，不存在同时改善目标且不违反约束的可行方向。

互补松弛性是最深刻的条件：若约束在最优解处不活跃（$f_i(x^*)<0$），则 $\lambda_i^*=0$（该约束不计入惩罚）；只有活跃约束才影响最优解。

✅ 例子：QP的KKT

考虑 $\min \frac{1}{2}x^T P x + q^T x$ s.t. $Ax = b$（等式约束QP）。KKT条件（令 $\nu$ 为乘子）：

$$P x^* + q + A^T \nu^* = 0,\qquad A x^* = b$$

这等价于线性方程组系统，可直接求解。

📘 例5.9 箱约束LP的KKT (Boyd)

$\min c^T x$ s.t. $l \preceq x \preceq u$。引入乘子 $\lambda^+ \succeq 0$（对上界）和 $\lambda^- \succeq 0$（对下界）。KKT条件给出互补松弛：

$$\lambda_i^+(x_i - u_i) = 0,\qquad \lambda_i^-(l_i - x_i) = 0$$

若 $x_i^* \in (l_i, u_i)$ 则在内部 $\Rightarrow \lambda_i^+ = \lambda_i^- = 0$。若 $x_i^* = u_i$ 则 $\lambda_i^+ \ge 0$ 抵消梯度分量。这解释了最优解必然"碰到"某些边界。

📘 例5.8 最小范数问题的KKT (Boyd)

$\min \|Ax-b\|$。KKT条件导出 $A^T z^* = 0$ 且 $\|z^*\|_* \le 1$，其中 $z^*$ 与残差 $Ax^*-b$ 有关。这给出了最优残差的刻画。

📖 公式解读 — KKT四个条件每条意味着什么？
  • ① 原始可行性 $f_i(x^*)\le0, h_i(x^*)=0$： 你选的方案必须满足所有合同要求。不满足 → 根本不算候选解。
  • ② 对偶可行性 $\lambda_i^* \ge 0$： 罚款单价必须非负。如果你给负的罚款（即奖励违反约束），那"最优"就会变成"尽可能违反约束"——失去意义。
  • ③ 互补松弛 $\lambda_i^* f_i(x^*) = 0$（最深刻！）： 对于每个不等式约束，如果它在最优解处不活跃（$f_i(x^*)<0$，即约束宽松），那么对应的乘子 $\lambda_i^*$ 必须为 0——这个约束不计价。只有"紧"的约束才影响最优解。
  • ④ 稳定性条件 $\nabla f_0 + \sum\lambda_i^*\nabla f_i + \sum\nu_i^*\nabla h_i = 0$： 在最优解处，目标函数梯度 + 活跃约束梯度的线性组合 = 0。几何上：目标函数的负梯度落在活跃约束梯度的锥中——没有可行下降方向。
  • 通俗类比： 你在碗里（凸函数），被绳子（约束）限制。在最低点（最优解），重力（下降方向）被绳子拉力正好抵消。绳子的拉力就是 Lagrange 乘子。松的绳子（非活跃约束）没有力。
🧠 一句话总结

KKT = 梯度零 + 原可行 + 对偶可行 + 互补松弛。凸优化的最优性充要条件。

🎤 面试高频问题 & 工程落地陷阱

Q: 影子价格在工程中的实战应用？
A: MPC中检查哪个约束是瓶颈: 扭矩约束的lambda*=0.05→升级电机收益有限; 通信带宽约束lambda*=500→这是严重瓶颈→增加带宽或压缩数据。lambda*=0的约束→完全不用管。

Q: 为什么有时候对偶间隙不为零？
A: 1)Slater条件不满足(无严格可行点); 2)原问题非凸(如深度学习); 3)数值问题(求解器容差不够)。修复: 加微小松弛(slack变量)→创造严格可行点。

Q: 灵敏度分析如何指导硬件选型？
A: 在仿真中扫描各约束→生成"升级价值报告": lambda大的约束=瓶颈=优先升级。例: 计算带宽约束lambda*=100, 内存带宽lambda*=10→先升级计算单元。

5.6 扰动与灵敏度分析

📋 中文定义

考虑扰动问题：

$$\begin{aligned} \text{minimize} \quad & f_0(x) \\ \text{subject to} \quad & f_i(x) \le u_i,\; i=1,\ldots,m \\ & h_i(x) = v_i,\; i=1,\ldots,p \end{aligned}$$

定义 $p^*(u,v)$ 为扰动后的最优值（$u,v$ 是扰动向量）。

全局灵敏度：若强对偶成立且对偶最优解 $(\lambda^*,\nu^*)$ 在原问题处达到，则：

$$p^*(u,v) \ge p^*(0,0) - \lambda^{*T} u - \nu^{*T} v$$

即对偶变量 $\lambda_i^*$ 给出了"放松第 $i$ 个不等式约束"对最优值的边际改善率——这正是经济学中的影子价格(shadow price)。

若 $p^*$ 在 $(0,0)$ 处可微，则 $\nabla p^*(0,0) = (-\lambda^*, -\nu^*)$。

🔮 几何直觉

对偶变量 = 影子价格。$\lambda_i^*$ 告诉你：如果可以多"违反"第 $i$ 个约束一点（放松约束），最优值大约会改善多少。这非常直观——严格的约束"值钱"，宽松的约束"不值钱"（$\lambda_i^* = 0$）。

在工程设计中，这告诉你哪个约束是瓶颈——哪个约束的松弛能最大程度改善设计目标。

📖 公式解读 — $p^*(u,v) \ge p^*(0,0) - \lambda^{*T}u - \nu^{*T}v$ 说明了什么？
  • 拆解符号： $p^*(u,v)$ 是扰动后的最优值：约束放松了 $u$（不等式右边从0变为$u$）和 $v$（等式右边从0变为$v$）。$\lambda^*$ 和 $\nu^*$ 是原问题最优处的 Lagrange 乘子。
  • 通俗类比： 老板说"预算再给你 $u_i=10$ 万元"——你的最优成本大约降低 $\lambda_i^* \times 10$ 万。$\lambda_i^*$ 就是预算的影子价格——每多一元预算能省多少总成本。
  • 为什么重要： 这告诉你哪个约束是瓶颈。$\lambda_i^*=0$ → 约束完全宽松，再放松也没用。$\lambda_i^*$ 很大 → 这个约束死死限制了你，放松它能带来巨大改善。
  • 数值例子： $\min x^2$ s.t. $x\ge1$（重写为 $1-x\le0$）。$x^*=1, \lambda^*=2$。若放松为 $1-x\le0.1$（即 $x\ge0.9$）：新最优 $x^*=0.9$，最优值 $0.81$。原最优值 $1$。改善量 $0.19$。影子价格预测改善 $=\lambda^*\times0.1=2\times0.1=0.2$。近似成立！
🧠 一句话总结

对偶变量 = 影子价格 = 约束的边际价值。松弛一个严格约束对目标的改善程度由其对偶变量给出。

5.7 对偶例子

📘 LP对偶

原问题(LP)： $\min c^T x$ s.t. $Ax = b,\; x \succeq 0$

对偶问题： $\max -b^T \nu$ s.t. $A^T \nu + c \succeq 0$

LP的对偶也是LP。强对偶总是成立（如果问题可行）。这是线性规划对偶理论的经典结果。

📘 QP对偶

原问题： $\min \frac{1}{2}x^T P x + q^T x$ s.t. $Gx \preceq h,\; Ax = b$（$P \succ 0$）

Lagrange函数关于 $x$ 的最小化有解析解：$x^* = -P^{-1}(q + G^T \lambda + A^T \nu)$。代入得到对偶问题：

$$\max -\frac{1}{2}(q+G^T\lambda+A^T\nu)^T P^{-1}(q+G^T\lambda+A^T\nu) - \lambda^T h$$

s.t. $\lambda \succeq 0$。这是一个凹二次最大化问题（可以转化为凸问题求解）。

📘 熵最大化(Entropy Maximization)

原问题： $\max -\sum x_i \log x_i$ s.t. $Ax \preceq b,\; \mathbf{1}^T x = 1$（$x \succ 0$）

通过 Lagrange 对偶的解析处理，得到对偶问题为无约束最大化：$\max -b^T \lambda - \log\sum \exp(-a_i^T \lambda)$。这是 log-sum-exp 函数，是凸的（所以对偶问题是凸的）。

📘 SDP对偶

原问题： $\min c^T x$ s.t. $x_1 F_1 + \cdots + x_n F_n \preceq G$（SDP）

对偶问题： $\max \text{tr}(GZ)$ s.t. $\text{tr}(F_i Z) + c_i = 0,\; Z \succeq 0$

SDP对偶也是SDP。对偶问题的变量 $Z \in \mathbb{S}^k$ 是对应矩阵不等式的 Lagrange 乘子。

📘 例5.10 无套利价格界 (Boyd)

考虑 $n$ 个资产，价格 $p$，偿付矩阵 $V$。$\min c^T p$（最小化当前价格）s.t. $V^T p \succeq 0$（无套利），对偶给出了资产价格的上下界。这在金融数学中有重要应用。

📘 例5.11 SDP的Lagrange对偶 (Boyd)

原问题：$\min c^T x$ s.t. $F_0 + \sum x_i F_i \preceq 0$（线性目标 + LMI约束）。

Lagrange乘子是对称矩阵 $Z \succeq 0$，Lagrange函数 $L(x,Z) = c^T x + \text{tr}(Z(F_0 + \sum x_i F_i))$。对 $x$ 最小化得对偶 SDP：

$$\max \text{tr}(F_0 Z) \quad \text{s.t.} \quad \text{tr}(F_i Z) + c_i = 0,\; Z \succeq 0$$
📘 例5.7 不等式约束几何规划对偶 (Boyd)

GP 的对偶问题通过 log-sum-exp 的共轭函数来构建。原 GP 的 Lagrange 对偶是一个带有非负约束和线性约束的凹最大化问题。对偶变量对应原约束的对数灵敏度。

📘 例5.12 标准锥规划的对偶 (Boyd)

原问题：$\min c^T x$ s.t. $Fx + g \preceq_K 0$（$K$ 是正锥）。对偶：$\max g^T z$ s.t. $F^T z + c = 0,\; z \succeq_{K^*} 0$。LP、SOCP、SDP 的对偶都是这个统一形式的特例。

📘 例5.13 不等式形式SDP的对偶 (Boyd)

原 SDP：$\min c^T x$ s.t. $F_0 + \sum x_i F_i \preceq 0$。对偶 SDP：$\max \text{tr}(F_0 Z)$ s.t. $\text{tr}(F_i Z) + c_i = 0,\; Z \succeq 0$。这是 SDP 对偶的标准对，强对偶在 Slater 条件下成立。

🧠 一句话总结

LP、QP、SDP 的对偶问题都属于同类问题家族。对偶的构建遵循统一的 Lagrange 乘子规则。

5.8 择一定理

📋 中文定义

对偶理论给出了不等式系统的择一定理(Theorems of alternatives)：两个系统中的恰有一个有解。

Farkas引理（经典）：以下两个系统中恰有一个有解：

  1. $Ax \preceq 0,\; c^T x > 0$
  2. $A^T y + c = 0,\; y \succeq 0$

几何意义：要么存在一个向量与所有行向量 $a_i$ 夹角 $\ge 90^\circ$ 但与 $c$ 夹角 $< 90^\circ$，要么 $c$ 在行向量的负锥中。

严格线性不等式择一定理： $Ax \prec b$ 有解 $\iff$ 不存在 $\lambda \succeq 0, \lambda \neq 0$ 满足 $\lambda^T A = 0, \lambda^T b \le 0$。

🔮 几何直觉

择一定理是几何直观的：两个系统不能同时有解，因为如果它们同时有解，会导出矛盾（如 $0 < 0$）。它们之一有解是因为分离定理——不相交的凸集可以被超平面分离。

在优化中，择一定理提供了检验可行性/不可行性的工具，也是推导对偶关系的基础。

📘 例5.14 LMI可行性择一性 (Boyd)

以下两个系统恰有一个有解：

  1. $F(x) \succ 0$（严格 LMI 可行）
  2. $Z \succeq 0,\; Z \neq 0,\; \text{tr}(F_i Z) = 0,\; \text{tr}(F_0 Z) \le 0$

这是 SDP 版本的择一定理。第一个系统有解 $\iff$ 第二个系统无解。证明使用分离定理。

🧠 一句话总结

择一定理 = 两个不等式系统恰有一个有解。Farkas引理是最著名的例子，几何本质是分离定理。

5.9 广义不等式下的对偶

📋 中文定义

将标量不等式 $f_i(x) \le 0$ 推广为广义不等式：

$$\begin{aligned} \text{minimize} \quad & f_0(x) \\ \text{subject to} \quad & f_i(x) \preceq_{K_i} 0,\; i=1,\ldots,m \\ & h_i(x) = 0,\; i=1,\ldots,p \end{aligned}$$

其中 $\preceq_{K_i}$ 是由正锥 $K_i$ 定义的广义不等式。Lagrange乘子 $\lambda_i$ 变为属于对偶锥 $K_i^*$（$\lambda_i \succeq_{K_i^*} 0$）。

Lagrange函数：$L(x,\lambda_1,\ldots,\lambda_m,\nu) = f_0(x) + \sum \lambda_i^T f_i(x) + \sum \nu_i h_i(x)$（注意 $\lambda_i^T f_i(x)$ 是内积）。

弱对偶性成立（$g(\lambda,\nu) \le p^*$ 当 $\lambda_i \succeq_{K_i^*} 0$ 时）。强对偶性需要广义 Slater 条件。

🔮 几何直觉

这是对偶理论向高维/矩阵变量的自然推广。SDP 对偶就是典型例子：原问题约束是 $F(x) \preceq_{S_+} 0$，对偶变量 $Z \succeq 0$（在半正定锥中）。

关键区别：对偶变量不再是一个标量，而是一个向量（或矩阵），且需要属于对应对偶锥。

🧠 一句话总结

广义不等式下的对偶 = 将乘子提升为对偶锥中的向量。SDP对偶是最重要的实例。

📐 逐步演算 — 简单 QP 的 Lagrange 对偶

原问题：$\min\ x_1^2+x_2^2$ s.t. $x_1+x_2=1$。Lagrange 函数 $L(x,\nu)=x_1^2+x_2^2+\nu(x_1+x_2-1)$。

对 $x$ 求极小：$\partial L/\partial x_i=2x_i+\nu=0\Rightarrow x_i=-\nu/2$。代回得对偶函数 $g(\nu)=2\cdot(\nu^2/4)+\nu(-\nu-1)=-\nu^2/2-\nu$。最大化 $g$：$g'(\nu)=-\nu-1=0\Rightarrow\nu^\*=-1$, $g(-1)=1/2$。

原最优 $x^\*=(1/2,1/2)$, $p^\*=1/2 = d^\*$ → 强对偶成立，对偶给出了完全相同的最优值。

📐 完整演算 — KKT 条件

问题：$\min\ x_1^2+x_2^2$ s.t. $x_1\ge1$（即 $1-x_1\le0$）。KKT 四条件：

  • 原始可行：$1-x_1\le0$。
  • 对偶可行：$\lambda\ge0$。
  • 互补松弛：$\lambda(1-x_1)=0$。
  • 稳定性：$\nabla f+\lambda\nabla g=0\Rightarrow(2x_1-\lambda,\ 2x_2)=0$。

解：$x_2=0$;若 $\lambda>0$ 则 $x_1=1$（约束紧），$\lambda=2x_1=2\ge0$ ✓。故 $x^\*=(1,0)$, $\lambda^\*=2$, $p^\*=1$。约束起作用，影子价格 $\lambda^\*=2$。

📐 影子价格 (Shadow Price) 的具体含义

把约束写成 $g(x)\le u$，最优值 $p^\*(u)$ 是 $u$ 的函数。灵敏度定理：$\lambda^\*=-\dfrac{\partial p^\*}{\partial u}$。

承上例（约束 $x_1\ge1$ 即 $-x_1\le-1$，取 $u$ 为右端松弛）：放松约束让 $x_1$ 下限从 $1$ 降到 $0.9$，则 $p^\*$ 从 $1$ 约降到 $0.81$，减少约 $0.19\approx\lambda^\*\cdot0.1=2\cdot0.1$。即每放松 1 单位约束，目标改善约 $\lambda^\*$ 个单位——这就是"资源的边际价值/影子价格"。

📐 弱对偶 vs 强对偶：对偶间隙计算

弱对偶恒成立：$d^\*\le p^\*$，间隙 $p^\*-d^\*\ge0$。强对偶时间隙 $=0$。

非凸例(说明间隙)：组合问题最优 $p^\*=5$，其拉格朗日对偶可能只给 $d^\*=3$，间隙 $=2$，对偶给出了下界但不精确。

凸 + Slater 条件成立 → 强对偶 → 间隙 $=0$，对偶最优即原始最优。前面 QP 例中 $p^\*=d^\*=1/2$，间隙为 0，正是凸 + 仿射约束自动满足 Slater 的结果。

📕 补充 (5.1.6) — 共轭函数与 Lagrange 对偶的联系

当问题形如 $\min f_0(x)$ s.t. $Ax\preceq b,\ Cx=d$ 时，对偶函数可直接用共轭 $f_0^\*$ 表达：

$g(\lambda,\nu)=-b^T\lambda-d^T\nu-f_0^\*(-A^T\lambda-C^T\nu)$。

这说明"求对偶函数"本质上就是"求目标函数的共轭"。一旦算出 $f_0^\*$，各种线性约束下的对偶都能套用此公式，免去逐题做 $\inf_x L$ 的繁琐推导。

📕 补充 (5.2.3) — 强对偶与 Slater 条件细节

Slater 条件：存在严格可行点 $x$ 使所有不等式约束 $f_i(x)<0$ 严格成立（仿射约束只需 $\le$）。对凸问题，Slater 成立 $\Rightarrow$ 强对偶 $p^\*=d^\*$ 且对偶最优可达。

细化：若某些 $f_i$ 是仿射的，则它们不需要严格不等号（弱化 Slater）。等式约束 $Ax=b$ 要求 $b\in\operatorname{range}(A)$ 且严格可行点落在相对内部 $\operatorname{relint}\mathcal{D}$。线性规划即使无严格内点通常也保持强对偶（只要原始或对偶可行）。

🔧 工程实践

对偶在工程中的核心用途
  1. 下界计算（弱对偶）： 对偶函数值 $g(\lambda,\nu)$ 给出原问题最优值的下界。工程中：快速估算"至少需要多少资源"。
  2. 影子价格（灵敏度）： $\lambda_i^*$ = 第i个约束的"边际价值"。$\lambda_i^*=10$ → 放松约束1单位，目标改进约10单位。
  3. 分布式优化： 对偶分解可以将一个大问题分解为多个子问题并行求解（dual decomposition）。
  4. 停止准则： 原-对偶间隙 $f_0(x)-g(\lambda,\nu) \le \epsilon$ 给出解的精度的可验证证书。
🔧 实例：SVM的对偶（支持向量机）
# 原始问题 (凸): min ½||w||² + C·Σξᵢ  s.t. yᵢ(w·xᵢ+b) ≥ 1-ξᵢ, ξᵢ≥0
# 对偶问题 (凸): max Σαᵢ - ½ΣΣαᵢαⱼyᵢyⱼ(xᵢ·xⱼ)  s.t. 0≤αᵢ≤C, Σαᵢyᵢ=0
# 优势: 对偶只有N个变量(αᵢ), 且只需内积→可引入核技巧(Kernel trick)!

SVM利用了对偶将高维原始变量转化为低维对偶变量的技巧。对偶问题只需样本间的内积——这是核方法(Kernel Methods)可行的理论基础。
