第四章 凸优化问题

本章将凸集和凸函数的理论应用于优化问题本身。我们将学习优化问题的标准形式、凸优化问题的定义、最优性条件，以及最重要的凸优化问题家族：线性规划(LP)、二次规划(QP)、二阶锥规划(SOCP)、半正定规划(SDP)、几何规划(GP)。

4.1 优化问题

📋 标准形式

优化问题的标准形式：

$$\begin{aligned} \text{minimize} \quad & f_0(x) \\ \text{subject to} \quad & f_i(x) \le 0,\; i=1,\ldots,m \\ & h_i(x) = 0,\; i=1,\ldots,p \end{aligned}$$

其中 $x \in \mathbb{R}^n$ 是优化变量，$f_0$ 是目标函数，$f_i$ 是不等式约束，$h_i$ 是等式约束。问题的可行集为满足所有约束的 $x$ 的集合。

最优值 $p^* = \inf\{f_0(x) \mid f_i(x)\le0, h_i(x)=0\}$。最优解 $x^*$ 满足 $f_0(x^*) = p^*$。

🔮 几何直觉

优化问题就是在"允许的区域"（可行域）中寻找使目标函数值最小的点。形象地说：在一片带有围栏（约束）的地形（目标函数）中寻找最低的点。

✅ 关键概念
  • 上镜图形式(epigraph form)： $\min_{x,t} t \;\text{s.t.}\; f_0(x) \le t, f_i(x) \le 0, h_i(x)=0$。这直接将原问题转化为在 $(x,t)$ 空间中在约束集上最小化 $t$。
  • 无约束问题： $m=p=0$，即为 $\min_x f_0(x)$。
  • 可行问题(feasibility problem)： $f_0(x)=0$（常数），只关心是否存在可行点。
📘 例4.1 无约束优化 (Boyd)

$\min f_0(x)$ 其中 $x \in \mathbb{R}^n$（$m=p=0$）。凸函数的无约束优化问题也称凸优化。最优性条件简化为 $\nabla f_0(x^*)=0$。

例如 $\min \|Ax-b\|_2^2$（最小二乘）是典型的无约束凸优化问题。

📘 例4.2 箱约束 (Boyd)

$\min f_0(x)$ s.t. $l_i \le x_i \le u_i$（$x$ 每个分量有上下界）。箱约束是线性不等式（$x_i - u_i \le 0, l_i - x_i \le 0$），$2n$ 个约束。若 $f_0$ 凸，这是凸优化问题。

📘 例4.3 最小范数问题 (Boyd)

$\min \|x\|_2$ s.t. $Ax = b$（等式约束下找最小范数解）。等价于 $\min \frac{1}{2}\|x\|_2^2$ s.t. $Ax=b$（凸问题），有解析解 $x^* = A^T(AA^T)^{-1}b$。

📘 例4.1 无约束优化示例 (Boyd)

$x \in \mathbb{R}, \text{dom} f_0 = \mathbb{R}_{++}$:
• $f_0(x)=1/x$: $p^*=0$，无穷小但不可达。
• $f_0(x)=-\log x$: $p^*=-\infty$（无下界）。
• $f_0(x)=x\log x$: $p^*=-1/e$，在 $x^*=1/e$ 处唯一取得。

📘 例4.2 箱约束的标准形式 (Boyd)

$\min f_0(x)$ s.t. $l_i \le x_i \le u_i$。转换为标准形式：$l_i - x_i \le 0$（$n$ 个约束）和 $x_i - u_i \le 0$（$n$ 个约束），共 $2n$ 个不等式约束。

🧠 一句话总结

优化问题 = 目标函数 + 不等式约束 + 等式约束。这是数学优化的通用语言。

4.2 凸优化

📋 中文定义

一个优化问题是凸优化问题(convex optimization problem)，如果它满足：

  • 目标函数 $f_0$ 是凸的
  • 不等式约束函数 $f_1,\ldots,f_m$ 是凸的
  • 等式约束函数 $h_i(x) = a_i^T x - b_i$ 是仿射的

标准凸形式：

$$\begin{aligned} \text{minimize} \quad & f_0(x) \\ \text{subject to} \quad & f_i(x) \le 0,\; i=1,\ldots,m \\ & Ax = b \end{aligned}$$

其中各 $f_i$（包括 $f_0$）是凸函数。可行集是凸集（因为它是凸函数的下水平集与超平面之交）。

🔮 几何直觉

凸优化问题就是在凸的碗里找最低点。因为碗是凸的，局部最低点就是全局最低点（没有"假谷底"）。这是凸优化在实际中最强大的性质——梯度下降等局部方法可以保证全局最优。

关键性质：局部最优 ⇒ 全局最优。

📘 最优性条件 (Boyd §4.2.2-4.2.3)

对于可微的凸优化问题（无等式约束），$x^*$ 是最优解 当且仅当：

$$\nabla f_0(x^*)^T (y - x^*) \ge 0, \quad \forall y \in X$$

其中 $X$ 是可行集。几何解释：$-\nabla f_0(x^*)$ 是 $X$ 在 $x^*$ 处的支撑超平面的法向量。

对于无约束问题（$m=p=0$），最优性条件简化为：$\nabla f_0(x^*) = 0$。

❌ 常见错误

将非凸优化问题当作凸优化来求解。例如：$\min x_1 x_2$ 受限于 $x_1,x_2 \ge 0$——目标函数不是凸的（Hessian 不定），但可行集是凸的。使用梯度下降可能得到局部最优而非全局最优。

📘 例4.5 无约束二次优化 (Boyd)

$\min \frac{1}{2}x^T P x + q^T x + r$（$P \succ 0$）。最优性条件 $\nabla f_0 = Px^* + q = 0 \implies x^* = -P^{-1}q$。

📘 例4.6 解析中心 (Boyd)

$\min -\sum_{i=1}^m \log(b_i - a_i^T x)$（无约束，定义在 $\{x \mid a_i^T x < b_i\}$ 上）。目标函数是凸的（$-\log$ 复合仿射）。解称为多面体 $\{x \mid Ax \prec b\}$ 的解析中心(analytic center)，它是该多面体内部的"最中心"点。

📘 例4.4 部分变量受约束的二次最小化 (Boyd)

考虑 $\min \frac{1}{2}x^T P x + q^T x + r$ s.t. $x_i \ge 0, i=1,\ldots,k$。对不受约束的变量，最优性条件 $\nabla_i f_0(x^*)=0$；对受约束变量，$\nabla_i f_0(x^*) \ge 0$ 且 $x_i^* \nabla_i f_0(x^*) = 0$（互补松弛）。

🧠 一句话总结

凸优化 = 凸目标 + 凸不等式约束 + 仿射等式约束。局部最优 = 全局最优。

4.3 线性规划 (Linear Programming, LP)

📋 中文定义

线性规划的标准形式：

$$\begin{aligned} \text{minimize} \quad & c^T x + d \\ \text{subject to} \quad & Gx \preceq h \\ & Ax = b \end{aligned}$$

目标函数和所有约束函数都是仿射的（线性的）。可行集是多面体，因此是凸的。

LP 是最简单的凸优化问题——所有仿射函数既是凸的也是凹的。

🔮 几何直觉

LP 是在一个多面体（由线性不等式削出的凸多面体）上最小化一个线性函数。最优解总是出现在可行集的顶点上（因为线性函数的等值线是平行超平面，推到可行集边缘就是顶点）。

这是单纯形法(simplex method)工作的原理——在多面体的顶点之间移动。

✅ 经典 LP 例子
  1. 食谱问题(diet problem)：选择食物组合以最小化成本，同时满足营养要求。$\min c^T x$ s.t. $Ax \succeq b, x \succeq 0$。
  2. Chebyshev 逼近： $\min \max_{i} |a_i^T x - b_i|$ 可以转化为 LP。
  3. 线性分式规划(Linear-fractional programming)： $\min f_0(x)/(c^T x+d)$ 可以转化为 LP。
$$\text{minimize } c^T x \quad \text{s.t. } Gx \preceq h,\; Ax = b$$
📖 公式解读 — $\min c^T x$ s.t. $Gx \preceq h, Ax=b$ 为什么最优解一定在顶点？
  • $c^T x$ 的含义： $c$ 是一个方向向量，$c^T x$ 是该方向上的投影。固定 $c^T x = k$ 是一族平行超平面。最小化 $c^T x$ 就是把这族超平面沿 $-c$ 方向推，直到碰到可行集边缘。
  • 为什么在顶点： 线性函数没有"弯曲"——它的等值线是平的。你在多面体上把一个平面往一个方向推，它最后碰到的一定是某个角（顶点），而不是边上的某处。
  • 通俗类比： 你把一个相框（等值平面）从房间的西南角往东北方向推。相框首先碰到房间里哪个家具的角？答案一定是一个"尖角"（顶点），而不是光滑的曲面。
  • 数值例子： $\min -x_1-2x_2$ s.t. $x_1+x_2\le3, x_1\ge0, x_2\ge0$。三个顶点：$(0,0),(3,0),(0,3)$。代入目标：$0,-3,-6$。最优在 $(0,3)$——恰好是一个顶点。
📖 公式解读 — $\nabla f_0(x^*)^T(y-x^*)\ge0,\;\forall y\in X$ 到底在说什么？
  • 拆解符号： $\nabla f_0(x^*)$ 是目标函数在 $x^*$ 处的梯度（指向函数增大最快的方向）。$(y-x^*)$ 是从 $x^*$ 指向任意可行点 $y$ 的方向。
  • 通俗类比： 你站在碗底 $x^*$。往任何可行方向迈一步，海拔都只会上升（或不变）。如果你在某处可以往某个方向走一步让海拔下降，那你就还没到碗底。
  • 几何翻译： 梯度 $-\nabla f_0(x^*)$ 是可行集 $X$ 在 $x^*$ 处的支撑超平面法向量。如果你站在碗的最低处，碗壁在最低点处是平的支持的。
  • 无约束的特例： 若没有约束，条件退化为 $\nabla f_0(x^*)=0$——梯度为零。这就是一维时导数=0的推广。
  • 为什么重要： 这条不等式可以检验任意候选解是否真的是最优——是凸优化的"试金石"。对于非凸问题，梯度为零只是必要而非充分条件。
📖 公式解读 — 优化问题标准形式每部分代表什么？
  • $\min f_0(x)$： "我要最小化什么"——目标函数。$f_0$ 是你想让它尽量小的量，如成本、误差、能耗。
  • $f_i(x) \le 0$： "我不能超过的界限"——不等式约束。$f_i(x)\le0$ 定义了可行域的"围墙"。例如 $x_1-5\le0$ 意味着 $x_1\le5$。
  • $h_i(x)=0$： "必须恰好满足的条件"——等式约束。例如功率守恒 $P_{in}=P_{out}$、质量守恒等。注意：等式约束必须是仿射的才能保证凸性。
  • $p^* = \inf\{f_0(x)\mid\text{满足约束}\}$： 最优值。如果没有人能达到精确的最优值但可以无限接近，用 $\inf$。
  • 通俗类比： 你在一个围栏（不等式约束）里找最低点，同时必须站在指定的地砖上（等式约束）。围栏内的最低的那块地砖就是最优解。
  • 上镜图形式技巧： $\min_{x,t} t$ s.t. $f_0(x)\le t$ + 原约束。这引入了一个辅助变量 $t$，把目标函数"拉平"为线性函数——方便后续对偶推导。

📘 例4.7 Von Neumann增长模型 (Boyd)

考虑有 $n$ 个部门的经济体。$x_i$ 是第 $i$ 部门的产出。最大化增长率 $\alpha$，s.t. $\sum_i a_{ij} x_i \ge \alpha x_j$（部门 $j$ 有足够投入）。这是 LP（或等价的特征值问题）。

🧠 一句话总结

LP = 线性目标 + 线性约束。最优解在多面体的顶点处取得。计算高效的数学规划基石。

4.4 二次优化 (QP, QCQP, SOCP)

📋 中文定义

二次规划(QP - Quadratic Program)：

$$\begin{aligned} \text{minimize} \quad & \frac{1}{2}x^T P x + q^T x + r \\ \text{subject to} \quad & Gx \preceq h,\; Ax = b \end{aligned}$$

其中 $P \succeq 0$（$P$ 半正定）。目标函数是凸二次函数。

二次约束二次规划(QCQP)：在 QP 基础上增加二次约束 $\frac{1}{2}x^T P_i x + q_i^T x + r_i \le 0$，其中 $P_i \succeq 0$。

二阶锥规划(SOCP)：

$$\begin{aligned} \text{minimize} \quad & f^T x \\ \text{subject to} \quad & \|A_i x + b_i\|_2 \le c_i^T x + d_i,\; i=1,\ldots,m \\ & Fx = g \end{aligned}$$
🔮 几何直觉

QP 是在多面体上最小化一个抛物面（凸二次函数）。SOCP 允许二次约束，相当于要求在 $(A_i x + b_i, c_i^T x + d_i)$ 空间中的点落在二阶锥（冰淇淋锥）内。

重要性链：LP ⊂ QP ⊂ QCQP ⊂ SOCP ⊂ SDP。越后面的类越强大，但求解的计算成本也越高。

✅ 典型例子
  1. 最小二乘(Least-squares)： $\min\|Ax-b\|_2^2 = x^T A^T A x - 2b^T A x + b^T b$。这是一个 QP。
  2. 投资组合优化： $\min x^T \Sigma x$ s.t. $\mu^T x \ge R, \mathbf{1}^T x = 1, x \succeq 0$。风险最小化，是 QP（$\Sigma \succeq 0$）。
  3. 鲁棒最小二乘： $\min \|Ax-b\|_2 + \rho\|x\|_1$ 可以重写为 SOCP。
📘 例4.8 带损失风险约束的投资组合 (Boyd)

$\min - \mu^T x$ s.t. $x^T \Sigma x \le \sigma^2,\; \mathbf{1}^T x = 1,\; x \succeq 0$。线性目标（最大化收益），二次约束（风险预算），是 QCQP。

或其 SOCP 等价形式：$\min -\mu^T x$ s.t. $\|\Sigma^{1/2}x\|_2 \le \sigma,\; \mathbf{1}^T x = 1,\; x \succeq 0$。

📘 例4.8 带损失风险的投资组合 (Boyd)

$\min \mu^T x$ s.t. $x^T \Sigma x \le \sigma^2,\; \mathbf{1}^T x = 1,\; x \succeq 0$。这是线性目标 + 二次约束的 QCQP。等价 SOCP 形式：$\min \mu^T x$ s.t. $\|\Sigma^{1/2} x\|_2 \le \sigma$ 加线性约束。

🧠 一句话总结

QP = 凸二次目标 + 线性约束；SOCP = 二阶锥约束。它们是 LP 的自然推广，广泛用于工程和金融。

4.5 几何规划 (Geometric Programming, GP)

📋 中文定义

几何规划处理单项式(monomial)和正项式(posynomial)：

  • 单项式： $f(x) = c x_1^{a_1} x_2^{a_2} \cdots x_n^{a_n}$，其中 $c>0, a_i \in \mathbb{R}$，定义在 $\mathbb{R}^n_{++}$ 上。
  • 正项式： 多个单项式之和：$f(x) = \sum_{k=1}^K c_k x_1^{a_{1k}} \cdots x_n^{a_{nk}}$。

GP 的标准形式：

$$\begin{aligned} \text{minimize} \quad & f_0(x) \\ \text{subject to} \quad & f_i(x) \le 1,\; i=1,\ldots,m \\ & h_i(x) = 1,\; i=1,\ldots,p \end{aligned}$$

其中 $f_i$ 是正项式，$h_i$ 是单项式。通过变量变换 $x_i = e^{y_i}$，GP 可以转化为凸优化问题！

🔮 几何直觉

看似非凸的 GP 问题（正项式通常不是凸的）通过巧妙的对数变换可以变成凸的。这是因为 $\log(e^{y_1}+\cdots+e^{y_n})$ 是 log-sum-exp 函数——我们知道它是凸的。

这使得 GP 在工程设计中非常强大——许多工程设计问题自然地以 GP 的形式出现（如电路尺寸、机械设计）。

✅ 经典 GP 例子 (Boyd §4.5.4)
  1. 悬臂梁设计：确定分段梁的截面尺寸，最小化体积（材料成本），受限于应力、挠度等约束。所有约束都是正项式。
  2. 电路晶体管尺寸：确定晶体管宽度和长度，受限于增益、带宽约束。
  3. 最大化椭圆体体积：受限于线性不等式。可以通过 GP 或其对偶来解决。
转化公式： 令 $y_i = \log x_i$，则单项式变为 $c e^{a^T y}$，正项式变为 $\sum_k c_k e^{a_k^T y}$。 $$\text{GP} \xrightarrow{x_i = e^{y_i}} \text{凸优化问题}$$
🧠 一句话总结

GP 看起来非凸，但通过 log 变换可以转化为凸问题。在工程设计中广泛应用。

4.6 广义不等式约束

📋 中文定义

将广义不等式应用于优化约束，得到锥规划(conic programming)：

标准锥形式：

$$\begin{aligned} \text{minimize} \quad & c^T x \\ \text{subject to} \quad & Fx + g \preceq_K 0 \\ & Ax = b \end{aligned}$$

其中 $K$ 是一个正锥。当 $K$ 取不同形式时得到不同问题：

  • $K = \mathbb{R}^m_+$ → 线性规划 LP
  • $K = \{(x,t) \mid \|x\|_2 \le t\}$ → 二阶锥规划 SOCP
  • $K = \mathbb{S}^n_+$ → 半正定规划 SDP

半正定规划(SDP)：

$$\begin{aligned} \text{minimize} \quad & c^T x \\ \text{subject to} \quad & x_1 F_1 + \cdots + x_n F_n + G \preceq 0 \\ & Ax = b \end{aligned}$$

其中 $F_i, G \in \mathbb{S}^k$。这是线性矩阵不等式(LMI)约束。

🔮 几何直觉

锥规划统一了 LP、SOCP、SDP。它们都是在特定锥的"切片"上最小化线性函数。SDP 的可行集是一类特殊的凸集——它不是多面体，但仍然是凸的。

SDP 在控制理论中特别重要（Lyapunov 不等式、$H_\infty$ 控制、LMI 条件）。

✅ SDP 应用
  1. 矩阵范数最小化： $\min \|A(x)\|_2$ 可以写为 SDP。
  2. 特征值优化： $\min \lambda_{\max}(A(x))$ 是 SDP。
  3. 线性系统的镇定(Stabilization)：寻找反馈增益使闭环系统稳定是 SDP 问题。
  4. 图的最大割近似：Goemans-Williamson 算法使用 SDP 松弛。
📘 例4.9 最佳线性无偏估计 (Boyd)

设 $y = Ax + v$，$v$ 为零均值噪声，协方差 $E[vv^T] = I$。寻找矩阵 $B$ 使 $\hat{x} = By$ 是无偏的（$BA = I$）且最小化 $E[\|\hat{x}-x\|_2^2] = \text{tr}(BB^T)$。该问题可写为 SDP。

📘 例4.10 矩阵集合的最小上界 (Boyd)

给定 $A_i \in \mathbb{S}^n$，$i=1,\ldots,m$，寻找一个"最小"的对称矩阵 $X$ 满足 $X \succeq A_i$（即 $X \succeq A_i$ 对所有 $i$）。$\min \lambda_{\max}(X)$ s.t. $X \succeq A_i,\; \forall i$，可写为 SDP：$\min t$ s.t. $X \preceq t I,\; X \succeq A_i$。

📘 例4.10 矩阵集合的最小上界 (Boyd)

给定 $A_1,\ldots,A_m \in \mathbb{S}^n$，求最小化 $\lambda_{\max}(X)$ 满足 $X \succeq A_i$。SDP 形式：$\min t$ s.t. $X \preceq t I,\; X \succeq A_i,\; i=1,\ldots,m$。这是寻找一组矩阵的"最小公共上界"的凸优化方法。

🧠 一句话总结

LP ⊂ SOCP ⊂ SDP。锥规划用广义不等式统一考虑不同类型的凸约束。

4.7 向量优化

📋 中文定义

向量优化问题中，目标函数 $f_0: \mathbb{R}^n \to \mathbb{R}^q$ 是向量值的：

$$\begin{aligned} \text{minimize (w.r.t. } K) \quad & f_0(x) \\ \text{subject to} \quad & f_i(x) \le 0,\; i=1,\ldots,m \\ & h_i(x) = 0,\; i=1,\ldots,p \end{aligned}$$

用正锥 $K$ 定义"最小"（即 $\preceq_K$ 意义下的最小）。

Pareto 最优：$x^*$ 是 Pareto 最优（极小元），如果不存在可行点 $x$ 使 $f_0(x) \preceq_K f_0(x^*)$ 且 $f_0(x) \neq f_0(x^*)$——即无法在不损害其他目标的情况下改善某个目标。

标量化方法：取 $\lambda \succ_{K^*} 0$（在 $K^*$ 内部），求解 $\min \lambda^T f_0(x)$ 得到向量优化问题的 Pareto 最优解。

🔮 几何直觉

向量优化对应多目标优化——如同时最小化成本和最大化性能。Pareto 最优的意思是：在现有方案中没有"全面更优"的选择。

标量化的几何解释：取一个正的价格向量 $\lambda$，将所有目标加权求和，最小化这个加权和，得到的点在 Pareto 前沿上。通过改变权重 $\lambda$，可以扫描 Pareto 前沿。

✅ 应用
  1. 多目标投资组合：最大化期望收益同时最小化风险。
  2. 工程设计：最小化成本、最大化的强度，同时满足约束。
  3. 正则化回归：$\min \|Ax-b\|_2^2$ 和 $\|x\|_1$ 之间的权衡（LASSO 路径）。
🧠 一句话总结

向量优化 = 多目标优化。通过标量化（加权求和）将多目标转化为单目标凸优化。

🔧 工程实践

凸优化问题的建模流程
  1. 识别变量和参数： 哪些是可优化的（x），哪些是固定的（A,b,λ等）。
  2. 写出目标： 最小化成本/误差/风险 → min f₀(x)。确保f₀是凸的。
  3. 写出约束： 物理限制 → fᵢ(x)≤0（凸的）+ 线性等式Ax=b。
  4. 识别问题类型： LP/QP/SOCP/SDP/GP → 选择对应求解器。
  5. 验证与求解： CVXPY自动检查DCP规则 → 调用MOSEK/ECOS/SCS求解。
🔧 实例：投资组合优化 (Python + CVXPY)
import cvxpy as cp
n = 10  # 资产数量
mu = cp.Parameter(n)       # 期望收益
Sigma = cp.Parameter((n,n)) # 协方差矩阵
w = cp.Variable(n)          # 权重
risk = cp.quad_form(w, Sigma)  # w^T Σ w (凸二次)
ret = mu @ w                   # 期望收益 (线性)
constraints = [cp.sum(w) == 1, w >= 0, ret >= 0.05]
problem = cp.Problem(cp.Minimize(risk), constraints)
problem.solve()  # 自动选择 SOCP 求解器

输出：$w^*$ 是给定最低收益0.05下的最小风险投资组合。
