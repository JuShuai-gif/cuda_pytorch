第二章 凸集

凸集是凸优化的基本语言。掌握它意味着你能用"凸"的眼睛看世界——你会发现许多看似复杂的集合，本质上都是凸的。本章将带你从最简单的直线线段出发，逐步建立凸集、锥、保凸运算、广义不等式、分离定理直到对偶锥的完整框架。

💡 关键概念速查 — 这些话让抽象变具体

ℓ₂ 范数 ‖x‖₂ = √(∑xᵢ²)

就是"直线距离"。你家到公司的直线距离=√(Δx²+Δy²)。GPS导航说的"5公里"就是ℓ₂范数。
为什么叫ℓ₂："2"来自平方再开方。ℓ₂是唯一旋转不变的范数——你转个角度看，距离不变。

ℓ₁ 范数 ‖x‖₁ = ∑|xᵢ|

就是"曼哈顿距离"。你在方格街区开车——只能东西走再南北走，不能斜穿。总路程=|东-西|+|南-北|。
为什么重要：ℓ₁产生稀疏解——很多分量精确为0。这就是LASSO能自动选特征的原因。

ℓ∞ 范数 ‖x‖∞ = max|xᵢ|

就是"最差分量"。你的考试成绩=最低那科的分。短板效应——水桶容量由最短木板决定。
为什么重要：ℓ∞保证每个分量偏差都不超过最优值。Chebyshev逼近="公平对待每个点"。

凸集 = "没有坑的集合"

一句话：集合里随便选两点，整条直线都在里面。
凸的：圆形、正方形、整个空间、一条线段。
不凸的：月牙、五角星、圆环（中间有洞）。
为什么重要：凸可行域→局部最优=全局最优。

半正定矩阵 X⪰0

就是"矩阵版的非负数"。非负数a≥0→对所有正数w，a·w≥0。半正定矩阵X⪰0→对所有向量v，vᵀXv≥0。
通俗验证：2×2矩阵[[x,y],[y,z]]⪰0 ⇔ x≥0,z≥0,xz≥y²（类比：一维a≥0）。

对偶锥 K*

就是"能与K中所有向量友好相处的向量集"。K*= {y | y与K中每个x的内积≥0}。
形象理解：K是手电筒光束，K*是能看到整束光的方向。K越窄，K*越宽——互补关系。

2.1 仿射集合和凸集

2.1.1 直线与线段

📋 中文定义

给定两点 $x_1 \neq x_2 \in \mathbb{R}^n$，

  • 直线：集合 $\{y \mid y = \theta x_1 + (1-\theta)x_2,\; \theta \in \mathbb{R}\}$。即经过 $x_1$ 和 $x_2$ 的整条直线，$\theta$ 可取任意实数。
  • 线段：集合 $\{y \mid y = \theta x_1 + (1-\theta)x_2,\; \theta \in [0,1]\}$。即 $\theta$ 只能取 0 到 1 之间，构成 $x_1$ 和 $x_2$ 之间的所有点。

换句话说：线段是直线的"截断"——$\theta$ 从 $\mathbb{R}$ 约束到 $[0,1]$。

🔮 几何直觉

想象教室里的两个学生。连接他们的那条无限延伸的激光就是直线，而他们之间那段恰好触手可及的部分就是线段。如果把 $\theta$ 看作"配比旋钮"，旋到 0 就在 $x_1$，旋到 1 就在 $x_2$，旋到 0.5 就在中点。

✅ 典型例子
  1. $\mathbb{R}^2$ 中，$x_1=(0,0), x_2=(2,2)$，$\theta=0.3$ 给出点 $(0.6,0.6)$，位于线段之上。
  2. $\mathbb{R}^3$ 中，$x_1=(1,0,0), x_2=(0,1,0)$，所有 $\theta \in [0,1]$ 的点构成从 $(1,0,0)$ 到 $(0,1,0)$ 的线段。
❌ 反例

若限定 $\theta \in [0, 0.5]$，得到的是线段的一部分（从 $x_1$ 到中点），不包含完整的 $x_1$ 到 $x_2$ 之间的所有点。这不是通常意义下 $x_1$ 和 $x_2$ 之间的完整线段。

数学公式： $$ y = \theta x_1 + (1-\theta) x_2 = x_2 + \theta(x_1 - x_2) $$ 当 $\theta \in \mathbb{R}$ → 直线；当 $\theta \in [0,1]$ → 线段。
📖 公式解读 — 为什么 $y = \theta x_1 + (1-\theta)x_2$？
  • 拆解符号： $x_1$ 是起点，$x_2$ 是终点。$\theta$ 是一个旋钮——拧到 0 得到 $x_2$，拧到 1 得到 $x_1$，拧到 0.5 得到中点。
  • 通俗类比： 你和朋友各站在房间的两端。$\theta=0$ 你就在朋友的位置，$\theta=1$ 你就在自己的位置，$\theta=0.3$ 你走了从朋友到你之间 30% 的路程。
  • 为什么重要： 这是凸优化的"第一公式"。后面所有的仿射集、凸集、锥、凸函数都是对它做微调得到的——仿射集放开 $\theta$ 范围到 $\mathbb{R}$，凸集缩窄到 $[0,1]$。
  • 数值代入： $x_1=(2,3), x_2=(10,7)$，取 $\theta=0.25$：$y = 0.25\cdot(2,3) + 0.75\cdot(10,7) = (0.5+7.5,\; 0.75+5.25) = (8,6)$。你位于从 $(2,3)$ 到 $(10,7)$ 这条路上走了 25% 的位置。

2.1.2 仿射集合

📋 中文定义

集合 $C \subseteq \mathbb{R}^n$ 是仿射集合(affine set)，当且仅当：对任意 $x_1, x_2 \in C$ 和任意 $\theta \in \mathbb{R}$，有 $\theta x_1 + (1-\theta) x_2 \in C$。

等价定义：$C$ 是一个线性方程组的解集，即 $C = \{x \mid Ax = b\}$，其中 $A \in \mathbb{R}^{m \times n}, b \in \mathbb{R}^m$。仿射集合 = 线性方程组解集 = 子空间的平移。

🔮 几何直觉

仿射集合就是"平坦"的东西——直线、平面、超平面——它们不需要经过原点。你可以把它们想象成"子空间 + 位移"。例如，$y=2x+1$ 这条线不经过原点，所以它不是子空间，但它是仿射集合。用解集 $Ax=b$ 来看更直观：$b$ 就是平移量，$A$ 决定方向约束。

✅ 典型例子
  1. $\mathbb{R}^2$ 中直线 $3x_1 + 4x_2 = 5$，写成 $Ax=b$ 即 $[3\; 4]\begin{bmatrix}x_1\\x_2\end{bmatrix}=5$。
  2. $\mathbb{R}^3$ 中平面 $x_1 + x_2 + x_3 = 1$。
  3. $\mathbb{R}^n$ 中的单个点 $\{x_0\}$ 也是仿射集合（零维仿射子空间）。
❌ 反例

单位圆 $\{x \in \mathbb{R}^2 \mid x_1^2 + x_2^2 = 1\}$ 不是仿射集合。取 $x_1=(1,0), x_2=(0,1)$，在 $\theta=0.5$ 时得到 $(0.5,0.5)$，其模长为 $\sqrt{0.5} \neq 1$，不在圆上。圆是"弯的"——仿射必须是"平的"。

$$C = \{x \mid Ax = b\}$$
📖 公式解读 — $Ax=b$ 到底在说什么？
  • 拆解符号： $A$ 是一个 $m\times n$ 的矩阵（$m$ 个方程，$n$ 个未知数），$b$ 是常数向量。每一行 $a_i^T x = b_i$ 是一个线性方程。
  • 通俗类比： 你去超市买菜，买了 $x_1$ 斤西红柿和 $x_2$ 斤黄瓜。西红柿 3元/斤、黄瓜 4元/斤，总共花了 5元 → $3x_1+4x_2=5$。反过来，一切满足"总价=5元"的购买方案构成一条仿射直线。
  • 二维直觉： 一个方程 $a_1 x_1 + a_2 x_2 = b$ 就是平面上的直线；两个方程就是两条直线的交点（通常是一个点）；三个方程如果相容就是同一个点。
  • 为什么重要： 所有仿射集合都是 $Ax=b$ 的解集——这是仿射集与线性代数之间的桥梁。"子空间+平移" 这一本质也来自于此：先把 $b$ 移项得到零空间，再由 $b$ 做平移。

2.1.3 仿射维数与相对内部

📋 中文定义

仿射集合 $C$ 的仿射维数(affine dimension)定义为与其关联的子空间的维数。即若 $C = V + x_0$，$V$ 是子空间，则 $\text{affdim}(C) = \dim(V)$。

$C$ 的相对内部(relative interior)定义为：$\text{relint}(C) = \{x \in C \mid \exists \epsilon > 0,\; B(x,\epsilon) \cap \text{aff}(C) \subseteq C\}$。

简单说：在 $C$ 的仿射壳内部看，有点"胖"的地方就是相对内部。这解决了一个核心问题——很多凸集在 $\mathbb{R}^n$ 中没有内部（如 $\mathbb{R}^3$ 中的线段），但它们在自身仿射壳中总是有内部的。

🔮 几何直觉

想象 $\mathbb{R}^3$ 中的一张纸（2维仿射集合）。在 $\mathbb{R}^3$ 中这张纸没有"内部"——因为它太薄了，任何3维球都会戳穿它。但在纸张自身的2维世界里，它当然有内部。这就是相对内部的精髓——降维到集合自身所在的世界去看。

✅ 典型例子
  1. $\mathbb{R}^3$ 中的线段，仿射维数为 1，其相对内部是去掉两端点的线段。
  2. $\mathbb{R}^2$ 中的三角形内部（不含边界）仿射维数为 2，而边的仿射维数为 1。
❌ 反例

$\mathbb{R}^2$ 中的一个孤立点（一个单点集合）：其仿射维数为 0，相对内部就是该点自身。一个单点的相对内部不是"空心"的，因为它没有比你所在维度更低的空间来讨论"体积"。这显示了相对内部定义的微妙之处。

$$\text{relint}(C) = \{x \in C \mid \exists \epsilon > 0: B(x,\epsilon) \cap \text{aff}(C) \subseteq C\}$$

🎯 学完用途

降维后的流形学习、概率分布的支撑集分析、退化约束下的优化。理解"相对内部"是处理半正定规划(SDP)中严格可行点(Slater条件)的前提——SDP求解器依赖于此。

🧠 一句话总结

相对内部 = 在集合自身维度里看的"内部"。线段在3D里没有内部，但在自己的1D世界里，去掉端点就是内部。

📘 例2.2 (Boyd) R³中的正方形

考虑 R³ 中 (x₁,x₂)-平面上的正方形：

$$C = \{x \in \mathbb{R}^3 \mid -1 \le x_1 \le 1,\; -1 \le x_2 \le 1,\; x_3 = 0\}$$

其仿射壳为 $\text{aff}\;C = \{x \mid x_3=0\}$，仿射维数为 2。在 R³ 中 $C$ 的内部为空（int $C = \emptyset$），但相对内部为：

$$\text{relint}\;C = \{x \in \mathbb{R}^3 \mid -1 < x_1 < 1,\; -1 < x_2 < 1,\; x_3 = 0\}$$

相对边界（relative boundary） = 正方形的四条边框：$\{x \mid \max\{|x_1|,|x_2|\} = 1,\; x_3=0\}$

关键启示：内部(int)和相对内部(relint)的区别在于维度——正方形在3D中没有内部，但在它自己的2D平面中有相对内部。

2.1.4 凸集

📋 中文定义

集合 $C \subseteq \mathbb{R}^n$ 是凸集(convex set)，当且仅当：对任意 $x_1, x_2 \in C$ 和任意 $\theta \in [0,1]$，有 $\theta x_1 + (1-\theta) x_2 \in C$。

直观理解：集合内任意两点之间的线段完全包含在该集合中。没有"缺口"、没有"凹陷"、没有"洞"。

更一般地，对任意 $x_1,\ldots,x_k \in C$ 和 $\theta_i \ge 0, \sum \theta_i = 1$，凸组合 $\sum \theta_i x_i \in C$。

🔮 几何直觉

拿一只笔画一个集合——如果你能在里面随便选两个点，然后用直尺连接它们，而直尺上的每一点都还在集合里面——那这个集合就是凸的。凹进去的部分、孔洞、断开的区域都会破坏凸性。凸集就像一个"鼓胀的气球"——从任何角度打光，影子都是连续的，没有缺口。

✅ 典型例子
  1. $\mathbb{R}^n$ 本身、空集、单点集、直线、线段都是凸的。
  2. 任何仿射集合都是凸的（凸集推广了仿射集，把 $\theta \in \mathbb{R}$ 放宽为 $\theta \in [0,1]$）。
  3. 所有 Euclid 球 $\{x \mid \|x - x_c\|_2 \le r\}$ 是凸的。
  4. 概率单纯形 $\{x \mid x \ge 0,\; \mathbf{1}^T x = 1\}$ 是凸的。
❌ 反例

$\mathbb{R}^2$ 中的月牙形、五角星、圆环(annulus)、整数点集 $\mathbb{Z}^2$。它们都在内部存在"缺口"或"凹陷"，某些点对之间的线段会跑出集合。$S = \{0,1\} \subset \mathbb{R}$（只有两个端点），取 $x_1=0, x_2=1, \theta=0.5$ 得到 0.5，不在 $S$ 中，所以不凸。

凸组合的一般形式： $$ \sum_{i=1}^{k} \theta_i x_i,\quad \theta_i \ge 0,\; \sum_{i=1}^{k} \theta_i = 1 $$ 凸包(convex hull)：包含集合 $S$ 的所有凸组合的集合，记为 $\text{conv}(S)$。它是包含 $S$ 的最小凸集。
📖 公式解读 — 凸组合 $\sum \theta_i x_i$ 是什么意思？
  • 拆解符号： $\theta_i \ge 0$ 是权重（非负），$\sum\theta_i=1$ 是归一化条件。$x_i$ 是集合中的点。$\sum\theta_i x_i$ 就是这些点的"加权平均"。
  • 通俗类比： 把 $\theta_i$ 想象成你在 $x_i$ 这个地点停留的时间比例。如果你在 A 点 30% 时间、B 点 50% 时间、C 点 20% 时间，你的"等效位置"（加权平均）必须在凸集内部。
  • 几何验证法： 判断一个形状是否凸：拿一支笔随便选两个边界点，画一条线段——如果线段 全部在形状里面，就是凸的。凹进去的地方，线段会"飞出去"。
  • 数值例子： 矩形 $[0,2]\times[0,2]$ 取 $x_1=(0,0), x_2=(2,2), \theta=0.5$ → $(1,1)$ 在矩形内 ✓。但月牙形取 $x_1=(-1,0.5), x_2=(1,0.5), \theta=0.5$ → $(0,0.5)$ 在月牙外 ✗ → 不凸。

凸性是全局最优的保证。在深度学习（损失函数设计）、投资组合（风险最小化）、通信（功率分配）中，只有凸问题才能保证梯度下降找到的局部解就是全局最优。非凸问题需要凸松弛（如压缩感知的ℓ₁松弛）。

2.1.5 锥

📋 中文定义

集合 $C$ 是锥(cone)，当且仅当：对任意 $x \in C$ 和任意 $\theta \ge 0$，有 $\theta x \in C$。即 从原点出发的射线完全包含在集合中。

集合 $C$ 是凸锥(convex cone)，当且仅当：对任意 $x_1, x_2 \in C$ 和任意 $\theta_1, \theta_2 \ge 0$，有 $\theta_1 x_1 + \theta_2 x_2 \in C$。即 "既是凸的，也是锥"。等价条件是：包含其元素的所有非负线性组合。

🔮 几何直觉

锥就像一个手电筒的光束——从原点（或顶点）射出去，光束内的任何方向你都可以沿着它走任意远，而且还在光束里。如果两束光叠加后还在光束内，那就是凸锥。日常生活中，冰淇淋的锥形蛋卷就是典型的凸锥外形。

另一个重要直觉：凸锥同时是锥和凸集——把两条射线之间的扇形区域全部填满。

✅ 典型例子
  1. 第一象限 $\mathbb{R}^2_+ = \{x \mid x_1 \ge 0, x_2 \ge 0\}$ 是凸锥。
  2. 半正定锥 $\mathbb{S}^n_+$（所有 $n \times n$ 半正定对称矩阵的集合）。
  3. 范数锥 $\{(x,t) \mid \|x\| \le t\} \subseteq \mathbb{R}^{n+1}$（二阶锥，也叫冰淇淋锥）。
  4. 原点、整个空间、任意经过原点的射线都是锥（但不一定是凸锥）。
❌ 反例

由两条不同方向的射线组成的"×"形（x轴和y轴）：它关于原点缩放是闭合的（是锥），但取 $x_1=(1,0)$ 和 $x_2=(0,1)$ 的锥组合 $1\cdot(1,0) + 1\cdot(0,1) = (1,1)$ 在第一象限，不在坐标轴上。所以它是锥，但不是凸锥。这说明"锥"和"凸锥"是不同的概念。

$$\theta_1 x_1 + \theta_2 x_2 \in C,\; \forall \theta_1,\theta_2 \ge 0$$
📖 公式解读 — $\theta x$ 和 $\theta_1 x_1 + \theta_2 x_2$ 分别意味着什么？
  • 锥的定义 $\theta x \in C$（$\theta\ge0$）： 意思是：你在锥里找到一条射线，沿着它你随便走多远（$\theta$ 放大任意倍），永远还在锥里。不是锥的集合——走太远就"出界"了。
  • 凸锥的定义 $\theta_1 x_1 + \theta_2 x_2 \in C$： 在锥的基础上要求"两条射线之间的扇形区域也都填满"。取两条射线各选一点，用任意非负系数组合——得到的点还得在锥内。
  • 通俗类比： 手电筒的光束是锥——光束里的任何方向你都可以走无限远。如果两个光束重叠后还在原光束内，就是凸锥。如果你把手电筒的光做成十字形（×），光在 x 轴和 y 轴上——但组合 $(1,1)$ 不在十字上，所以 x 轴+y 轴是锥但不是凸锥。
  • 数值例子： 第一象限 $\{x\mid x_1\ge0,x_2\ge0\}$：取 $(1,0)$ 放 3 倍 → $(3,0)$ 还在；取 $(0,2)$ 放 0.5 倍 → $(0,1)$ 还在；组合 $2\cdot(1,0)+3\cdot(0,2) = (2,6)$ 还在 ✓。所以第一象限是凸锥。

2.2.1 超平面与半空间

📋 中文定义

超平面(hyperplane)：集合 $\{x \mid a^T x = b\}$，其中 $a \in \mathbb{R}^n, a \neq 0, b \in \mathbb{R}$。它是 $n-1$ 维仿射集合，法向量为 $a$，截距为 $b$。

（闭）半空间(halfspace)：集合 $\{x \mid a^T x \le b\}$。超平面把空间"劈"成两半，$a^T x \le b$ 取了其中一半（包括边界）。开半空间：$\{x \mid a^T x < b\}$（不含边界）。

🔮 几何直觉

在二维平面中，超平面是一条直线；在三维中是一个平面。法向量 $a$ 就像垂直于这个平面的"箭头"——它指向 $a^T x > b$ 那一侧。$a^T x \le b$ 的半空间就是法向量"背对"的那一半（按不等式方向）。
超平面 = 刀，半空间 = 被刀切开的一半西瓜。

✅ 典型例子
  1. $\mathbb{R}^2$: $2x_1 + 3x_2 = 5$ 是一条直线（1维超平面）；$2x_1 + 3x_2 \le 5$ 是下半平面。
  2. $\mathbb{R}^3$: $x_1 - x_2 + 2x_3 = 4$ 是一个平面（2维超平面）；不等式形式给出一个半空间。
  3. 非负象限 $\{x \mid x_i \ge 0,\; i=1,\ldots,n\}$ 是 $n$ 个半空间 $\{-e_i^T x \le 0\}$ 的交集。
❌ 反例

由曲线 $x_1^2 + x_2^2 \le 1$ 定义的集合不是半空间——因为它的"切面"不是直线，而是弯曲的。只有线性不等式才定义半空间。

$$\text{超平面: } a^T x = b \qquad \text{半空间: } a^T x \le b$$
📖 公式解读 — $a^T x = b$ 为什么叫"超平面"？
  • 拆解符号： $a$ 是法向量（垂直于超平面的方向），$x$ 是空间中的点，$b$ 是一个标量（截距）。$a^T x = a_1 x_1 + \cdots + a_n x_n$ 是内积。
  • 二维直觉（$a_1 x_1 + a_2 x_2 = b$）： 在纸上画一条直线——$a=(a_1,a_2)$ 是垂直于这条直线的一个箭头，$b$ 决定了直线离原点"多远"。如果改变 $b$ 而保持 $a$ 不变，直线平行移动。
  • $a^T x \le b$ 的半空间： 不等式 $\le$ 取了超平面的"一侧"。判断哪一侧的方法：把原点代入——若 $a^T 0 \le b$（即 $0\le b$），则原点在被选中的那一侧。
  • 为什么重要： 半空间是凸优化的"原子"——每个凸集都可以写成（无限多个）半空间的交集。多面体是有穷多个半空间的交。理解半空间 = 理解一切凸约束的起点。

2.2.2 Euclid球和椭球

📋 中文定义

Euclid球(Euclidean ball)：$B(x_c, r) = \{x \mid \|x - x_c\|_2 \le r\} = \{x_c + r u \mid \|u\|_2 \le 1\}$。中心 $x_c$，半径 $r > 0$。

椭球(ellipsoid)：$\mathcal{E} = \{x \mid (x - x_c)^T P^{-1} (x - x_c) \le 1\}$，其中 $P \in \mathbb{S}^n_{++}$（对称正定矩阵）。等价地，$\mathcal{E} = \{x_c + A u \mid \|u\|_2 \le 1\}$，其中 $A$ 非奇异方阵且 $P = AA^T$。

椭球 = 球经过线性变形（旋转+拉伸）后的结果。

🔮 几何直觉

球是对称的、完美的"圆胖"。矩阵 $P$ 的特征值决定了椭球各轴的长度（$\sqrt{\lambda_i}$），特征向量决定各轴的方向。把球想象成面团，$A$ 就是你可以朝不同方向拉伸/压缩它的变换。正定性保证它不会退化成一个扁平的面。

✅ 典型例子
  1. $\mathbb{R}^2$ 中单位圆盘 $B(0,1) = \{x \mid x_1^2 + x_2^2 \le 1\}$（$P=I, r=1$）。
  2. $\mathbb{R}^2$ 中椭球 $\{(x_1,x_2) \mid 4x_1^2 + x_2^2 \le 1\}$，$P = \text{diag}(1/4, 1)$，沿着 $x_1$ 方向被拉伸。
  3. $\mathbb{R}^n$ 中，任何对称正定矩阵 $P$ 定义的椭球都是凸的。
❌ 反例

若 $P$ 只是半正定（奇异矩阵），则椭球在某个方向退化为零长度（变成低维椭球，甚至线段）。在退化方向上，仿射维数下降。更关键的是，如果 $P$ 不是正定的（比如不定矩阵），集合 $\{x \mid (x-x_c)^T P^{-1}(x-x_c) \le 1\}$ 甚至不再有界——变成双曲面的一部分——不再是凸集。

$$\mathcal{E} = \{x \mid (x-x_c)^T P^{-1}(x-x_c) \le 1\},\; P \succ 0$$

2.2.3 范数球和范数锥

📋 中文定义

设 $\|\cdot\|$ 是 $\mathbb{R}^n$ 上的范数（不必是Euclid范数）。

  • 范数球(norm ball)：$\{x \mid \|x - x_c\| \le r\}$。
  • 范数锥(norm cone)：$C = \{(x, t) \in \mathbb{R}^{n+1} \mid \|x\| \le t\}$。也称为二阶锥(second-order cone)或冰淇淋锥(ice-cream cone)。

常见的 $\ell_p$ 范数：$\|x\|_p = (\sum |x_i|^p)^{1/p}$ 对于 $p \ge 1$；$\|x\|_\infty = \max_i |x_i|$。

🔮 几何直觉

$\ell_1$ 范数球在2D是菱形、在3D是八面体；$\ell_2$ 范数球是圆/球；$\ell_\infty$ 范数球是正方形/立方体。它们的样子体现了不同"距离"度量下的"单位球"。

范数锥 $(x,t)$ 的几何解释：在 $(n+1)$ 维空间中，以 $t$ 为垂直轴，所有满足 $\|x\| \le t$ 的点构成一个圆锥体（像冰淇淋蛋筒），顶点在原点。为什么叫二阶锥？因为 $\|x\|_2 \le t \iff x^T x \le t^2$（二次不等式）。

✅ 典型例子
  1. $\ell_2$ 范数锥 $\{(x,t) \in \mathbb{R}^3 \mid \sqrt{x_1^2+x_2^2} \le t\}$——这是经典的3D冰淇淋蛋筒，在凸优化中大量用到（二阶锥规划 SOCP）。
  2. $\ell_1$ 范数球在 $\mathbb{R}^3$ 中是一个正八面体。
  3. $\ell_\infty$ 范数球在 $\mathbb{R}^2$ 中是一个边与坐标轴平行的正方形。
❌ 反例

$p < 1$ 时的 $\ell_p$ "范数球"（如 $\ell_{0.5}$）：集合 $\{x \mid (\sum |x_i|^{0.5})^2 \le 1\}$ 不是凸的，因为它生成的是内凹的星形。只有 $p \ge 1$ 时 $\ell_p$ 范数才满足三角不等式，此时范数球和范数锥才是凸的。

$$\|x\|_p = \left(\sum |x_i|^p\right)^{1/p},\; p \ge 1$$

2.2.4 多面体

📋 中文定义

多面体(polyhedron) 定义为有限个线性不等式和等式的交集的解集：

$$ \mathcal{P} = \{x \mid a_i^T x \le b_i,\; i=1,\ldots,m,\; c_j^T x = d_j,\; j=1,\ldots,p\} $$

等价表示为 $\mathcal{P} = \{x \mid Ax \preceq b,\; Cx = d\}$。多面体是半空间和超平面的交。它是凸的（半空间和超平面的交集保持凸性）。

有界多面体也被称为多胞形(polytope)——可以看作是有限个点凸包的结果。

🔮 几何直觉

多面体就是"用平面切出来的形状"。在2D中是多边形（三角形、矩形等），在3D中是多面体（立方体、棱锥等）。每条不等式 $a_i^T x \le b_i$ 都是一把刀，把空间削掉一半；$c_j^T x = d_j$ 是把解约束到一个超平面上。所有刀切剩下的共同部分就是多面体。

✅ 典型例子
  1. $\mathbb{R}^2$ 中的单位正方形：$\{x \mid -1 \le x_1 \le 1,\; -1 \le x_2 \le 1\}$（4个不等式）。
  2. 概率单纯形：$\{x \mid x \ge 0,\; \sum x_i = 1\}$（$n$ 个不等式 + 1个等式）。
  3. 非负象限：$\{x \mid x \ge 0\}$（$n$ 个不等式，是多面体但无界）。
❌ 反例

Euclid球 $\{x \mid \|x\|_2 \le 1\}$ 不是多面体——它由无限个"切面"构成（你需要无穷多个半空间才能精确描述它）。正定锥也不是多面体。实际上，可以用多面体来逼近这些曲面集合，但永远无法精确等于。

$$\mathcal{P} = \{x \mid Ax \preceq b,\; Cx = d\}$$

📘 例2.5 单纯形 (Boyd)

设 $k+1$ 个点 $v_0,\ldots,v_k \in \mathbb{R}^n$ 仿射独立（即 $v_1-v_0,\ldots,v_k-v_0$ 线性无关）。它们确定的单纯形(simplex)为：

$$C = \text{conv}\{v_0,\ldots,v_k\} = \{\theta_0 v_0 + \cdots + \theta_k v_k \mid \theta \succeq 0,\; \mathbf{1}^T\theta = 1\}$$

单纯形的仿射维数是 $k$，称为 $\mathbb{R}^n$ 中的 $k$ 维单纯形。

常见单纯形：1维→线段；2维→三角形（含内部）；3维→四面体

单位单纯形（由 $0, e_1, \ldots, e_n$ 确定）：$\{x \mid x \succeq 0,\; \mathbf{1}^T x \le 1\}$

概率单纯形（由 $e_1,\ldots,e_n$ 确定）：$\{x \mid x \succeq 0,\; \mathbf{1}^T x = 1\}$

概率单纯形是 $(n-1)$ 维的，其中向量对应 $n$ 个元素的概率分布。

2.2.5 半正定锥

📋 中文定义

$\mathbb{S}^n$ 表示所有 $n \times n$ 实对称矩阵的集合（维数为 $n(n+1)/2$）。

  • $\mathbb{S}^n_+ = \{X \in \mathbb{S}^n \mid X \succeq 0\}$ 是半正定锥(positive semidefinite cone)。
  • $\mathbb{S}^n_{++} = \{X \in \mathbb{S}^n \mid X \succ 0\}$ 是正定锥(positive definite cone)（$\mathbb{S}^n_+$ 的相对内部）。

$\mathbb{S}^n_+$ 是凸锥。$X \succeq 0 \iff$ 所有特征值 $\ge 0$。

🔮 几何直觉

对于最简单的 $n=2$ 的情况，对称矩阵可参数化为 $X = \begin{bmatrix} x & y \\ y & z \end{bmatrix}$。$X \succeq 0$ 等价于 $x \ge 0, z \ge 0, xz \ge y^2$。这在 $(x,y,z)$ 空间中是一个实心的抛物面区域——像一个被曲面包裹的锥形。它从原点出发，截面是椭圆。

关键直觉：半正定锥把矩阵的"正定性"这个概念可视化了。在 $(x,y,z)$ 坐标中，边界是 $xz = y^2$（抛物面），内部是 $xz > y^2$。

✅ 典型例子
  1. $2 \times 2$ 单位矩阵 $\begin{bmatrix}1&0\\0&1\end{bmatrix} \in \mathbb{S}^2_{++}$（$(x,z)=(1,1), y=0$，在锥内部）。
  2. $2 \times 2$ 半正定边界矩阵 $\begin{bmatrix}1&1\\1&1\end{bmatrix} \in \mathbb{S}^2_+$（特征值 2 和 0，在锥的边界上）。
  3. 对角矩阵集合 $\{X = \text{diag}(\lambda_1,\ldots,\lambda_n) \mid \lambda_i \ge 0\}$ 是 $\mathbb{S}^n_+$ 的一个子集（$n$ 维非负象限嵌入）。
❌ 反例

矩阵 $\begin{bmatrix}1&2\\2&1\end{bmatrix}$ 不是半正定的（其特征值 $3$ 和 $-1$，有一个负的）。在 $(x,y,z)$ 空间中对应 $(1,2,1)$，代入条件 $xz \ge y^2 \to 1\cdot 1 \ge 4$ 不满足，所以它在锥外部。不定矩阵对应在锥外，负定矩阵在"相反的"锥中。

$$\mathbb{S}^n_+ = \{X \in \mathbb{S}^n \mid X \succeq 0\}$$
📖 公式解读 — $X = \begin{bmatrix}x&y\\y&z\end{bmatrix} \succeq 0$ 到底是什么意思？
  • 拆解条件： $x \ge 0$（左上角非负），$z \ge 0$（右下角非负），$xz \ge y^2$（行列式非负）。三个条件缺一不可。
  • 通俗类比： 想象旋转抛物面：条件 $xz = y^2$ 是这个抛物面的曲面，$xz > y^2$ 是曲面内部（正定），$xz < y^2$ 是曲面外部（不定/负定）。
  • 数值验证： $X = \begin{bmatrix}4&2\\2&1\end{bmatrix}$：$x=4\ge0✓, z=1\ge0✓, xz=4\ge y^2=4✓$ → 半正定，在锥的边界上。$X = \begin{bmatrix}4&3\\3&1\end{bmatrix}$：$xz=4 < y^2=9✗$ → 不在锥内。
  • 为什么重要： 这 3 个不等式给出了 $2\times2$ 半正定锥的完整解析描述。它是理解 SDP（半正定规划）约束的最简入口。高维 PSD 锥虽然没有这么简单的显式描述，但直觉完全相同。

📖 多层公式解读 —— 为什么仿射变换保凸而非线性变换不保凸
第1层：仿射=直线→直线

f(x)=Ax+b把直线映射为直线(或点)。凸集中任意两点的线段→仿射后仍为线段→仍在像集中。所以像保持凸性。旋转、缩放、平移都不产生"弯曲"。

第2层：非线性=直线→曲线

g(x)=(x,x²)把直线上的点映射到抛物线上。线段[-1,1]映射为抛物线弧——弦脱离弧(在弧上方)→像不是凸的。这就是为什么非线性激活函数(ReLU/Sigmoid)不保凸。

第3层：工程意义

坐标变换(机器人关节↔世界)如果仿射→凸问题保持凸。但前向运动学不是仿射→IK比FK难。数据预处理(标准化=仿射)不破坏凸性→可以安全使用。

2.3 保凸运算

2.3.1 交集

📋 中文定义

若 $S_\alpha$（$\alpha \in \mathcal{A}$）是一族凸集，则它们的交集 $\bigcap_{\alpha \in \mathcal{A}} S_\alpha$ 也是凸集。

这是最重要的保凸运算——没有之一。几乎所有凸集的构造（多面体、范数球等）都可以追溯到交集运算。

🔮 几何直觉

想象几个透明的凸形塑料片叠在一起——它们重合的部分就是交集。如果原来每片塑料片里的任意两点之间的线段都在该塑料片内部，那么在所有重合区域里，这条线段自然也同时在所有塑料片里。因此交集保持了凸性。

如果一个集合能写成 $\bigcap$ 一堆简单凸集，那它自己也是凸的。这就是证明凸性的"交集大法"。

✅ 典型例子
  1. 多面体 = 有限个半空间 $\cap$ 有限个超平面的交集 → 凸。
  2. 概率单纯形 = 非负象限 $\cap$ 归一化超平面 → 凸。
  3. 范数球可以看作多个凸集的交集。
❌ 反例

两个凸集的并集通常不凸。例如两个不相交的圆的并集是"哑铃形"——取一个圆内的一点和另一个圆内的一点的线段就会经过两圆之间的空白区域。并集只在特殊情况下凸（如嵌套关系 $S_1 \subseteq S_2$）。

$$\bigcap_{\alpha \in \mathcal{A}} S_\alpha \text{ 是凸的, 若每个 } S_\alpha \text{ 是凸的}$$

任意多个凸集的交集仍然是凸集（凸性证明的"万能钥匙"）。但并集一般不行。

📘 例2.7 半正定锥的无公共交集表示 (Boyd)

半正定锥 $\mathbb{S}^n_+$ 可以表示为无穷多个半空间的交集：

$$\mathbb{S}^n_+ = \bigcap_{z \neq 0} \{X \in \mathbb{S}^n \mid z^T X z \ge 0\}$$

对每一个 $z \neq 0$，$z^T X z$ 是 $X$ 的一个（非恒零的）线性函数，因此 $\{X \in \mathbb{S}^n \mid z^T X z \ge 0\}$ 是 $\mathbb{S}^n$ 中的一个半空间。半正定锥是无穷多个半空间的交，因此是凸的。

核心意义：这不是多面体（因为需要无穷多个半空间来描述），但仍然是凸的——交集保持凸性无论交多少集合。

2.3.2 仿射函数

📋 中文定义

设 $f: \mathbb{R}^n \to \mathbb{R}^m$ 是仿射函数，即 $f(x) = Ax + b$，其中 $A \in \mathbb{R}^{m \times n}, b \in \mathbb{R}^m$。

  • 若 $S \subseteq \mathbb{R}^n$ 是凸集，则 $f(S) = \{Ax+b \mid x \in S\}$ 也是凸集（像保持凸性）。
  • 若 $T \subseteq \mathbb{R}^m$ 是凸集，则 $f^{-1}(T) = \{x \mid Ax+b \in T\}$ 也是凸集（原像保持凸性）。

仿射变换包括：平移、旋转、缩放、投影、剪切——它们是空间中最"温和"的变形。

🔮 几何直觉

把凸集想象成橡胶印章。仿射变换就像平动、转动、均匀或非均匀缩放这块橡胶——它可能拉长、压扁、旋转，但不会产生凹陷或撕裂。印章上的凸图案变形后仍然是凸图案。

直观法则：仿射函数 = 保持"凸性DNA"的变换。

✅ 典型例子
  1. 将正方形旋转 45° 得到菱形——仍是凸的。
  2. 椭球 = 单位球的仿射像（$x \mapsto P^{1/2}x + x_c$）。
  3. 多面体 $\{x \mid Ax \preceq b\}$ 是仿射函数 $x \mapsto Ax$ 对非负象限 $\{y \mid y \preceq b\}$ 的原像。
❌ 反例

非线性变换（如 $f(x) = x^2$）不保持凸性。$f(x) = (x, x^2)$ 把凸集 $[-1,1]$ 映射到抛物线弧——这个弧不是凸集（因为弧形是弯的，两点间线段会落在弧的上方之外）。

$$f(x) = Ax + b,\quad S\text{ 凸} \Rightarrow f(S)\text{ 凸},\quad T\text{ 凸} \Rightarrow f^{-1}(T)\text{ 凸}$$

仿射变换 $Ax+b$ 同时保持凸集的像和原像的凸性。凸集被仿射变换后仍然是凸的。

📘 例2.9 多面体 = 非负象限的原像 (Boyd)

多面体 $\{x \mid Ax \preceq b,\; Cx = d\}$ 可以写为仿射函数 $f(x) = (b-Ax,\; d-Cx)$ 对 $\mathbb{R}^m_+ \times \{0\}$ 的原像：

$$\{x \mid Ax \preceq b,\; Cx = d\} = \{x \mid f(x) \in \mathbb{R}^m_+ \times \{0\}\}$$

因为 $\mathbb{R}^m_+ \times \{0\}$ 是凸的，且仿射原像保持凸性，所以多面体是凸的。这种表达方式统一了多面体的凸性证明。

📘 例2.10 线性矩阵不等式(LMI) (Boyd)

条件 $A(x) = x_1 A_1 + \cdots + x_n A_n \preceq B$，其中 $B, A_i \in \mathbb{S}^m$，称为 $\mathbb{R}^n$ 上的线性矩阵不等式(LMI)。

解集 $\{x \mid A(x) \preceq B\}$ 是凸集。因为它是对正半定锥 $\mathbb{S}^m_+$ 在仿射函数 $f(x) = B - A(x)$ 下的原像：

$$\{x \mid A(x) \preceq B\} = \{x \mid B - A(x) \in \mathbb{S}^m_+\} = f^{-1}(\mathbb{S}^m_+)$$

LMI 是 半正定规划(SDP) 的核心约束形式。

📘 例2.12 椭球 = 单位球的仿射像 (Boyd)

椭球 $\mathcal{E} = \{x \mid (x-x_c)^T P^{-1}(x-x_c) \le 1\}$（$P \succ 0$）是单位 Euclid 球

$$\{u \mid \|u\|_2 \le 1\}$$

在仿射映射 $f(u) = P^{1/2}u + x_c$ 下的像。由于仿射映射的像保持凸性，因此椭球是凸的。同时，它也是单位球在仿射映射 $g(x) = P^{-1/2}(x - x_c)$ 下的原像，这也证明了凸性。

2.3.3 线性分式及透视函数

📋 中文定义

透视函数(perspective function)：$P: \mathbb{R}^{n+1} \to \mathbb{R}^n$，定义为 $P(z, t) = z/t$，其中 $\text{dom} P = \{(z,t) \mid t > 0\}$。它将 $(n+1)$ 维空间映射到 $n$ 维。

线性分式函数(linear-fractional function)：$f(x) = \frac{Ax+b}{c^T x + d}$，其中 $\text{dom} f = \{x \mid c^T x + d > 0\}$。它可以分解为仿射变换 + 透视函数：先做仿射映射 $(Ax+b,\; c^T x + d)$ 到 $\mathbb{R}^{n+1}$，再应用透视函数。

线性分式函数保持凸性——它将凸集映射为凸集。

🔮 几何直觉

透视函数就像针孔相机成像：3D世界的物体通过小孔投影到2D胶片上。$(z,t)$ 是物体在3D中的坐标，投影到 $z/t$ 的2D平面上。$t$ 是"深度"——深度越大，投影越靠近原点。远处的大物体 → 投影成一个点。这就是为什么铁轨在远处汇聚。

线性分式函数则进一步允许先进行仿射变换（旋转、平移、缩放）再透视投影。最终效果是凸集依然凸——针孔相机不会把凸物体扭曲成非凸图像。

✅ 典型例子
  1. 函数 $f(x) = \frac{1}{x}$ 在 $(0,\infty)$ 上是线性分式函数（一维情况 $c=1, d=0, A=0, b=1$）。它将凸区间映射为凸区间。
  2. $\mathbb{R}^3$ 中的单位立方体经过透视函数映射到 $\mathbb{R}^2$ 平面上，得到一个四边形区域（投影）。
❌ 反例/注意

若去掉定义域限制 $c^T x + d > 0$，函数在 $c^T x + d = 0$ 处发散，会导致从凸集映射到不连通的像（甚至可能无定义）。所以线性分式函数保持凸性的前提是定义域必须选择在分母符号不变的一侧。

$$P(z,t) = \frac{z}{t},\; t>0 \qquad f(x) = \frac{Ax+b}{c^Tx+d}$$

Q: 如何判断一个工程中的约束集是否凸？
A: 三个步骤：1)检查每个约束函数是否凸(二阶条件/Hessian); 2)等式约束必须仿射(Ax=b); 3)多个凸约束取交集→凸。反例: 无人机避障约束\|x-obs\|>=d是非凸的→需要凸分解或混合整数规划。

Q: 为什么SLAM的位姿图优化是非凸的但可以求解？
A: 位姿图涉及SO(3)旋转群→非凸。但通过SDP松弛(把旋转矩阵R松弛为PSD矩阵X⪰0, rank(X)=3去掉→凸)可以得到全局最优的近似。实践中，用Gauss-Newton从好的初始点开始局部优化通常也能收敛到全局最优。

Q: 什么时候必须用非凸优化？
A: 1)离散决策(是否建厂=0/1)→整数规划; 2)凹约束(不低于某值)→需要bilinear或DC规划; 3)秩约束→需要核范数松弛。凸优化的边界: 障碍回避、接触动力学(互补约束)、多模态感知都是非凸的。

2.4 广义不等式

2.4.1 正锥与广义不等式

📋 中文定义

一个锥 $K \subseteq \mathbb{R}^n$ 称为正锥(proper cone)，如果它满足：(1) $K$ 是凸的 (2) $K$ 是闭的 (3) $K$ 是实心的（内部非空）(4) $K$ 是尖的（$x \in K, -x \in K \Rightarrow x = 0$）——即"不包含完整直线"。

借助正锥 $K$，定义广义不等式(generalized inequality)：

$$ x \preceq_K y \iff y - x \in K, \qquad x \prec_K y \iff y - x \in \text{int}(K) $$

这就是把标量 $\le$ 推广到向量/矩阵。核心思想：用锥定义"序"。

🔮 几何直觉

在 $\mathbb{R}$ 中，$x \le y$ 等价于 $y-x \in [0,\infty)$。这里 $K = [0,\infty)$ 是正锥。广义不等式就是把 $[0,\infty)$ 替换成任意正锥。

在 $\mathbb{R}^2$ 中，取 $K = \mathbb{R}^2_+$（第一象限），则 $x \preceq_K y$ 意味着每个分量都满足 $x_i \le y_i$（分量不等式）。如果取 $K$ 为二阶锥，$x \preceq_K y$ 表示 $(y_1 - x_1) \ge \sqrt{(y_2-x_2)^2 + \cdots}$。

✅ 典型例子
  1. $K = \mathbb{R}^n_+$（非负象限）→ 分量不等式 $x \preceq y \iff x_i \le y_i, \forall i$。
  2. $K = \mathbb{S}^n_+$（半正定锥）→ 矩阵不等式 $X \preceq_K Y \iff Y - X$ 半正定。
  3. $K = \{(x,t) \mid \|x\|_2 \le t\}$（二阶锥）→ 二阶锥不等式。
❌ 反例

$K = \{(x_1,x_2) \mid x_1 \ge 0\}$（一个闭半空间）不是正锥——它不是尖的：$\pm (0,1)$ 都在 $K$ 中但不等于 0。用这样的 $K$ 来定义序关系，会出现 $x \preceq_K y$ 且 $y \preceq_K x$ 但 $x \neq y$ 的情况——破坏了偏序的反称性。

$$x \preceq_K y \iff y-x \in K$$

多目标优化中的偏序定义。分量不等式→多标准决策(成本≤预算,重量≤限制)；矩阵不等式→控制器设计中"系统A比系统B更稳定"。广义不等式让你能比较不能直接比较的东西。

🧠 一句话总结

广义不等式 = 用正锥 $K$ 代替 $[0,\infty)$ 来定义"序"。$y-x \in K$ 就是 $x \preceq_K y$。

📘 例2.14 分量不等式 (Boyd)

$K = \mathbb{R}^n_+$（非负象限），则广义不等式 $\preceq_K$ 就是通常的分量不等式(componentwise inequality)：

$$x \preceq_K y \iff x_i \le y_i,\; i=1,\ldots,n$$

偏序性质：$\preceq_K$ 满足反称性($x\preceq y$ 且 $y\preceq x \Rightarrow x=y$)、传递性。许多向量不等式就自然地以这种广义不等式的形式出现。

📘 例2.15 矩阵不等式 (Boyd)

$K = \mathbb{S}^n_+$（半正定锥），则广义不等式 $\preceq_K$ 即为常用的矩阵不等式(matrix inequality)：$X \preceq_K Y \iff Y - X$ 半正定（通常简写作 $X \preceq Y$）。

在控制理论、信号处理等领域中，Lyapunov 不等式 $A^T P + P A \preceq 0$ 就是典型的矩阵不等式形式。

📘 例2.16 [0,1]上非负多项式的锥 (Boyd)

令 $K$ 为 $[0,1]$ 上所有系数在 $\mathbb{R}^n$ 中的非负多项式：

$$K = \{c \in \mathbb{R}^n \mid c_1 + c_2 t + \cdots + c_n t^{n-1} \ge 0,\; \forall t \in [0,1]\}$$

$K$ 是一个正锥。对应的广义不等式 $x \preceq_K y$ 表示 $x$ 和 $y$ 分别作为多项式系数，且 $y-x$ 的多项式在 $[0,1]$ 上处处非负。

2.4.2 最小元与极小元

📋 中文定义

设 $S$ 是某个集合，$K$ 是正锥。

  • $x \in S$ 是 $S$ 的最小元(minimum element)，如果对所有 $y \in S$，有 $x \preceq_K y$。等价地：$S \subseteq x + K$（$S$ 完全落在以 $x$ 为起点的锥里面）。
  • $x \in S$ 是 $S$ 的极小元(minimal element)，如果 $y \preceq_K x$ 且 $y \in S$ 蕴含 $y = x$。等价地：$(x - K) \cap S = \{x\}$（没有比 $x$ "更小"的元素在 $S$ 中）。

关键区别：最小元可以与所有元素比较（最强），极小元只是没有严格小于它的元素（Pareto 意义下的）。

🔮 几何直觉

在分量不等式 $K = \mathbb{R}^2_+$ 下：

  • $x$ 是最小元 → $S$ 中所有点都在 $x$ 的"右上角"（每个分量都不小于 $x$ 的对应分量）。这意味着 $x$ 是所有分量同时最小的点——现实中几乎不存在。
  • $x$ 是极小元 → 在 $S$ 中没有点在 $x$ 的"左下角"（不存在所有分量都 $\le x$ 且至少一个严格 < 的点）。这更常见——Pareto 最优就是极小元。

极小元可能有很多个，它们之间可能无法比较。

✅ 典型例子
  1. 在标量中（$K = \mathbb{R}_+$），极小元和最小元是一致的：最小值。
  2. 在 $\mathbb{R}^2$ 中，集合 $S = \{(1,2), (2,1), (3,3)\}$ 在分量不等式下：$(1,2)$ 和 $(2,1)$ 都是极小元（互相不可比较），没有最小元。
  3. 集合 $S = \{(x_1,x_2) \mid x_1 + x_2 \ge 1, x_1 \ge 0, x_2 \ge 0\}$ 的边界上有很多点都是极小元。
❌ 反例/陷阱

新手常犯的错误：以为极小元就是"最小"的。在偏序下，极小元可能有很多个，它们之间可能无法比较。比如 Pareto 前沿上的所有点都是极小元——不能说其中哪个更好。

$$\text{最小元: } S \subseteq x + K \qquad \text{极小元: } (x-K) \cap S = \{x\}$$

🧠 一句话总结

最小元 = 比所有元素都小（全局最优）。极小元 = 不存在更小的可比元素（Pareto最优）。两者在偏序下不同！

📘 例2.18 对称矩阵的最小元与极小元 (Boyd)

考虑 $K = \mathbb{S}^n_+$，$S$ 为所有 $n \times n$ 对称矩阵的一个子集。

  • 最小元 $X \in S$：对所有 $Y \in S$，$Y - X \succeq 0$，即 $Y - X$ 半正定。这意味着 $X$ 在所有矩阵中都"最小"。
  • 极小元 $X \in S$：如果 $Y \in S$ 满足 $Y \preceq X$（即 $X - Y \succeq 0$），则必有 $Y = X$。极小元在偏序下是 Pareto 最优的。

2.5 分离与支撑超平面

2.5.1 超平面分离定理

📋 中文定义

超平面分离定理(separating hyperplane theorem)：设 $C, D \subseteq \mathbb{R}^n$ 是两个不相交的凸集（$C \cap D = \emptyset$）。则存在 $a \in \mathbb{R}^n, a \neq 0$ 和 $b \in \mathbb{R}$，使得：

$$ a^T x \le b,\; \forall x \in C \qquad\text{且}\qquad a^T x \ge b,\; \forall x \in D $$

即存在一个超平面 $\{x \mid a^T x = b\}$ 将 $C$ 和 $D$ 分离。

严格分离(strict separation)：如果 $C$ 和 $D$ 至少有一个是闭的且另一个是紧的，则可以严格分离：$a^T x < b$ 对所有 $x \in C$，$a^T x > b$ 对所有 $x \in D$。

🔮 几何直觉

如果你和你的朋友各拿一个凸形气球（不重合），我一定能在你们之间插一张硬纸板，使得两个气球在纸板的两侧。这张硬纸板就是分离超平面。

这个定理是凸优化理论的基石——它保证了对偶理论（Lagrange 对偶）的几何合理性。它实际上就是Hahn-Banach 定理的几何版本。

✅ 典型例子
  1. 两个不相交的圆盘——它们的公切线之一可以作为分离超平面。
  2. 点 $\{x_0\}$ 和闭凸集 $C$（$x_0 \notin C$）：存在分离超平面把点和集合分开。这是对偶理论的基础构造。
  3. 两个不相交的多面体总能被严格分离（因为它们都是闭的且具有合适条件）。
❌ 反例

关键条件：两个集合都必须是对凸的。如果其中一个不是凸的（比如月牙形），那么两个不相交的非凸集合可能无法被超平面分离。

另外，两个不相交的开集（如两个开半空间）可能无法被严格分离——分离超平面会碰到共同的边界点。

$$\exists a \neq 0, b:\; a^T x \le b\;(x\in C),\; a^T x \ge b\;(x\in D)$$
📖 公式解读 — 分离不等式 $a^T x \le b \le a^T y$ 怎么理解？
  • 拆解符号： $a$ 是分离超平面的法向量。$b$ 是"分界线"的截距。$C$ 在超平面的一侧（$\le$），$D$ 在另一侧（$\ge$）。
  • 通俗类比： 两个互不侵犯的气球——你在它们之间插一张硬纸板。纸板的一侧是气球 C（$a^T x \le b$），另一侧是气球 D（$a^T x \ge b$）。这张纸板就是分离超平面。
  • 为什么重要： 分离定理是对偶理论的几何根基。Lagrange 乘子本质上就是分离超平面的法向量。没有分离定理就没有 KKT 条件，就没有 SVM，也没有凸对偶。
  • 分离一定存在吗？ 两个凸且不相交的集合：一定有分离超平面！但如果其中一个是月牙形（非凸），可能分不开。
  • 数值例子： $C$ 是单位圆盘 $(x_1-1)^2+x_2^2\le1$，$D$ 是 $(x_1+1)^2+x_2^2\le1$。它们不相交，存在分离线 $x_1=0$：对 $C$ 中所有点 $x_1\ge0$（$a^T x\ge0$），对 $D$ 中所有点 $x_1\le0$（$a^T x\le0$），取 $b=0$。

SVM的核心数学基础——最大间隔分类器就是找分离两个点集的超平面。对偶理论、博弈论的minimax定理、公平分配问题都依赖分离定理。没有分离定理，就没有Lagrange对偶。

📘 例2.19 仿射集与凸集的分离 (Boyd)

设 $C$ 是凸集，$D = \{x \mid Cx = d\}$ 是仿射集（$C$ 满行秩）。如果 $C \cap D = \emptyset$，则分离定理给出了分离超平面的存在性。

这是线性规划(LP)对偶性的几何基础——当一个凸集和一个仿射集不相交时，可以用超平面来"证明"它们不相交。

📘 例2.20 点与闭凸集的严格分离 (Boyd)

设 $C$ 是闭凸集，$x_0 \notin C$。则存在严格分离超平面：

$$\exists a \neq 0,\; b:\; a^T x_0 > b,\; a^T x < b,\; \forall x \in C$$

这是对偶理论和最优性条件的最关键工具。它等价于：如果 $x_0 \notin C$，则 $x_0$ 和 $C$ 可以被分离。

📘 例2.21 严格线性不等式的择一性定理 (Boyd)

分离定理的一个重要推论是不等式系统的择一定理(Theorem of alternatives)：

严格线性不等式系统 $Ax \prec b$ 无解 $\iff$ 存在 $\lambda \succeq 0, \lambda \neq 0$ 满足 $\lambda^T A = 0, \lambda^T b \le 0$

这体现了凸优化中"原始问题有解 vs 对偶问题有解"的二择一法则。

2.5.2 支撑超平面

📋 中文定义

超平面 $\{x \mid a^T x = b\}$ 称为凸集 $C$ 在边界点 $x_0 \in \partial C$ 处的支撑超平面(supporting hyperplane)，如果 $a^T x \le b$ 对所有 $x \in C$ 成立，且 $a^T x_0 = b$。

即：该超平面与 $C$ 相切于 $x_0$，且 $C$ 完全在超平面的一侧。

支撑超平面定理：凸集 $C$ 边界上的任意一点都存在支撑超平面。

🔮 几何直觉

想象一个凸气球。在气球表面任何一点，你都可以放置一张纸板刚好贴在气球上，而整个气球都在纸板的同一侧。这张纸板就是支撑超平面。如果你站在气球里面往外看，你永远看不到"凹陷"——因为在凹陷处你会看到气球的那部分在纸板的另一侧。

支撑超平面的存在与否是区分凸集和非凸集的方法：非凸集总有一些边界点无法找到支撑超平面。

✅ 典型例子
  1. 单位圆在任意边界点 $(x_1,x_2)$ 处的切线就是支撑超平面（该点的切线方向是法向量为 $(x_1,x_2)$ 的直线）。
  2. 多面体的每个面都是一个支撑超平面的子集。
  3. 对于非负象限 $\mathbb{R}^n_+$，坐标轴上的每个点都对应一个"边界"超平面（其中一个坐标为0）。
❌ 反例——关键！

非凸集可能在某些边界点没有支撑超平面。例如月牙形凹进去的部分——在那里的边界点，任何经过该点的超平面都会把月牙切成两半（一部分在一边，另一部分在另一边）。这恰好是区分凸和非凸的判定方式：如果边界上的每一点都存在支撑超平面，则集合是凸的。

$$a^T x \le b = a^T x_0,\; \forall x \in C$$

第1层：构造方法

2.6 对偶锥与广义不等式

2.6.1 对偶锥

📋 中文定义

设 $K$ 是一个锥。$K$ 的对偶锥(dual cone) 定义为：

$$ K^* = \{y \mid y^T x \ge 0,\; \forall x \in K\} $$

$K^*$ 也是锥，且总是凸的（即使 $K$ 本身不是凸锥）。如果 $K$ 是正锥（proper cone），则 $K^*$ 也是正锥。

自对偶锥(self-dual cone)：如果 $K^* = K$。例如 $\mathbb{R}^n_+$、二阶锥 $\{(x,t) \mid \|x\|_2 \le t\}$、半正定锥 $\mathbb{S}^n_+$。

🔮 几何直觉

在 $\mathbb{R}^2$ 中，取 $K$ 为第一象限。$y^T x \ge 0$ 对所有 $x \in K$ 意味着 $y$ 也必须落在第一象限——所以 $K^* = K$。

如果 $K$ 是角度很窄的一个尖锥，则 $y^T x \ge 0$ 意味着 $y$ 与所有 $K$ 中的向量夹角 $\le 90^\circ$，所以 $K^*$ 会是一个非常宽的锥（宽到能包住 $K$）。对偶锥 = 与 $K$ 中所有向量夹角都 ≤ 90° 的向量的集合。$K$ 越窄，$K^*$ 越宽。

✅ 典型例子
  1. $\mathbb{R}^n_+$ 的对偶锥是它自己（自对偶）。
  2. 二阶锥的对偶锥是它自己（自对偶）。
  3. 半正定锥 $\mathbb{S}^n_+$ 的对偶锥是它自己（自对偶）。
  4. 角度为 $\alpha$ 的平面锥 $K = \{(\cos\theta,\sin\theta) \mid |\theta| \le \alpha/2\}$ 的对偶锥角度为 $\pi - \alpha$。
❌ 注意

注意：$K$ 可以不是凸的，但 $K^*$ 总是凸的——因为 $K^* = \bigcap_{x \in K} \{y \mid y^T x \ge 0\}$ 是半空间的交集，凸集的交集总是凸的。

$$K^* = \{y \mid y^T x \ge 0,\; \forall x \in K\}$$
📖 公式解读 — $K^* = \{y \mid y^T x \ge 0,\;\forall x\in K\}$ 到底在说什么？
  • 拆解符号： $y^T x$ 是内积，几何上是 $y$ 和 $x$ 之间夹角的"余弦 × 长度乘积"。$y^T x \ge 0$ 就是说 $y$ 和 $x$ 的夹角 $\le 90°$。
  • 通俗类比： 你在追光灯（锥 K）的照射范围内。对偶锥 $K^*$ 中的向量是那些"能看到整束光"的方向——你和 K 中每一条光线 的夹角都不超过 90°。K 越窄（像激光），$K^*$ 就越宽（像泛光灯）。
  • 为什么叫"对偶"： 在 $K$ 中的向量让你"看到 $K^*$ 中的每个方向都是非负内积"，反之亦然。这是一个对称关系——就像照镜子。
  • 数值例子： $K = \{(\cos\theta,\sin\theta) \mid |\theta|\le30°\}$（张角 60°）。$K^* = \{(\cos\phi,\sin\phi) \mid |\phi|\le60°\}$（张角 120°）。因为 $60°+120°=180°$——互补关系！任何与 K 中所有方向夹角 ≤ 90° 的方向恰好落在 $120°$ 的扇形中。

🧠 一句话总结

对偶锥 $K^*$ = 所有与 $K$ 中向量夹角 ≤ 90° 的向量。$K$ 越小（越窄），$K^*$ 越大（越宽）。三种最重要的锥都是自对偶的。

📘 例2.22 子空间的对偶锥 (Boyd)

子空间 $V \subseteq \mathbb{R}^n$（也是一个锥）的对偶锥就是其正交补：

$$V^* = V^\perp = \{y \mid y^T x = 0,\; \forall x \in V\}$$

这是因为 $y^T x \ge 0$ 和 $y^T (-x) = -y^T x \ge 0$ 同时对任意 $x \in V$ 成立，所以必须有 $y^T x = 0$。

📘 例2.23 非负象限 (Boyd)

$\mathbb{R}^n_+$ 是自对偶锥：$(\mathbb{R}^n_+)^* = \mathbb{R}^n_+$

证明：若 $y^T x \ge 0$ 对所有 $x \succeq 0$ 成立，则若 $y$ 有负分量 $y_i < 0$，取 $x = e_i$（第 $i$ 单位向量）得 $y_i < 0$，矛盾。所以 $y \succeq 0$。

📘 例2.24 半正定锥 (Boyd)

$\mathbb{S}^n_+$ 是自对偶锥：$(\mathbb{S}^n_+)^* = \mathbb{S}^n_+$

关键的证明工具：$\text{tr}(XY) \ge 0$ 对所有 $X \succeq 0$ 等价于 $Y \succeq 0$。这是因为 $\text{tr}(XY) = \text{tr}(X^{1/2} Y X^{1/2})$，而 $X^{1/2} Y X^{1/2} \succeq 0$ 当且仅当 $Y \succeq 0$。

📘 例2.25 范数锥的对偶 (Boyd)

设 $\|\cdot\|$ 是 $\mathbb{R}^n$ 上的范数，其对偶范数为 $\|\cdot\|_*$。范数锥 $K = \{(x,t) \mid \|x\| \le t\}$ 的对偶锥是：

$$K^* = \{(u,v) \mid \|u\|_* \le v\}$$

这即是对偶范数定义的范数锥！因此二阶锥（$\ell_2$ 范数，自对偶 $\|\cdot\|_2 = \|\cdot\|_*$）是自对偶的，但 $\ell_1$ 范数锥的对偶是 $\ell_\infty$ 范数锥（反之亦然）。

2.6.2 广义不等式的对偶

📋 中文定义

设 $K$ 是正锥，其广义不等式 $\preceq_K$。则对偶广义不等式 $\preceq_{K^*}$ 基于对偶锥 $K^*$：

$$ x \preceq_{K^*} y \iff y - x \in K^* \iff \lambda^T (y - x) \ge 0,\; \forall \lambda \succeq_K 0 $$

换句话说：$x \preceq_{K^*} y$ 当且仅当对所有在原来 $K$ 意义下"非负"的向量 $\lambda$，都有 $\lambda^T x \le \lambda^T y$。

这个定义非常优雅：对偶不等式用原锥中的所有"测试向量"来检查不等式关系。

🔮 几何直觉

在经济学/优化中，$\lambda$ 可以解释为"价格向量"（shadow price）。$x \preceq_{K^*} y$ 意味着：无论你用什么样的非负价格 $\lambda$ 来评估，$y$ 的价值总是大于等于 $x$ 的价值。这是一种"鲁棒的"大小关系。

由于 $(\mathbb{R}^n_+)^* = \mathbb{R}^n_+$，所以分量不等式的对偶还是分量不等式。而二阶锥和半正定锥也都是自对偶的——这些情况下对偶广义不等式与原不等式一致。

✅ 典型例子
  1. $K = \mathbb{R}^n_+$，$\preceq_{K^*}$ 即分量不等式（与 $\preceq_K$ 相同）。
  2. 若 $K$ 是一个角度很窄的锥，$\preceq_{K^*}$ 的意义就与 $\preceq_K$ 不同——$K^*$ 宽得多，$x \preceq_{K^*} y$ 更容易满足。
❌ 注意

对偶广义不等式不是原不等式的"反向"——它只是换了一个锥。对于非自对偶锥，$\preceq_K$ 和 $\preceq_{K^*}$ 是不同的偏序关系。不要把 $K^*$ 和 $-K$ 混淆！

$$x \preceq_{K^*} y \iff \lambda^T x \le \lambda^T y,\; \forall \lambda \succeq_K 0$$
🎯 学完用途

经济学中的价格理论——原问题(min成本)的对偶是max利润。对偶不等式给出了用"价格"来检验"效率"的方法。这在机制设计、拍卖理论、资源分配中有直接应用。

🧠 一句话总结

对偶广义不等式用 $K^*$ 代替 $K$。对于三大自对偶锥（非负象限、二阶锥、PSD锥），对偶不等式与原不等式相同。

2.6.3 对偶不等式下的最小元与极小元

📋 中文定义

借助对偶广义不等式，我们可以刻画原不等式的极小元和最小元：

  • $x$ 是 $S$ 在 $\preceq_K$ 下的最小元 $\iff$ 对所有 $\lambda \succ_{K^*} 0$，$x$ 是标量函数 $\lambda^T z$ 在 $z \in S$ 上的唯一最小点。
  • $x$ 是 $S$ 在 $\preceq_K$ 下的极小元 $\iff$ 存在 $\lambda \succ_{K^*} 0$ 使得 $x$ 最小化 $\lambda^T z$ 在 $S$ 上。

这是对偶的一个非常强大的应用：向量优化问题可以通过标量化（用对偶锥中的向量加权）来求解极小元。

🔮 几何直觉

思想精髓：最小元必须对所有可能的加权方向都是最优的——这是非常强的条件，通常不存在。极小元只需要存在至少一个加权方向使得它是该标量问题的最优解。这就是"Pareto最优 = 某个线性加权和的最优解"的数学表述。

在工程中，这意味着你可以通过选择不同的权重 $\lambda$ 来"扫描"Pareto前沿上的不同极小元。

✅ 典型例子
  1. $K = \mathbb{R}^2_+$，$S = \{(x_1,x_2) \mid x_1^2 + x_2^2 \le 1, x_1 \ge 0, x_2 \ge 0\}$（四分之一单位圆）。取 $\lambda = (1,0)$，最小化 $\lambda^T z = z_1$ 得到极小元 $(0,1)$；取 $\lambda = (0,1)$ 得 $(1,0)$；取 $\lambda = (1,1)$ 得 $1/\sqrt{2} (1,1)$。这些全部是极小元。
  2. 在经济中：用不同价格向量 $\lambda$ 来最小化总成本，得到的解都是 Pareto 最优采购方案。
❌ 陷阱

不是所有的极小元都能通过标量化找到！只有当 $S$ 是凸的时，上述标量化定理才保证每一个极小元都对应某个 $\lambda \succ_{K^*} 0$。对于非凸 $S$，可能存在"隐藏"的极小元无法用任何正权重 $\lambda$ 标量化得到。

$$x\text{ 极小元 }\iff \exists \lambda \succ_{K^*} 0: x = \arg\min_{z\in S} \lambda^T z$$

对偶给出向量优化的标量化方法：选权重 $\lambda \in K^*$，求最优 → 得到原问题的极小元。这就是Pareto最优的数学原理。

📘 例2.27 Pareto最优生产前沿 (Boyd)

我们考虑在 $n$ 种资源下生产一种产品的生产函数。设 $x \in \mathbb{R}^n$ 表示 $n$ 种资源的投入向量，产出为 $f(x)$。在投入集合 $S \subseteq \mathbb{R}^n$ 中（假设 $S$ 是凸的），我们关心的是在保持产出不变的前提下如何最小化投入。

使用 $K = \mathbb{R}^n_+$（分量不等式），一个投入向量 $x$ 是极小元（Pareto最优），如果不存在另一个可行投入在所有资源方面都不超过 $x$ 且至少一种资源严格小于 $x$——即在相同产出下没有"全面更省"的方式。

由标量化定理，每个 Pareto 最优投入 $x$ 对应某个正权重向量 $\lambda \succ 0$，极小化 $\lambda^T z$ 在 $S$ 上的目标函数：

$$x = \arg\min_{z \in S} \lambda^T z$$

这正是成本最小化问题 $\min \sum_i \lambda_i z_i$ —— $\lambda$ 是各资源的价格（shadow prices），而最优解就是给定价格下的最优投入组合。不同价格选择会导致不同 Pareto 最优方案分布在 Pareto 前沿上。

📐 公式数值例子 — 凸组合 $y=\theta x_1+(1-\theta)x_2$

🔧 工程实践

怎么在工程中判断一个集合是否凸？
  1. 定义法（最直接）： 取集合内任意两点，检查它们之间的线段是否完全在集合内。在代码中可以通过采样大量点对来数值验证。
  2. 构造法（最实用）： 如果集合能写成"已知凸集的交/仿射像/原像"，则它自动是凸的。例：$\{x \mid Ax \le b, \|x\|_2 \le 1\}$ 是半空间与Euclid球的交 → 凸。
  3. 反证法（快速排除）： 如果肉眼可见"凹陷"或"洞"，一定不凸。月牙形、星形、整数点集都不凸。
🔧 实际应用：可行域设计

在设计优化问题的约束时，确保可行域是凸的是第一步。例如：

  • 投资组合约束： 权重非负($x_i\ge0$)+总权重=1 → 概率单纯形(凸)✓
  • 天线阵列波束成形： 每通道功率约束 $\sum|x_i|^2\le P_{max}$ → Euclid球(凸)✓
  • 非凸陷阱： 无人机路径避开障碍物 → 可行域被"挖洞"→ 非凸✗。需要凸近似或分解为多个凸子问题。
