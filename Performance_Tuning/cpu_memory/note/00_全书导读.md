# 00 全书导读

> 本文档是《What Every Programmer Should Know About Memory》(Ulrich Drepper, Version 1.0, 2007-11-21) 系统化中文学习项目的总纲。
> 这是阶段一（结构分析与映射）的产物：不包含后续笔记正文，也不包含实验代码。

## 1. 本文档的作用

本文档回答三个问题：

1. 这本 PDF 到底讲了什么，章节是如何组织的？
2. 每一章对应我们的哪些笔记文件、哪些可运行实验？
3. 接下来的阶段二、三、四分别要做什么？

| 项 | 值 |

| 标题 | What Every Programmer Should Know About Memory |

## 6. 三条学习路线

### 路线一：CPU 内存体系基础

PDF 第 2~4 章 + 笔记 01~15：

```
RAM → DRAM 访问原理 → Cache 基础 → Cache Line → 局部性
    → 映射与关联度 → 写策略 → 一致性 → 指令缓存 → 内存墙
    → 虚拟内存/MMU → 多级页表 → TLB → 大页
```

对应实验：01、02、03、04、05、06、07、08、12、18、19、20。

### 路线二：C++ 内存性能优化

PDF 第 6 章 + 笔记 18~25：

```
顺序访问 → 数据布局(AoS/SoA) → 矩阵分块(Cache Blocking)
    → 预取 → False Sharing → 原子竞争 → Non-Temporal Store → NUMA 编程
```

对应实验：09、10、11、13、14、15、16、17、24、25、26、28。

### 路线三：Linux 系统性能分析

PDF 第 7 章 + 笔记 26~29：

```
perf 事件 → perf stat/record → Cachegrind → Page Fault 分析
    → Huge Page → NUMA 检测 → CPU Affinity
```

对应实验：与所有实验配套，使用 scripts/ 下的 perf_stat.sh、cachegrind.sh、numa_test.sh。
