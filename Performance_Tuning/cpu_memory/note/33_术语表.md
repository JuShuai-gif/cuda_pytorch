# 33 术语表

> 综合篇：全书核心术语的速查表。每个术语给出中文名、英文全称、一句话定义与出处笔记。
> 覆盖全书（PDF 第 1~8 章 + 附录）。

## A

- **ASLR（Address Space Layout Randomization，地址空间布局随机化）**：把进程各段（栈/堆/DSO/代码）随机放置，防止攻击者猜测地址；代价是页表目录数增多。→ note/13
- **ASID（Address Space ID）**：TLB 标签扩展，标识地址空间，避免上下文切换全刷（AMD Pacifica 引入）。→ note/12
- **Associativity（关联度）**：同一缓存集合内可放的缓存行数（ways）。→ note/07
- **Atomic Operation（原子操作）**：不可分割的读-改-写，并发下结果确定。→ note/24
- **AoS（Array of Structures，结构体数组）**：一个结构体含全部字段、数组连续排列的数据布局。→ note/19

## B

- **Burst（突发传输）**：一次 CAS 后连续传输多个数据字（2/4/8）。→ note/03
- **Bypassing the Cache（绕过缓存）**：用 non-temporal 指令直接读/写内存，避免缓存污染。→ note/22

## C

- **Cache Line（缓存行）**：缓存管理的最小单位（现代多 64B）。→ note/05
- **Cache Set（缓存集合）**：由地址 S 位选择的缓存槽组。→ note/07
- **Cache Tag（标签）**：区分同一集合内不同别名的地址高位。→ note/07
- **CAS（Compare-and-Swap）**：仅当当前值等于期望值时写入新值的原子操作。→ note/24
- **Cache Coherency（缓存一致性）**：多处理器对内存持有统一视图。→ note/09
- **CPI（Cycles Per Instruction，每指令周期）**：周期数/指令数，衡量内存惩罚。→ note/27
- **Conflict Miss（冲突未命中）**：容量未满但多地址映射同一集合互相驱逐导致的 miss。→ note/07
- **Compulsory Miss（强制未命中）**：首次访问某行不可避免的 miss。→ note/07
- **Capacity Miss（容量未命中）**：工作集超过缓存容量导致的 miss。→ note/07
- **CL（CAS Latency）**：CAS 到数据出现的延迟。→ note/03

## D

- **DDR（Double Data Rate DRAM）**：每个时钟周期传输两次数据的 DRAM。→ note/03
- **Dirty Cache Line（脏缓存行）**：已修改、未写回主存的缓存行。→ note/08
- **DMA（Direct Memory Access）**：设备绕过 CPU 直接访问内存。→ note/01
- **DRAM（Dynamic RAM）**：用电容存储、需刷新的内存。→ note/02
- **DTLB（Data TLB）**：数据地址翻译缓存。→ note/14
- **Demand Paging（按需分页）**：页在首次访问时才分配/读入。→ note/29

## E

- **ECC（Error Correction Code，纠错码）**：内存控制器为数据附加校验位，纠正单位错误。→ note/02
- **EPT（Extended Page Tables）**：Intel 硬件二次页表翻译，避免影子页表。→ note/12
- **Eviction（驱逐）**：为腾空间把缓存行逐出。→ note/05
- **Exclusive Cache（独占缓存）**：同一数据只存在一个缓存级别。→ note/05

## F

- **False Sharing（伪共享）**：不同变量同一缓存行，写互相触发 RFO。→ note/23
- **FSB（Front Side Bus，前端总线）**：CPU 与北桥之间的共享总线（历史）。→ note/01
- **First-Touch（首次触碰）**：页在首次访问时分配，节点由当时策略决定。→ note/25

## H

- **Hardware Prefetching（硬件预取）**：CPU 自动识别访问模式并预取。→ note/21
- **Huge Page（大页）**：比 4KB 大得多的页（x86-64 常用 2MB/1GB）。→ note/15
- **hugetlbfs**：Linux 预留大页的伪文件系统。→ note/15
- **Hypercube（超立方体）**：2^C 节点、直径 C 的互连拓扑。→ note/16

## I

- **Inclusive Cache（包含缓存）**：高一级缓存包含低一级内容。→ note/05
- **Instruction Cache（指令缓存 / L1i）**：缓存指令（含已解码的 trace cache）。→ note/10
- **Interleave（交错分配）**：内存按节点轮流分配（MPOL_INTERLEAVE）。→ note/25
- **ITLB（Instruction TLB）**：指令地址翻译缓存。→ note/14

## L

- **L1d / L1i / L2 / L3**：一级数据/指令缓存、二级、三级缓存。→ note/05
- **LL/SC（Load Lock / Store Conditional）**：成对的原子读-条件写。→ note/24
- **Locality（局部性）**：空间（相邻地址）与时间（刚用的还用）。→ note/05
- **LRU（Least Recently Used）**：最久未使用先逐出的策略（Cachegrind 模拟）。→ note/28

## M

- **MESI**：Modified/Exclusive/Shared/Invalid 四状态一致性协议。→ note/09
- **MMU（Memory Management Unit）**：执行虚拟→物理翻译的硬件。→ note/12
- **Major Page Fault**：需读盘的页错误。→ note/29
- **Minor Page Fault**：内容已在内存的页错误。→ note/29
- **MPOL_BIND/PREFERRED/INTERLEAVE/DEFAULT**：四种内存策略。→ note/25
- **Memory Controller（内存控制器）**：把访存请求转成 RAS/CAS 时序的部件。→ note/04

## N

- **Non-Temporal Store（非临时写）**：绕过缓存、配合写合并的流式写。→ note/22
- **NUMA（Non-Uniform Memory Architecture）**：不同 CPU 访问不同内存代价不同的架构。→ note/16
- **NUMA Factor**：远程相对本地访问的额外代价倍数。→ note/16
- **NPT（Nested Page Tables）**：AMD 硬件二次页表翻译。→ note/12

## P

- **Page Table（页表）**：记录虚拟页→物理页映射的结构。→ note/12
- **Page Table Walk（页表遍历）**：从顶级目录逐级索引到物理页。→ note/13
- **Prefetch（预取）**：提前装入数据以隐藏延迟。→ note/21
- **Prefetch Distance（预取距离）**：当前点与预取点的间隔。→ note/21

## R

- **RFO（Request For Ownership）**：写前获取缓存行所有权。→ note/08
- **RAS/CAS**：行/列地址选通。→ note/03
- **Registered Memory（寄存器内存）**：模块带缓冲芯片（降负担、增延迟）。→ note/02
- **Replication（复制）**：只读数据每节点一份副本。→ note/25

## S

- **SDRAM（Synchronous DRAM）**：与时钟同步的 DRAM，DDR 的基础。→ note/03
- **Set-Associative（组相联）**：地址选集合、集合内 N 条并行比较。→ note/07
- **SRAM（Static RAM）**：6T 单元、无需刷新的高速内存。→ note/02
- **SMC（Self Modifying Code，自修改代码）**：程序修改自身代码（应避免）。→ note/10
- **SIMD（Single Instruction, Multiple Data）**：一条指令处理多个数据。→ note/18
- **SoA（Structure of Arrays，数组结构体）**：每字段一个数组的数据布局。→ note/19
- **Stripe（条带化）**：内存按节点轮流分配以均衡（默认策略）。→ note/17

## T

- **TLB（Translation Look-Aside Buffer）**：缓存完整地址翻译的小缓存。→ note/14
- **THP（Transparent Huge Pages，透明大页）**：内核自动选择大页的机制（现代）。→ note/15
- **TLS（Thread-Local Storage）**：`__thread` 每线程独立变量。→ note/23
- **tRCD / tRP / tRAS**：RAS-to-CAS 延迟 / 行预充电时间 / 激活到预充电延迟。→ note/03
- **Transactional Memory（事务内存）**：一组内存操作全提交或全回滚（论文 8.2 展望）。→ note/30

## W

- **Working Set（工作集）**：程序短期实际使用的内存集合。→ note/06
- **Write-Through（写透）**：写缓存同时写主存。→ note/08
- **Write-Back（写回）**：先写缓存标脏，逐出时写回。→ note/08
- **Write-Combining（写合并）**：把多次部分写合并成整行后写出。→ note/08
