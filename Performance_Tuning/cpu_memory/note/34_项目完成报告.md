## 3. 本机环境

- CPU: Intel Core i9-14900HX（Raptor Lake，移动端）

- 缓存: L1d 48K/12-way、L1i 32K/8-way、L2 2M/16-way、L3 36M/12-way（每 CPU 报告）

## 4. 本机基准结果（节选）

> 完整数据见 benchmark_results/20260805_095540/。以下为代表性结果，均来自本机实测。

### 4.1 缓存层级延迟（experiment 01，pointer chasing，随机序）

| 工作集 | ns/elem | 推断层级 |
|---|---:|---|
| ≤32K | ~0.9 | L1d 命中 |
| 64K~512K | ~3.0 | L2 命中 |
| 1M~8M | ~4.5~15.8 | L3 命中 |
| ≥16M | ~85 | 主存 |

### 4.2 顺序 vs 随机（experiment 02，256MB）

| 模式 | ns/elem | GB/s |
|---|---:|---:|
| 顺序 forward | 0.24 | 16.6 |
| 逆序 backward | 0.26 | 15.4 |
| 随机 random | 6.61 | 0.6 |

- 随机比顺序慢约 27 倍，验证论文"随机访问应尽量避免"的论点。

### 4.3 数据布局（experiment 11，2M 粒子）

| 模式 | time_ms | 有效 GB/s |
|---|---:|---:|
| AoS 全字段 | 3.26 | 20.6 |
| AoS 只读 x/y | 2.68 | 6.3 |
| SoA 只读 x/y | 0.83 | 20.2 |

- SoA 只读部分字段比 AoS 快约 3.2 倍。

### 4.4 多线程（experiment 13/14）

- False sharing：padding 分离比同行快 2.31 倍。
- 原子竞争（experiment 14，8 线程，每线程 2e7 次）：
  - 局部归约：0.21 ms
  - 共享 atomic：1453 ms（~7000× 慢）
  - CAS 循环：3099 ms
  - mutex：12267 ms

### 4.5 流式写（experiment 17，256MB）

| 模式 | time_ms |
|---|---:|
| 普通写 | 16.9 |
| 流式写（_mm_stream） | 5.3 |

- 流式写快约 3.2 倍（数据不重用场景）。

### 4.6 矩阵优化链（experiment 28，1024³）

| 阶段 | GFLOPS |
|---|---:|
| baseline | 0.92 |
| 分块(64) | 11.9 |
| 分块(32) | 11.1 |

- 分块提升约 13 倍（本机 g++ 已自动优化部分 baseline 列访问；SIMD 阶段未启用，需 ENABLE_AVX2/AVX512）。

## 5. 与论文数据的差异说明

- 论文表 6.2（Core 2 @ 2.66GHz，2007）：318 MFLOPS → 3.35 GFLOPS。
- 本机（i9-14900HX，现代）：优化后 ~12 GFLOPS（未开 SIMD）。
- **本报告所有数字均为本机实测，不与论文数字直接换算**；跨硬件对比仅作量级参考。

## 6. 已知限制

1. **物理地址映射不可控**：experiment 06/07（关联度/冲突）基于虚拟地址探测，现代 CPU 的物理页着色可能削弱效应；输出已打印 CAVEAT。
2. **单节点机器**：NUMA 三实验无法获得远程访问数据，如实跳过。
3. **大页未预分配**：HugePages_Total=0，显式 HugeTLB 实验跳过；THP=madvise 已覆盖透明大页路径。
4. **perf 权限**：perf_event_paranoid=4 下需 root 才能采集事件；脚本已容错。
5. **Cachegrind 未安装**：scripts/cachegrind.sh 输出安装提示；需要时 `sudo apt install valgrind`。
6. **软件预取收益有限**：experiment 16 在本机预取效果不明显（符合论文"预取不一定快"），结果如实呈现。

## 8. 工程深度增强（实验 29 与笔记 35）

在原理实验之外补充了"工程实战中的坑"系列，每个坑均可本机复现：

| 实验 | 本机结果（节选） | 坑 |
