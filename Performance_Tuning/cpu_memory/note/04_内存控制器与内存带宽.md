# 04 内存控制器与内存带宽

> 对应 PDF：第 2.2.4 节 Memory Types（PDFp10~11）、第 2.3 节 Other Main Memory Users（PDFp12~13）；补充第 2.2.5 节 Conclusions（PDFp12）
> 本篇回答：内存带宽从哪来、被谁限制？多通道/多内存控制器如何提高带宽？除了 CPU 还有谁在抢带宽？

## 1. 本章要解决的问题

- 内存带宽 = 什么公式？"有效频率"与营销名称如何换算？
- DDR2/DDR3/FB-DRAM 各自的带宽、引脚、通道数对比。
- 为什么主板内存条数量受限（2 通道 × 2 条 = 4 条）？
- 集成内存控制器、多内存控制器如何突破带宽瓶颈？
- DMA 设备、共享显存系统如何与 CPU 争抢带宽？

## 2. 前置知识

- note/02、note/03：DRAM 单元、行列寻址、突发传输、DDR 的 I/O buffer 架构。
- 总线位宽：数据并行传输的位数（内存总线通常 64 位 = 8 字节）。
- 双泵/四泵（double/quad-pumped）：每个时钟周期传输 2/4 次。
- 内存通道（channel）：内存控制器与内存条之间独立的总线。
- DMA：设备直接读写内存（note/01 已引入）。

## 3. 核心概念

- **Effective Bus Frequency（有效总线频率）**：把多泵传输折算出的频率。200MHz 四泵 = 800MHz 有效。
- **Data Rate / Transfer Rate（数据传输速率）**：有效频率 × 位宽 / 8 = 每秒字节数。例：100MHz×64bit×2 = 1600MB/s。
- **DDR 模块命名**：PC1600 / PC2-6400 / PC3-12800 等，数字来自实际传输速率。
- **Channel（通道）**：内存控制器连接内存条的一条独立总线；通道越多，可并行的数据总线越多。
- **FB-DRAM（Fully Buffered DRAM，全缓冲 DRAM）**：用高速串行总线连接内存模块，引脚少、通道多。
- **Registered / Unregistered Memory**：见 note/02 附录 C。
- **Memory Controller（内存控制器）**：把 CPU 访存请求转成 RAS/CAS 时序，并仲裁所有访存请求。
- **DMA（Direct Memory Access）**：设备绕过 CPU 直接访问内存。
- **Shared Video Memory（共享显存）**：无独立显存的系统把主存当作显存使用。

## 4. 硬件工作流程

### 4.1 带宽公式（论文 2.2.4，PDFp10）

```text
传输速率 (bytes/s) = 有效总线频率 × 总线位宽 / 8
SDR:  cell array f ──► bus f         每周期 1 字（64bit）
DDR1: cell array f ──► 2bit buffer ──► 2f   每周期 2 字
DDR2: cell array f ──► 4bit buffer ──► 4f   每周期 4 字
DDR3: cell array f ──► 8bit buffer ──► 8f   每周期 8 字
```

例：DDR2-800（有效 800MHz，64 位宽）= 800MHz × 8B = 6.4GB/s；双通道 × 2 = 12.8GB/s（论文 2.2.5 结论）。

### 4.2 多通道/多控制器的演进（论文图 2.1~2.3，PDFp3~4 + 2.2.4）

```text
单通道：  MC ──1条总线──► 内存条                （瓶颈：单总线、单端口）
双通道：  MC ──2条总线──► 内存条/内存条          （北桥交错访问，带宽翻倍）
外接多MC： 北桥 ──► MC1 MC2 MC3 MC4              （4 条内存总线，带宽×4）
集成MC：  CPU1(本地内存) CPU2(本地内存) ...      （每 CPU 一条/多条通道，NUMA 起点）
```

- 北桥把访问在通道间交错（interleave）以利用全部带宽。
- 集成内存控制器后，"有多少处理器就有多少内存 bank"，四 CPU 机带宽直接翻四倍，无需巨大带宽的北桥（PDFp4）。

### 4.3 FB-DRAM：串行总线方案（论文 2.2.4，PDFp11~12）

```text
DDR2:  240 引脚/模块, 2 通道, 每通道 2 条,  16GB,  ~10GB/s
FB-DRAM: 69 引脚/模块, 6 通道, 每通道 8 条, 192GB, ~40GB/s
```

- 串行总线可跑更高频率，缓解并行总线信号失真问题。
- 全双工 + 差分信号 + 每模块菊花链，模块数/通道数大幅提升。
- 代价：菊花链逐级增加延迟，串行驱动芯片功耗高。

### 4.4 带宽竞争者（论文 2.3，PDFp12~13）

```text
CPU1 ──► MC ──► DRAM
CPU2 ──► MC      ▲
DMA设备 ────────►│ (网卡/存储控制器 直写内存)
共享显存 ────────►│ (GPU 用主存当显存)
USB/南桥设备 ────►│ (即便不用 DMA 也占用 FSB)
```

## 5. PDF 核心观点

> 来源：PDF 第 10~13 页；对应章节 2.2.4、2.2.5、2.3。以下为概括。

1. **SDR→DDR1 只提高传输不提高频率**（PDFp10）：在 cell array 与总线之间加 I/O buffer，DDR1 上下沿各传一次（双泵）。
2. **DDR2 再把 buffer 带宽翻倍**（PDFp10）：4 bit buffer、四泵总线；只把小小的 I/O buffer 提速，不大动 cell array，几乎不增加功耗。
3. **DDR3 是 8 bit buffer + 1.5V**（PDFp10~11）：电压从 1.8V 降到 1.5V，按 P=C·V²·f 光电压就省约 30%；同频功耗可减半或同功耗翻容量。
4. **命名即传输速率**（PDFp10）：PC1600、PC2-6400、PC3-12800 的数字就是 MB/s，营销上把双泵/四泵折算进"有效频率"。
5. **DDR 并行总线瓶颈**（PDFp11）：240 引脚、等长布线、每通道最多 2 条（DDR2）/高频 1 条（DDR3），北桥最多驱动 2 通道 → 消费级主板最多 4 条内存。
6. **两个解药**（PDFp11）：一是把内存控制器放进 CPU（Opteron/Nehalem CSI），代价是 NUMA；二是 FB-DRAM 用串行总线绕开并行总线限制，6 通道 8 条/通道。
7. **持续带宽能力**（PDFp12, 2.2.5）：DRAM 整行突发可 100% 占满数据总线；DDR 每周期 2 个 64 位字，双通道 DDR2-800 达 12.8GB/s。
8. **DMA 缓解 CPU 但竞争带宽**（PDFp13）：网卡/存储控制器直接读写内存；DMA 流量高时 CPU 等待内存会加剧。
9. **共享显存系统是特例**（PDFp13）：1024×768@60Hz 16bpp 就需要 94MB/s，且系统内存是单端口，访问相互影响。
10. **预取帮助错峰**（PDFp12）：硬件/软件预取让读写错开时间，避免"存上轮的 + 读下轮的"在同时刻撞带宽。

## 6. 通俗解释

把内存带宽想成**加油站的油管**：

- **单通道**：一根油管，一次只能给一辆车加油。
- **双通道**：两根油管并排，一次能同时加两辆——前提是你要的车刚好排在两个口（内存交错）。
- **DDR1/2/3**：油管没变粗（单元频率没变），但加油枪出口速度变快（I/O buffer），枪口喷得快，但"油泵"本身还是那么慢。
- **集成内存控制器**：每家加油站（CPU）门口都有自己的油库（本地内存），加油不用跨城跑，但也出现了"本城便宜、外城贵"的 NUMA。
- **DMA**：快递公司（网卡）直接进仓库搬货，不经过你（CPU）——省了你的事，但也占了仓库通道。

"有效频率"的营销味道：一根 200MHz 的油管，因为四个泵头轮流喷，广告里就写"等效 800MHz"——数字好看了，物理上其实没变快那么多。

## 7. 示例分析

### 7.1 传输速率换算（论文图 2.11 公式，PDFp10）

- DDR 模块 100MHz × 64bit × 2（上下沿）= 1600MB/s = 命名 PC1600。
- DDR2-800：800MHz 有效 × 8B = 6.4GB/s = 命名 PC2-6400。
- DDR3-1600：1600MHz × 8B = 12.8GB/s = 命名 PC3-12800。
- 双通道 DDR3-1600 = 25.6GB/s（对照论文 2.2.5 中双通道 DDR2-800 = 12.8GB/s）。

### 7.2 为什么消费级主板最多 4 条内存

- 每通道 240 引脚，北桥合理上限 2 通道。
- DDR2 每通道最多 2 条、DDR3 高频时 1 条 → 2 通道 × 2 条 = 4 条。
- 想插更多 → 换集成内存控制器（每 CPU 有本地通道）或 FB-DRAM（6 通道 × 8 条）。

### 7.3 谁抢走了带宽

- 一个 10GbE 网卡满速约 1.25GB/s，持续 DMA 会与 CPU 访存争用。
- 共享显存系统 94MB/s 看起来小，但它是单端口内存上的额外流量，且访问模式可能很随机，容易打断 CPU 的顺序流。

## 8. 未优化代码

对应"单线程 + 随机 + 不利用多通道"的程序（带宽利用率最低）。

```cpp
// bad.cpp: 单线程随机访问大数组，带宽与延迟双输
#include <vector>
#include <random>

int main() {
    constexpr int N = 1 << 26;   // 64M int = 256MB，远超 LLC
    std::vector<int> data(N, 1);
    std::mt19937 rng(42);
    long long sum = 0;
    for (int i = 0; i < N; ++i)
        sum += data[static_cast<int>(rng() & (N - 1))];
    return sum == 0;
}
```

## 9. 优化后代码

对应"多线程 + 顺序 + 尽量分摊到多通道"的程序（带宽利用率最高）。

```cpp
// good.cpp: 多线程分块顺序访问，让多个核并发拉满内存带宽
#include <vector>
#include <thread>
#include <atomic>

int main() {
    constexpr int N = 1 << 26;
    std::vector<int> data(N, 1);
    unsigned nthreads = std::thread::hardware_concurrency();
    std::atomic<long long> sum{0};
    std::vector<std::thread> pool;
    for (unsigned t = 0; t < nthreads; ++t) {
        pool.emplace_back([&, t] {
            long long local = 0;
            for (int i = t; i < N; i += (int)nthreads)  // 交错分块，多核并发
                local += data[i];
            sum += local;
        });
    }
    for (auto &th : pool) th.join();
    return sum.load() == 0;
}
```

> 说明：多线程是否真的提高带宽取决于硬件（单核能否打满内存带宽）。验证交给 src/23 实验，
> 不在这里承诺加速比。跨线程局部求和也顺带避免了原子竞争（note/24）。

## 10. 为什么会更快

| 角度 | 单线程随机 | 多线程顺序 |
|---|---|---|
| 内存带宽利用 | 被延迟限死，远低于峰值 | 多核并行，逼近平台峰值 |
| DRAM 行命中 | 差 | 好 |
| 多通道利用 | 单请求流难摊满双通道 | 并发请求流更易交错到各通道 |
| Cache 层 | miss 多 | 顺序 + 预取命中高 |
| TLB | 随机页频繁 miss | 顺序页连续命中 |
| checksum 一致性 | 相同 | 相同（分块求和） |

> 注意：真实加速比必须实测（src/23），严禁凭公式"编造提升百分比"。

## 12. 实验结果应该怎么看

- src/23 的 GB/s：单线程顺序 Copy 的实测值应远低于双通道理论峰值（受延迟、行切换、单核上限等限制）。
- 增大线程数观察 GB/s 是否提升：若不再增长，说明已达内存带宽墙（而不是 CPU 计算墙）。
- 关键点：**带宽墙出现时，加线程/加核没有用**——这正是 note/23"多线程带宽"要演示的现象。
- 对照论文：双通道 DDR2-800 理论 12.8GB/s 只是上界；实测要低得多，属正常。

## 13. 常见误区

- **误区 1：内存带宽 = 内存频率**。带宽 = 有效频率 × 位宽 / 8，与通道数、突发能力都有关。
- **误区 2：多线程一定更快**。工作集小（能进缓存）时多线程反而因共享缓存/一致性开销变慢；只有工作集大、带宽受限时才受益。
- **误区 3：DMA 不影响 CPU**。DMA 减少 CPU 工作，但占内存带宽，可能让 CPU 等内存更久。
- **误区 4：插满 4 条内存就有 4 通道**。多数消费平台内存插槽多于物理通道，插法要成对；通道数由 CPU/主板决定。
- **误区 5：共享显存系统性能也还好**。单端口 + 随机访问 + 持续流量，论文明确建议性能敏感时避开这类机器（PDFp13）。

## 15. 本章总结

- 带宽 = 有效频率 × 位宽 / 8；DDR 系列通过加宽 I/O buffer 提高传输速率，不提高单元频率。
- 多通道、外接多控制器、集成内存控制器是三代提高总带宽的方案，最后一种引出了 NUMA。
- 并行总线限制了每通道模块数（消费级最多 4 条），FB-DRAM 用串行总线突破。
- 带宽不只归 CPU 所有：DMA、共享显存都在抢。
- 对程序员：大工作集下，目标是"顺序访问 + 足够线程数拉满带宽"，且要知道带宽墙的存在。
