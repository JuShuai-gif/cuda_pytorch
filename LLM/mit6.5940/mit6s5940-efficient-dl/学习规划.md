> **课程**: MIT 6.5940 Efficient Deep Learning Computing / TinyML

---

## 1. 课程概览

MIT 6.5940 系统讲授从模型压缩到边缘部署的全栈技术，核心四大方向：

```
剪枝 (Pruning)  →  量化 (Quantization)  →  神经架构搜索 (NAS)  →  知识蒸馏 (KD)
                                    ↓
                          TinyML 系统 (MCUNet + TinyEngine)
                                    ↓
                        LLM 优化 (AWQ / SmoothQuant / StreamingLLM)
                                    ↓
                        工业项目 (压缩→导出→部署→基准测试)
```

**学完你能做到**：把一个 PyTorch 模型通过剪枝+量化+蒸馏压缩 3-10 倍，导出 ONNX/TFLite，部署到手机/MCU/嵌入式设备，并解释每一步的硬件加速原理。
