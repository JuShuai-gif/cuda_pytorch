# 一、数学地基

## 1.1 线性代数
- **矩阵乘法(GEMM)** — `C=AB` 是深度学习最核心运算(全连接/注意力/卷积 im2col 后都是它)。理解其 O(n³) 复杂度与分块(tiling)是 GPU 优化的根;PyTorch 里 `torch.mm/matmul` 最终落到 cuBLAS/MKL。
- **矩阵分解** — SVD(奇异值分解,降维/低秩)、QR(正交化)、Cholesky(正定矩阵解方程/协方差)、LU。用于 `torch.linalg`、低秩适配(LoRA)、白化、数值求解。
- **特征值/特征向量** — 描述线性变换的主方向;PCA、谱归一化、稳定性分析的基础。
- **张量代数与 einsum** — 高维数组的收缩/转置的统一记法 `torch.einsum("bij,bjk->bik")`。掌握它能读懂任意复杂张量运算,是 attention/MoE 实现的通用语言。
- **范数与内积** — L1/L2/Frobenius/谱范数;梯度裁剪、正则化、相似度(cosine)都依赖。

## 1.2 微积分
- **多元链式法则** — 反向传播的数学本质:复合函数梯度 = 各层雅可比连乘。不懂它就无法理解 autograd。
- **雅可比 / 海森矩阵** — 雅可比是向量函数的一阶导(反向传播传的就是"向量-雅可比积" VJP);海森是二阶导,用于二阶优化/曲率分析。
- **矩阵求导** — 标量对矩阵、矩阵对矩阵求导的规则(分子/分母布局)。手推一个 Linear 层的 `dL/dW = x^T · dL/dy` 是入门必修。
- **VJP / JVP** — 反向模式(VJP,autograd)与前向模式(JVP,`functorch.jvp`)自动微分的数学核心 📓`s3_04_functorch`。

## 1.3 概率统计
- **概率分布** — 高斯/伯努利/类别/狄利克雷;`torch.distributions` 提供采样与 `log_prob`,用于生成模型/强化学习/贝叶斯。
- **期望与方差** — 初始化理论(保持激活方差恒定)、BatchNorm、dropout 的期望校正都靠它。
- **最大似然估计(MLE)** — 交叉熵损失 = 负对数似然,分类任务的理论根基。
- **KL 散度 / 交叉熵** — 度量分布差异;蒸馏、变分推断、RLHF 的 PPO 都用。
- **蒙特卡洛** — 用采样估计期望;dropout、VAE 重参数化、随机估计器。

## 1.4 数值分析
- **浮点表示(IEEE754)** — fp32/fp16/bf16/fp8 的符号-指数-尾数结构;决定精度与范围,是混合精度/量化的物理基础。
- **数值误差与条件数** — 舍入误差累积、病态问题;为什么大规模求和要用 Kahan/成对求和。
- **数值稳定化技巧** — logsumexp(避免 exp 溢出)、softmax 减最大值、log1p/expm1、layernorm 的 eps。不做这些就会 NaN。
- **累加顺序与非确定性** — 浮点不满足结合律,GPU 并行归约顺序不定 → 结果非 bit 级一致 📓`s2_05_rng`。

# 二、深度学习理论

## 2.1 反向传播
- **计算图** — 前向构建 DAG,反向按逆拓扑序传梯度。PyTorch 用动态图(define-by-run)🧪`trace_backward`。
- **反向传播算法** — 链式法则在计算图上的高效实现(每个节点存局部导数,复用中间结果)。手推 MLP/CNN/Attention 的反向是分水岭。
- **梯度累积与消失/爆炸** — 深层网络梯度连乘导致的问题;残差连接、归一化、梯度裁剪是对策。

## 2.2 优化
- **SGD / Momentum** — 最基础;momentum 累积历史梯度平滑震荡。
- **Adam / AdamW** — 自适应学习率(一阶+二阶矩估计);AdamW 解耦权重衰减。手推每一项含义 📓`s2_04_optimizer`。
- **学习率调度** — warmup、cosine、step;大模型训练的关键超参。
- **二阶方法** — 牛顿法/L-BFGS/K-FAC;用海森信息加速但代价高。
- **收敛性与泛化** — 凸/非凸、鞍点、平坦极小值与泛化的关系。

## 2.3 网络结构
- **MLP / 全连接** — 最基本单元 `y=Wx+b`。
- **CNN** — 卷积(权值共享/局部感受野)、池化;im2col 转 GEMM。
- **RNN / LSTM / GRU** — 序列建模、门控、梯度问题(已大多被 Transformer 取代)。
- **Transformer / Attention** — `softmax(QK^T/√d)V`;自注意力/多头/位置编码。现代 LLM 核心,必须手推前向+反向 📓`s4_05_sdpa_attention`。
- **归一化** — BatchNorm(批统计)、LayerNorm、RMSNorm(LLM 常用);稳定训练 📓`s2_06_amp`(含 Conv-BN 融合)。
- **残差 / 初始化** — 残差解决深层退化;Xavier/Kaiming 初始化保持方差。

## 2.4 现代架构
- **LLM 架构** — decoder-only、RoPE、KV cache、GQA/MQA。
- **扩散模型** — 前向加噪/反向去噪、U-Net、DDPM/DDIM。
- **MoE** — 稀疏专家、门控路由、负载均衡、专家并行 📓`s5_15_moe`。
- **正则化** — dropout(随机置零+期望校正)、weight decay、label smoothing 📓`s2_05_rng`(compile 下的 dropout)。

# 三、编程语言与工具

## 3.1 Python 深入
- **CPython 对象模型** — 一切皆 `PyObject`,`ob_refcnt` 引用计数、`ob_type` 类型指针。理解 Tensor 如何是一个 Python 对象。
- **GIL** — 全局解释器锁,为什么 DataLoader 用多进程而非多线程 📓`s1_06_dataloader`。
- **引用计数与 GC** — 循环引用、`weakref`;张量生命周期与显存释放时机。
- **C-API / `tp_call`** — C 扩展如何被 Python 调用;`THPVariable_add` 就是 C 函数 🧪`trace_add`。
- **描述符 / 元类** — `nn.Module` 的 `__setattr__` 拦截 Parameter 注册靠它 📓`s1_04_module`。
- **字节码 / frame** — `dis` 反汇编;Dynamo 拦截的就是字节码执行帧 📓`s5_03_dynamo`。
- **`__torch_function__` / `__torch_dispatch__`** — 两级重写协议:前者在 Python API 层拦截,后者在 dispatcher 层拦截(子类/FakeTensor 靠它)📓`s3_05`。

## 3.2 C++ 深入
- **模板 / SFINAE / concepts** — 泛型;dispatcher 的 boxing/unboxing 全是模板元编程。
- **移动语义 / 完美转发** — `std::move`/`&&`/`std::forward`;避免张量拷贝。
- **RAII** — 资源获取即初始化;`DeviceGuard`/`StreamGuard`/`NoGradGuard` 都是 RAII 📓`s4_09_design_patterns`。
- **智能指针** — `shared_ptr` vs `unique_ptr` vs PyTorch 的 `intrusive_ptr` 📓`s1_02_intrusive_ptr`。
- **模板元编程** — 编译期计算;`make_boxed_from_unboxed_functor.h` 是典型 🧪`trace_add`(栈里的 WrapFunctionIntoFunctor)。

## 3.3 构建与调试工具
- **源码编译** — `setup.py`/cmake/USE_CUDA/TORCH_CUDA_ARCH_LIST 🧪`build_debug.sh`。
- **可编辑安装** — PEP 660 editable,改 Python 立即生效 🧪(develop.sh)。
- **ccache** — 编译缓存,重编从小时降到分钟。
- **torchgen** — 从 yaml 生成 C++/Python 绑定,产物在 `build/`。
- **gdb / cuda-gdb** — C++/kernel 断点 🧪`README.md`;`git`/`ghstack`(PR 工作流)。

# 四、计算机体系结构

## 4.1 CPU 📓`s4_07_cpu_arch`
- **流水线 / 乱序执行** — 指令级并行;为什么分支和依赖会拖慢。
- **分支预测** — 预测错误的惩罚;数据相关分支(如逐元素比较)影响性能。
- **cache 层级(L1/L2/L3)** — 访存延迟差几十倍;局部性原理决定算法访存模式。
- **cache 一致性 / false sharing** — 多核共享缓存行导致的伪竞争;线程池设计要避开。
- **SIMD(SSE/AVX2/AVX512)** — 单指令多数据,一条指令算 8/16 个 float;ATen 的 `Vectorized<T>` 就是封装它 🧪(阶段1 `ufunc/add.h` 的 `fmadd`)。
- **内存对齐** — 对齐访问才能用宽向量指令。
- **NUMA** — 多路 CPU 的内存亲和性;跨节点访存慢 📓`s4_07`。
- **内存屏障 / 原子操作** — 多线程同步;lock-free 数据结构与引用计数。
- **线程池** — ATen 的 CPU 并行(`at::parallel_for`/OpenMP)。

## 4.2 GPU 📓`s4_08_cuda_arch`
- **SM / warp / thread block** — GPU 执行层级;32 线程一个 warp 锁步执行(SIMT)。
- **occupancy** — 活跃 warp 占比;受寄存器/shared memory 用量限制,影响延迟隐藏。
- **warp divergence** — 同 warp 内分支不一致导致串行化,性能杀手。
- **显存层级** — global(大慢)/L2/shared(片上快)/register(最快);优化本质是把数据搬到更快的层。
- **合并访存(coalescing)** — 同 warp 连续访存合并成一次事务;非合并访问带宽暴跌。
- **bank conflict** — shared memory 分 bank,同 bank 冲突串行化。
- **Tensor Core** — 硬件矩阵乘单元(fp16/bf16/tf32/fp8);现代 GPU 算力主体,cuBLAS/cuDNN 自动用。
- **roofline 模型** — 性能受算力或带宽哪个限制;算术强度(FLOP/Byte)决定 📓`s5_16_jax_scaling_book`。判断优化方向的第一步。

# 五、并行 / GPU 编程

## 5.1 CUDA 编程
- **kernel / 执行配置** — `__global__` 函数 + `<<<grid, block>>>`;线程如何映射到数据。
- **线程索引** — `blockIdx/threadIdx/blockDim` 计算全局下标。
- **shared memory / `__syncthreads`** — 块内共享的快速缓存 + 同步屏障;tiling 的关键。
- **stream / event** — 异步执行队列 + 计时/同步点 📓`s4_02_cuda_stream`。
- **CUDA Graph** — 把一串 kernel 录制成图,消除 launch 开销 📓(并入 s4_02)。
- **优化技巧** — 合并访存、shared memory tiling、warp shuffle(warp 内通信)、循环展开、减少 bank conflict、寄存器复用。
- **库** — cuBLAS(GEMM)、cuDNN(卷积/RNN/attention)📓`s4_06_cudnn_backend`、CUTLASS(可组合 GEMM 模板)、CCCL(Thrust/CUB 的归约/扫描)。

## 5.2 Triton 📓`s5_07_triton_kernel`
- **Triton 编程模型** — Python 写 GPU kernel,block 级抽象,编译器自动处理合并/shared memory。
- **autotune** — 自动搜索 block size 等配置。
- **与 Inductor 集成** — `torch.compile` 的 GPU 后端生成的就是 Triton 📓`s5_06_inductor` 🧪`stage5_compile`。

# 六、PyTorch 核心内部机制

## 6.1 Tensor 数据结构
- **Tensor** — Python/C++ 用户对象,本质是 `intrusive_ptr<TensorImpl>` 的薄包装 📓`s1_01_tensor`。
- **TensorImpl** — 元数据:sizes/strides/storage_offset/dtype/device/key_set 🧪`stage4_tensorimpl`(gdb 打出 176 字节布局)。
- **Storage / StorageImpl** — 引用计数的连续内存块;多个 Tensor 可共享(view 不拷贝)。
- **Allocator** — 内存分配抽象;CPU 用 malloc,CUDA 用缓存分配器 📓`s4_03_memory_allocator`。
- **stride / view / contiguous** — 步长决定内存布局;view/slice/transpose 只改 stride;`contiguous()` 触发拷贝 📓`s1_01`。
- **channels_last** — 内存格式(NHWC),卷积在 Tensor Core 上更快 📓`s1_01`。
- **intrusive_ptr** — 引用计数嵌在对象内(vs shared_ptr 外置控制块),更省内存/更快 📓`s1_02`。
- **IValue** — tagged union,JIT/dispatcher 的通用值容器(类型擦除)📓`s1_03`。

## 6.2 Dispatcher 与算子
- **DispatchKey / DispatchKeySet** — 标识后端/功能(CPU/CUDA/Autograd/Autocast...);Tensor 带一个位集,取最高优先 key 📓`s3_01_dispatcher` 🧪`stage3_custom_op`。
- **Dispatcher / OperatorEntry** — (算子, key)→ kernel 的查表器。
- **两次分发** — 先命中 Autograd(记反向图)→ redispatch → 命中 backend(算)🧪`trace_add`。
- **boxing / unboxing** — IValue 装箱与还原,统一 kernel 调用约定。
- **TLS exclude / include** — 线程本地开关(如 `no_grad` 关掉 Autograd key)📓`s3_01`。
- **torchgen** — 读 `native_functions.yaml`(声明+dispatch)与 `derivatives.yaml`(求导)生成绑定 📓`s3_02_torchgen`。
- **structured kernel** — meta(形状/dtype 推断)+ impl(计算)分离 📓`s3_02`。
- **composite kernel** — 用其它算子组合实现,无需单独 backend kernel(自动支持所有后端)。
- **TensorIterator** — 逐元素/归约算子的广播+类型提升+并行+向量化引擎 🧪`trace_add`(命中 `build`)。
- **custom op / torch.library** — 注册自定义算子(Python 或 C++ TORCH_LIBRARY)📓`s3_03_custom_ops` 🧪`stage3_custom_op`。

## 6.3 Autograd
- **动态计算图** — 前向即建图,`grad_fn` 链接反向节点 📓`s2_01_autograd`。
- **Node / Edge / Function** — 反向图的节点(如 `MulBackward0`)与连接 🧪`trace_backward`。
- **Engine** — 反向执行引擎:GraphTask + ReadyQueue + `thread_main` 拓扑调度 🧪`trace_backward`。
- **AccumulateGrad** — 叶子节点,把梯度写进 `.grad`。
- **autograd.Function** — 自定义前向/反向;double backward(高阶导)📓`s2_01/mini_pro`。
- **hook** — tensor/module 上的梯度钩子(DDP 梯度同步靠它)📓`s5_13_ddp_reducer`。
- **no_grad / inference_mode / detach** — 关闭梯度追踪的不同层次 🧪`s2_01`(合并的 no_grad 笔记)。
- **version counter** — 检测 inplace 修改破坏反向 📓`s2_03_functionalization`。

## 6.4 函数变换与编译前置
- **functorch / vmap** — 可组合变换:vmap(自动批处理/BatchedTensor)、grad、jacfwd/jacrev、per-sample grad 📓`s3_04`。
- **functionalization** — 把 inplace/view 改写成纯函数(view_copy),编译栈需要 📓`s2_03`。
- **meta tensor / FakeTensor** — 只有元数据无真实数据,用于形状推断与编译期执行 📓`s3_05`。
- **SymInt / 动态 shape** — 符号整数,支持不特化具体尺寸的编译 📓`s3_05`。

## 6.5 内核开发与性能
- **AT_DISPATCH 宏** — 按 dtype 分派模板 kernel。
- **cpu_kernel / cpu_kernel_vec** — 写 CPU 逐元素 kernel(标量+向量化)。
- **gpu_kernel / Loops.cuh / OffsetCalculator** — 写 CUDA 逐元素 kernel。
- **算子融合** — 合并多个逐元素算子成一个,省中间张量读写(Inductor 自动做)🧪`stage5_compile`。
- **profiler** — `torch.profiler`/Nsight,找瓶颈 📓`s4_04_profiler`。
- **SDPA / FlashAttention** — 融合的注意力 kernel,省显存与带宽 📓`s4_05`。
- **benchmark 方法论** — warmup+synchronize+分位数(见 MASTERY_PLAN 附录 J)。

# 七、编译栈(torch.compile)

- **FX** — 符号追踪得到的图 IR(`Graph`/`Node`/`GraphModule`);可读可改写 📓`s5_01_fx_graphs` 🧪`stage5_compile`。
- **graph passes** — 图优化遍:pattern match、常量折叠、DCE(死代码消除)、算子替换 📓`s5_02_graph_passes`。
- **TorchDynamo** — 前端:拦截 Python 字节码,抓成 FX 图;抓不动处产生 graph break;用 guard 保证假设 📓`s5_03_dynamo`。
- **VariableTracker** — Dynamo 内部对 Python 值的符号追踪表示。
- **guard** — 记录输入假设(shape/dtype/id),失效则重新编译 📓`s5_08_compile_debug`。
- **graph break** — Dynamo 无法追踪(Python 副作用/数据依赖控制流)时把图断开,退回 eager 📓`s5_08`。
- **AOTAutograd** — 中端:提前追踪出前向+反向联合图(joint graph),做 decomposition,再用 partitioner 切分前反向 📓`s5_05_aot_autograd`。
- **decomposition** — 把复杂算子拆成基本算子(便于编译器优化)。
- **partitioner** — 决定哪些中间值重算 vs 保存(min-cut,省显存)。
- **TorchInductor** — 后端:把图 lowering 到 Inductor IR,scheduler 做融合与调度,codegen 生成 Triton(GPU)/C++(CPU)📓`s5_06_inductor` 🧪`stage5_compile`。
- **lowering** — 高层 aten 算子降解到 Inductor 的低层 IR。
- **scheduler / fusion** — 决定算子分组融合、buffer 复用、内存规划。
- **codegen** — 生成实际 kernel 源码(Triton/C++ 向量化)🧪`stage5`(看到 `cpp_fused_add_relu_0`)。
- **extern kernel** — 不融合、直接调库的算子(如 matmul→cuBLAS)🧪`stage5`。
- **torch.export** — 导出可移植的静态图(部署用)📓`s5_10_deploy`。
- **compile mode** — `default`/`reduce-overhead`(CUDA Graph)/`max-autotune`(搜最优 kernel)📓`s5_04_torch_compile`。

# 八、分布式与大规模训练

- **集合通信** — all-reduce/all-gather/reduce-scatter/broadcast/scatter/gather 📓`s5_11_collective_operations`。
- **NCCL** — NVIDIA 集合通信库;ring vs tree 算法、拓扑感知、带宽最优 📓`s5_11`。
- **ProcessGroup** — 通信抽象;`init_process_group`、backend(nccl/gloo/mpi)选择 📓`s5_12_torch_dist`。
- **DDP** — 数据并行:每卡完整模型,反向 all-reduce 梯度求平均 📓`s5_13_ddp_reducer`。
- **Reducer / bucket** — DDP 把梯度分桶,边反向边通信(通信-计算重叠)📓`s5_13`。
- **comm hook** — 自定义梯度通信(如压缩/fp16 all-reduce)📓`s5_13`。
- **数据并行(DP/DDP)** — 切分 batch;DP 单进程多线程(废弃),DDP 多进程 📓`s5_14`。
- **张量并行(TP)** — 切分单层权重矩阵(行/列并行),层内通信 📓`s5_14`。
- **流水并行(PP)** — 按层切分到不同设备,micro-batch 流水 📓`s5_14`。
- **ZeRO / FSDP** — 分片优化器状态/梯度/参数,省显存 📓`s5_14`。
- **sequence parallelism** — 沿序列维切分,配合 TP 省激活显存 📓`s5_14`。
- **专家并行(EP)** — MoE 专家分布到多卡,routing 通信(all-to-all)📓`s5_15_moe`。
- **DTensor** — 分布式张量抽象,声明式描述 sharding(现代并行基础)。
- **3D 并行 / 显存估算** — DP×TP×PP 组合;参数/激活/优化器显存核算 📓`s5_16_jax_scaling_book`。
- **梯度累积 / activation checkpoint** — 小显存跑大 batch;用时间换显存 📓`s2_02_checkpoint`。

# 九、数值 / 量化 / 混合精度 / 内存

- **AMP / autocast** — 自动混合精度,算子按白/黑名单选 fp16/fp32 📓`s2_06_amp`。

- **PTQ / QAT** — 训练后量化 vs 量化感知训练(fake quant 模拟量化误差)📓`s5_09`(合并的 ptq_qat)。
- **LLM 量化** — LLM.int8()/AWQ/GPTQ/SmoothQuant(离群值处理、逐层校准)📓`s5_09`。
- **caching allocator** — CUDA 显存缓存分配器,避免频繁 cudaMalloc;碎片/`expandable_segments` 📓`s4_03_memory_allocator`。
- **显存优化** — activation checkpoint、offload(CPU/NVMe)、`memory_summary`/snapshot 诊断 📓`s4_03`。
