# CS336 LLM System 学习规划

> **目标**：从零掌握现代 LLM 全栈技术 —— Tokenization / Transformer / Distributed Training / CUDA / Inference
> **哲学**：`accuracy = efficiency × resources` —— 每个设计决策都是资源约束下的最优解

---

## 一、前置要求

| 领域          | 最低要求                             | 推荐 |
| ------------- | ------------------------------------ | ---- |
| Python        | 熟练使用 PyTorch, einops             |      |
| 线性代数      | 矩阵乘法、softmax、梯度反向传播      |      |
| 概率论        | 交叉熵、条件概率                     |      |
| Linux / Shell | git, conda/uv, 命令行基础            |      |
| GPU 概念       | 知道 GPU 有显存（HBM）和计算单元（SM） | 有 CUDA 基础更好  |
| 时间投入       | 每天 3-4 小时，共 10 周              | 每周至少 25 小时 |

---

## 二、总体路线图

```
第1周  Tokenization + 资源计算          → 理解数据和算力
第2周  Transformer + 训练基础           → 从零写一个 GPT
第3周  GPU 架构 + Triton Kernel         → 理解硬件瓶颈
第4周  分布式训练 (DDP/FSDP/TP/PP)      → 多卡训练原理
第5周  Attention 深度剖析               → GQA/MQA/MLA/FlashAttention
第6周  归一化 + 激活函数                → 架构选择的工程理由
第7周  推理系统 Part1 (KV Cache)       → 推理为什么 memory-bound
第8周  推理系统 Part2 (PagedAttention)  → vLLM 原理
第9周  数据 Pipeline                    → 数据清洗/去重/混合
第10周 Alignment + 综合项目             → RLHF/DPO + mini_llm_system
```

## 八、学习建议

1. **先读 note，再读代码**：note 给出直觉，代码给出细节
2. **每学完一个 lecture 就动手**：只看不写 = 没学
3. **手算**：自己动手算 FLOPs、memory、bandwidth，不要只依赖工具
