## 通用运行方式

```bash
# 每个子目录的脚本以 python 直接运行（需先编译安装 triton）
python <子目录>/xxx.py

# 记录结果
python <子目录>/xxx.py > <子目录>/RUN.log 2>&1
```

## 完成规则

1. 每次实验必须能跑通（有输出、有校验通过）。
2. 记录：运行命令、关键输出、错误与解法 → 写进该目录 `README.md` 或 `RUN.log`。
3. 实验完成后在 `30_最终总结.md` 勾选"尚未验证"条目。
