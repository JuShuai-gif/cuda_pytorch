## 2. AGENTS.md 准则（深度）

### 构建
- 改 native/编译器 → 先 `make` 重编再测。
- 只改 Python → **不要**跑 `make`。

### 测试
- 编译器改动：加 `python/test/`（pytest）或 `test/`（lit）。
- GPU 测试：`python/test/unit/` 或 `python/test/gluon/`，命名 `test_<feature>_<condition>`。
- 避免新建测试文件（除非必要）。
- `pytest -s --tb=short`，单个 `pytest file.py::test_name`。

### lit
```bash
BUILD_DIR := $(shell PYTHONPATH="./python" python3 -c 'from build_helpers import get_cmake_dir; print(get_cmake_dir())')
cd $BUILD_DIR; ninja triton-opt; lit -v test/<path>.mlir
```
- lit 本地跑，无需 GPU。

### 崩溃
- 保存 `mlir_reproducer` + `{-# ... #-}` 到 `/tmp/x.mlir`。
- `triton-opt /tmp/x.mlir --run-reproducer`。

### C++
- `assert` 里不放副作用代码。
