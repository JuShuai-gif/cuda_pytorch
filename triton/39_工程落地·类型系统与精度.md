# 39 工程落地·类型系统与精度（深度版）

> 本类问题的共性：GPU 编程的类型/精度决策影响正确性（溢出、精度丢失）与性能（mma 支持的 dtype）。难点在于"**推导规则要正确、不支持的组合要拒绝**"。

## 机制 1：参数类型的 signature 推导

### 约束
- `@triton.jit` 函数参数类型由运行时实际参数推导。
- 类型串（如 `*fp32`）决定代码生成。

### 实现（`compiler.py:78` `ast_to_ttir`）
```python
# src.signature 如 {'x': '*fp32'}
base_type = str_to_ty(...)   # 参数类型 → base_type
```

> **不变量 T1**：参数类型必须由实际参数唯一确定，参与 specialization 与缓存键。

### 工程判断
- **类型推导参与特化**：`specialization` 元组（类型 + 常量）决定 kernel 变体——**类型系统是 JIT 特化的核心**。

## 机制 2：constexpr 类型标注

### 约束
- `tl.constexpr` 参数是编译期常量，形状/循环依赖它。

### 实现（jit.py `_pack_args`）
- constexpr 提取为 `constexprs`，参与 `src.hash()`。

> **不变量 T2**：constexpr 值不同 → 不同 kernel 变体（不同缓存键）。

### 工程判断
- **编译期常量显式化**：`tl.constexpr` 让编译器知道"这是静态值"，从而特化。
- 与 TileLang 的 `T.const`/`compile(n=...)` 同构。

## 机制 3：mma 的 dtype 支持矩阵

### 约束
- 不是所有 dtype 组合都支持 mma。
- 不支持的必须拒绝或显式降级。

### 实现（`Utility.cpp:1105-1183` supportMMA）
```cpp
// v5 (Blackwell): 只允许 i8×i8→i32, 禁止 f64
// v3 (Hopper): fp8/i8/f16/bf16/f32, 禁 f64, k>=256/bitwidth
// f32×f32 非 TF32 一律 false
```

> **不变量 T3**：mma 版本选择必须满足该版本的 dtype/shape 支持矩阵，否则降级/拒绝。

### 工程判断
- **能力矩阵显式化**：`supportMMA` 是"每个 mma 版本支持什么"的显式清单。
- **拒绝边界**：fp8 在 FMA 下无意义（`supportMMA` 拒绝），int8 需特定约束——**不支持的组合宁可降级也不静默错算**。

## 机制 4：TF32 与精度模拟（F32DotTC）

### 约束
- fp32 dot 可用 TF32（精度损失）或 FMA（慢但精确）。
- 模拟 TF32 需特殊 pass。

### 实现（`F32DotTC.cpp` + `emuTF32 = capability//10 >= 8`）
- capability≥80 时 `f32_dot_tc` 用 TF32 模拟。

> **不变量 T4**：精度相关决策（TF32 模拟）必须按架构显式开启。

### 工程判断
- **架构决定精度策略**：`emuTF32` 由 capability 推导，不是用户瞎猜。
- `TRITON_F32_DEFAULT`（knobs）控制 fp32 默认行为——**精度策略可配置**。

## 机制 5：fp8 支持与架构门控

### 约束
- fp8 dtype（fp8e4b15/fp8e4nv）不同架构支持不同。

### 实现（`nvidia/backend/compiler.py:202-205`）
```python
if capability >= 89: supported_fp8_dtypes.add("fp8e4nv")
# fp8e4b15 仅 SM90+ 标 deprecated
```

> **不变量 T5**：fp8 dtype 支持必须按架构门控（capability 决定可用集合）。

### 工程判断
- **能力随架构演进**：新架构解锁新 dtype（SM89 解锁 fp8e4nv）——**能力矩阵动态化**。
- deprecated 标记：旧 dtype 保留兼容但警告——**兼容性与清晰度平衡**。

## 本类工程判断总结

1. **类型系统是 JIT 特化的核心**（signature/constexpr 参与缓存键）。
2. **能力矩阵显式化**（supportMMA 按 dtype/shape 拒绝）。
3. **架构决定精度策略**（TF32 模拟按 capability）。
4. **fp8 按架构门控 + 兼容警告**。
5. **不支持的组合宁可降级也不静默错算**。
