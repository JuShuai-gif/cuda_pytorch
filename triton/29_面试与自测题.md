# 29 面试与自测题（深度版）

## 1. 概念题

### Q1：Triton 是什么？
**加分**：基于 MLIR 的块级 GPU 语言，AST→ttir→ttgir→llir→ptx→cubin 五阶段编译，布局用 GF(2) LinearLayout。与 TileLang 最大区别：IR 栈（MLIR vs TVM TIRX）。

### Q2：和 CUDA 关系？
**加分**：program=CTA、`num_warps`=blockDim、布局系统自动分配 threadIdx，最终生成 mma/cp.async 指令（driver.c 用 cuLaunchKernelEx）。

### Q3：和 TileLang 区别？
**加分**：布局数学本质（GF(2) 矩阵 vs 显式表达式）、pass 可定制性、缓存键、mma 模板（自研 PTX vs CUTLASS）。

## 2. 原理题

### Q4：JIT 编译链？
**加分**：`kernel[grid](args)` → JITFunction.run(jit.py:727) → 进程内缓存 → miss → _do_compile(jit.py:879) → compile()(compiler.py:226) → 磁盘缓存(get_cache_key cache.py:319) → 五阶段 → CompiledKernel。缓存键 = triton_key + src.hash + backend.hash + options.hash + env_vars。

### Q5：布局系统？
**加分**：LinearLayout 是 GF(2) 矩阵，BlockedEncodingAttr(sizePerThread/threadsPerWarp/warpsPerCTA/order) 转 LL。布局转换 = invertAndCompose。RemoveLayoutConversions 把转换推到 load/splat 处吸收。

### Q6：mma 降级？
**加分**：getMMAVersionSafe（AccelerateMatmul.cpp:43）按 arch 选版本（CC<90→v2, <100→v3, <120→v5）。MMAv2.cpp 生成 `mma.sync.aligned.m16n8k16.row.col.f32.f16.f16.f32`，每线程 A4/B2/C4 寄存器。FMA.cpp 兜底。

### Q7：软件流水线？
**加分**：assign_latencies 赋 latency → schedule_loops 写 loop.stage → pipeline（lowerLoads 生成 cp.async + 多缓冲 alloc，PipelineExpander 拆 prologue/kernel/epilogue）。buffer 份数 = getDefUseStageDiff（stage 差）。

## 4. 深挖题

### Q11：为什么 LinearLayout 用 GF(2)？
**加分**：布局映射本质是硬件位→张量位的排列，GF(2) 上可做矩阵代数（直和、伪逆），使 convert_layout 可计算；比显式函数更适合大规模 pass。

### Q12：给 Triton 加算子？
**加分**：language/core.py 语义 + Dialect TableGen + TritonGPUToLLVM 降级 + 测试。

### Q13：缓存为何失效？
**加分**：src.hash 含 AST hash + 起始行号（挪行也失效）；triton_key 含 libtriton 二进制 hash（改编译器失效）；TRITON_ALWAYS_COMPILE 强制。

### Q14：num_stages 如何影响 IR？
**加分**：loadLatency=(numStages-1)/(maxIndirectionLevel+1)，buffer 份数=stage 差，prologue/epilogue 变长。
