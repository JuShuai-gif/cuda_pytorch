## 3. 读 ttgir 关键（深度）

```mlir
#ttg.blocked = #ttg.blocked<{sizePerThread=[1,4], threadsPerWarp=[1,32], warpsPerCTA=[4,1], order=[1,0]}>
#ttg.mma = #ttg.mma<{versionMajor=2, warpsPerCTA=[4,1], instrShape=[16,8]}>
%acc = tt.dot %a, %b, %acc :
  tensor<128x64xf16, #ttg.dot_op<{opIdx=0, parent=#ttg.mma}>>
```
看：
- `#ttg.mma`：mma 生效。
- `ttg.dot_op`：dot 操作数布局。
- `ttg.local_alloc` 的缓冲份数（流水线深度）。
- `ttg.convert_layout` 数量。

## 4. m16n8k16 的 PTX（深度）

`MMAv2.cpp:439`：
```cpp
{TensorCoreType::FP32_FP16_FP16_FP32,
 "mma.sync.aligned.m16n8k16.row.col.f32.f16.f16.f32"}
```

寄存器形状（:823-825）：`NumRegisters = {2, 1, 2}`（m 2 个、n 1 个、k 2 个）。

操作数打包（`getValuesFromDotOperandLayoutStruct` :73）：
- A（opIdx=0）：按 `batch→m→k→vk→vm` 顺序（:242）。
- B（opIdx=1）：按 `batch→n→k→vk→vn`（:249）。

`callMmaV2`（:622）构造操作数列表：
- 输出 4 个 fp32（`numMmaRets`）。
- A 4 个寄存器（2 行×2 k）。
- B 2 个寄存器。
- C 4 个累加（复用输出）。

## 5. wgmma（Hopper）/tcgen05（Blackwell）

- wgmma：`WarpGroupDotOpConversion`（DotOpToLLVM.cpp:122）→ `convertWGMMA`（WGMMA.cpp:377）。
  - `WgmmaFenceAlignedOp` 开场（:261）。
  - `WGMMAOp` 循环（:338）。
  - `WgmmaGroupSyncAlignedOp` + wait（:360）。
- tcgen05：`TCGen5MMAOpConversion`（MMAv5.cpp:924）。
  - 只有 warp 0 执行（elect 谓词）。
  - 累加器在 TMEM（tmemLoad）。
  - 指令描述符位域（:145）。
  - `tcgen05.mma.cta_group::<1|2>.kind::<f16|...>`（:362）。

## 6. FMA 兜底（深度）

- 走 `BlockedEncodingAttr`（DotOpToLLVM.cpp:86）。
- `FMA.cpp` `multiplyVectors`（:18）：浮点 `llvm.fmuladd`；整数 Mul+Add。
- `FMADotUtility.cpp` `parametricConvertFMADot`（:78）：六重循环点积。
