> **不变量 M1**：分配的共享内存总量 ≤ 硬件/驱动允许上限，且复用区间不重叠。

### 工程判断
- **动态共享内存的上限处理**：48KB 是分水岭，超过需显式允许——**硬件约束显式化**。
- 分配分析（`Allocation.cpp`）保证复用正确性。

## 机制 2：TMEM 分配（Blackwell）

### 约束
- Hopper/Blackwell 的 TMEM（tensor memory）是 mma 累加器的专用存储。
- TMEM 分配有对齐/数量约束。

### 实现（`make_llir` 调 `allocate_tensor_memory`；`HoistTMEMAlloc` pass）
- `TensorMemoryEncodingAttr` 描述 TMEM 布局。
- `HoistTMEMAlloc` 把分配外提到循环外（避免重复分配）。

> **不变量 M2**：TMEM 分配必须在循环外完成（hoist），且不重复分配。

### 工程判断
- **循环不变量的外提**：TMEM 分配是循环不变量，hoist 是标准的 LICM 应用。
- 专用存储（TMEM）需要专用分配路径——**新硬件特性 = 新工程机制**。

## 机制 3：流水线多缓冲（版本化）

### 约束
- `num_stages` 缓冲，producer 写、consumer 读。

### 实现（`PipeliningUtility.cpp:389-406` createAlloc）
```cpp
bufferShape.insert(bufferShape.begin(), distance);   // 第一维 = stageDiff
Type memdescType = ttg::MemDescType::get(bufferShape, ..., sharedEnc, ...);
```
- 循环携带 insertIdx/extractIdx 取模递增（`createIncrementModulo`）。

> **不变量 M3**：多缓冲版本互不冲突（写版本 ≠ 读版本），缓冲份数 = stage 差。

### 工程判断
- **复用 = 版本化**：把"同一逻辑 buffer"变"多个物理版本"，用取模索引轮转——**用空间换并发安全**。
- 与 TileLang 的 `[3,M,K]` 前插维度同构。

## 机制 4：swizzle 共享内存（bank conflict 规避）

### 约束
- 32 bank，同 bank 访问串行化。

### 实现（`SwizzledSharedEncodingAttr` → `LinearLayoutConversions.cpp:50-96`）
```cpp
for (int row = 1; row < numRows; row *= 2) {
  int vec = shared.getVec(); int perPhase = shared.getPerPhase(); int maxPhase = shared.getMaxPhase();
  bases2D.push_back({row, (vec * ((row / perPhase) % maxPhase)) % numCols});  // xor swizzle 进基向量
}
```

> **不变量 M4**：swizzle 后同一 warp 对同一列的访问分散到不同 bank。

### 工程判断
- **内存布局本身即优化**：swizzle 编码进共享内存布局的基向量（GF(2) 表示直接支持）。
- **这是 LinearLayout 可计算性的体现**：swizzle 作为布局属性参与代数运算。

## 机制 5：寄存器分配（fragment 元素数）

### 约束
- 每线程元素数由布局决定，寄存器溢出 → spills。

### 实现（`mmaVersionToInstrShape` 等）
- 每线程 A/B/C fragment 元素数由指令形状推导（如 fp16 m16n8k16 → A4/B2/C4）。

> **不变量 M5**：fragment 每线程元素数必须匹配 mma 指令的寄存器要求。

### 工程判断
- **布局即分配**：指令形状决定每线程寄存器数，编译器保证匹配——布局推断是寄存器分配的抽象。

## 本类工程判断总结

1. **硬件约束显式化**（shared 48KB 分水岭、TMEM 专用）。
2. **复用必须有可证明依据**（分配分析、版本不重叠）。
3. **循环不变量外提**（TMEM hoist）。
4. **布局本身即性能**（swizzle 编码进布局）。
5. **布局即分配**（每线程元素数匹配指令）。
