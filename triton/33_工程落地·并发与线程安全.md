# 33 工程落地·并发与线程安全（深度版）

> 本类问题的共性：编译器是**多线程 + 多进程**系统——异步编译、多进程共享缓存、后端发现。难点在于"**并发读写的正确性**"。

## 机制 1：缓存原子写——并发进程安全

### 约束
- 多进程可能同时编译同一个 kernel，写同一缓存目录。
- 不能留下半写文件。

### 实现（`runtime/cache.py:103-127`）
```python
rnd_id = str(uuid.uuid4()); pid = os.getpid()
temp_dir = os.path.join(self.cache_dir, f"tmp.pid_{pid}_{rnd_id}")
os.makedirs(temp_dir, exist_ok=True)
with open(temp_path, "w") as f: f.write(data)
os.replace(temp_path, filepath)   # POSIX 原子替换
os.removedirs(temp_dir)
```

> **不变量 C1**：任何进程读到的缓存文件要么完整旧版，要么完整新版，绝不半写。

### 工程判断
- **用文件系统原子性代替进程间锁**：注释明确"Replace is guaranteed to be atomic on POSIX systems"。
- 多进程同时写 → last-write-wins，但每次都是完整文件——**不引入锁，靠原子性兜底**。

## 机制 2：后端发现——entry points 与 in-tree

### 约束
- 支持多种后端（nvidia/amd），通过 entry points 插件化。
- 发现过程要快，且冲突要报错。

### 实现（`backends/__init__.py:52`）
```python
if TRITON_BACKENDS_IN_TREE == "1":
    # 只扫 in-tree 目录，跳过 entry point（快）
    for name in os.listdir(root): ...
else:
    for ep in entry_points().select(group="triton.backends"):
        ...
```

> **不变量 C2**：后端发现结果必须唯一确定（同环境同结果）。

### 工程判断
- **快路径/慢路径**：`TRITON_BACKENDS_IN_TREE=1` 跳过慢的 entry point 发现——与双检锁同构的"快路径"思想。
- **歧义拒绝**：多个活跃 driver 时报错而非瞎猜（`runtime/driver.py:23`）。

## 机制 3：device 缓存的线程隔离

### 约束
- `JITFunction.device_caches` 按 device 隔离（`jit.py:810` `defaultdict(self.create_binder)`）。
- 不同 device 的编译互不干扰。

> **不变量 C3**：任一 device 的缓存只被该 device 的请求访问。

### 工程判断
- **按 key 隔离状态**：device 作为缓存字典的 key，天然隔离并发——**用数据结构设计避免锁**。

## 机制 4：异步编译的线程池

### 约束
- `_async_compile`（jit.py:887-902）异步编译，不阻塞主线程。
- 结果要在完成后正确写回缓存。

### 实现
```python
def async_compile():
    return self.compile(src, target=target, options=options.__dict__)
def finalize_compile(kernel):
    kernel_cache[key] = kernel
kernel = async_mode.submit(cache_key, async_compile, finalize_compile)
```

> **不变量 C4**：异步编译结果最终必须写回正确的 cache key。

### 工程判断
- **提交时携带 key 和回调**：异步任务完成时回调负责写回，避免"谁写回"的竞态。
- 与 TileLang autotuner 的 queue + idx 归位同构。

## 本类工程判断总结

1. **用文件系统原子性代替进程间锁**。
2. **按 key/device 隔离状态**：用数据结构设计避免锁。
3. **快路径/慢路径分离**：in-tree 快发现，entry point 慢但全。
4. **歧义拒绝**：多活跃者报错。
5. **异步结果带 key + 回调写回**。
