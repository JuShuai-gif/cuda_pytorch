## 3. 任务二：C++ pass（完整模板，深度）

在 `lib/Dialect/TritonGPU/Transforms/` 新建 `MyPass.cpp`：
```cpp
#include "mlir/IR/IR.h"
#include "mlir/Pass/Pass.h"
#include "triton/Dialect/TritonGPU/IR/Dialect.h"

namespace mlir {
namespace ttg {
struct MyPass : public PassWrapper<MyPass, OperationPass<ModuleOp>> {
  MLIR_DEFINE_EXPLICIT_INTERNAL_INLINE_TYPE_ID(MyPass)
  void runOnOperation() override {
    llvm::errs() << "[MyPass] running\n";
  }
};
}  // namespace ttg
}  // namespace mlir
```

**关键点**：
1. 命名空间 `mlir::ttg`。
2. `PassWrapper` 模板。
3. 需要在 `Transforms/CMakeLists.txt` 加源文件（与 TileLang 不同，Triton 不是 glob）。

验证：
```bash
make            # 增量编译
bin/triton-opt --ttgpu-my-pass test/TritonGPU/xxx.mlir
```

lit 测试（`test/TritonGPU/my_pass.mlir`）：
```mlir
// RUN: triton-opt %s --ttgpu-my-pass | FileCheck %s
// CHECK: ...
```
