# Particle Swarm Optimization (PSO) - 粒子群优化

## 算法原理

PSO 模拟鸟群觅食行为。每个"粒子"代表搜索空间中的一个候选解，粒子通过跟踪两个"极值"来更新自己的位置和速度：

1. **个体最优 (pbest)**: 粒子自身历史最优位置
2. **全局最优 (gbest)**: 整个种群历史最优位置

速度更新公式：

```
v_i = w * v_i + c1 * r1 * (pbest_i - x_i) + c2 * r2 * (gbest - x_i)
```

其中 `w` 为惯性权重，`c1, c2` 为学习因子，`r1, r2` 为随机数。

## CUDA 并行化策略

- **适应度评估**: 每个线程独立计算一个粒子的适应度值
- **全局最优查找**: 使用块内并行归约 (parallel reduction) 找出适应度最小的粒子
- **位置/速度更新**: 每个线程独立更新一个粒子的位置和速度
- **同步更新模式**: 所有粒子在同一迭代内使用相同的全局最优，保证 GPU 并行一致性

## 适用场景

| 适用 | 不适用 |
|------|--------|
| 连续空间优化问题 | 离散 / 组合优化问题 |
| 多峰值函数优化 (如 Rastrigin, Ackley) | 约束复杂的优化问题 |
| 神经网络超参数搜索 | 需要严格收敛证明的场景 |
| 机器人路径规划 (连续空间) | 高维稀疏搜索空间 |
| 大规模种群 (GPU 优势明显) | 小规模种群 (CPU 开销更低) |

## 运行方式

python robot/particle_swarm/pso.py
