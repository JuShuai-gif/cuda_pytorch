# Particle Swarm Optimization (PSO) - 粒子群优化

## 算法原理

PSO 模拟鸟群觅食行为。每个"粒子"代表搜索空间中的一个候选解，粒子通过跟踪两个"极值"来更新自己的位置和速度：

1. **个体最优 (pbest)**: 粒子自身历史最优位置
2. **全局最优 (gbest)**: 整个种群历史最优位置

速度更新公式：

```
v_i = w * v_i + c1 * r1 * (pbest_i - x_i) + c2 * r2 * (gbest - x_i)
```

其中 `w` 为惯性权重，`c1, c2` 为学习因子，`r1, r2` 为随机数。

## CUDA 并行化策略

- **适应度评估**: 每个线程独立计算一个粒子的适应度值
- **全局最优查找**: 使用块内并行归约 (parallel reduction) 找出适应度最小的粒子
- **位置/速度更新**: 每个线程独立更新一个粒子的位置和速度
- **同步更新模式**: 所有粒子在同一迭代内使用相同的全局最优，保证 GPU 并行一致性

## 适用场景

| 适用 | 不适用 |
|------|--------|
| 连续空间优化问题 | 离散 / 组合优化问题 |
| 多峰值函数优化 (如 Rastrigin, Ackley) | 约束复杂的优化问题 |
| 神经网络超参数搜索 | 需要严格收敛证明的场景 |
| 机器人路径规划 (连续空间) | 高维稀疏搜索空间 |
| 大规模种群 (GPU 优势明显) | 小规模种群 (CPU 开销更低) |

## 实际落地案例

| 场景 | 具体案例 |
|------|----------|
| 无人机编队路径规划 | 大疆 FlightAutonomy：数百架无人机同时优化无碰撞轨迹 |
| 天线阵列波束赋形 | 5G 基站 Massive MIMO，PSO 优化 64+ 天线相位权重 |
| 电池 SOC 估计 | 电动汽车 BMS 用 PSO 在线拟合电池等效电路模型参数 |
| 神经网络超参搜索 | AutoML 框架替代 grid search，搜学习率/层数/dropout |
| PID 控制器自整定 | 工业机器人关节电机 PID 参数自动优化 |

## 改进方向

| 方向 | 来源 | 说明 |
|------|------|------|
| 自适应惯性权重 | 学术: Shi & Eberhart (1998) | w 从 0.9 线性递减到 0.4，平衡探索与开发 |
| 协作 PSO (CPSO) | 学术: Van den Bergh (2004) | 高维空间拆分为多个低维子群，各群独立优化后组合 |
| 量子粒子群 (QPSO) | 学术: Sun et al. (2004) | 用量子势阱代替速度项，全局收敛性有理论保证 |
| 多群排斥 PSO | 工业: 大疆/Apollo | 多个子群并行 + 群间排斥力，防止整体陷入局部最优 |
| 环形拓扑 | 学术: Kennedy (1999) | 每粒子只与邻居通信，收敛慢但全局搜索能力更强 |
| GPU 寄存器优化 | 工程 | 粒子状态放寄存器、减少 global memory 访存、合并 reduction kernel |
| 贝叶斯 PSO | 学术 | 用高斯过程建模目标函数，减少昂贵适应度评估次数 |
