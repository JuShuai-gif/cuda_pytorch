# Genetic Algorithm (GA) - 遗传算法

## 算法原理

GA 模拟自然选择和遗传进化机制。种群中的每个个体代表一个候选解，通过选择、交叉、变异操作逐代进化：

1. **选择 (Selection)**: 锦标赛选择 - 随机选取 k 个个体，适应度最好的胜出
2. **交叉 (Crossover)**: 算术交叉 - 两个父代按比例混合产生子代
3. **变异 (Mutation)**: 高斯变异 - 在基因上添加正态分布噪声
4. **精英保留 (Elitism)**: 保留每代最优的若干个个体，防止退化

## CUDA 并行化策略

- **适应度评估**: 每个线程计算一个个体的适应度，完全并行
- **锦标赛选择**: 每个线程独立为一个新个体选择父代
- **交叉变异**: 每个线程独立生成一个新个体的全部基因
- **精英复制**: GPU kernel 将最优个体复制到新种群头部

## 适用场景

| 适用 | 不适用 |
|------|--------|
| 黑箱函数优化 (无需梯度) | 需要精确梯度的优化 |
| 组合优化问题 (TSP, 调度) | 严格实时系统 |
| 多目标优化 (如 NSGA-II) | 在线学习场景 |
| 神经网络架构搜索 (NAS) | 低维凸优化 (梯度法更快) |
| 大规模种群 (GPU 优势明显) | 小种群 (< 1000) |

## 实际落地案例

| 场景 | 具体案例 |

| 物流路径规划 (VRP) | 美团/饿了么骑手调度：2000 单 × 500 骑手，GA 秒级出方案 |

| 蛋白质结构预测 | Rosetta@home 早期用 GA 搜索折叠构象空间 |

## 改进方向

| 方向 | 来源 | 说明 |
|------|------|------|
| NSGA-II 多目标 | 学术: Deb et al. (2002) | Pareto 前沿 + 拥挤度排序，同时优化多个目标（如精度 vs 功耗） |
| NSGA-III 超多目标 | 学术: Deb & Jain (2014) | 4+ 目标时用参考点代替拥挤度，避免维度灾难 |
| CMA-ES | 学术: Hansen (2006) | 协方差矩阵自适应，连续空间收敛速度远超标准 GA |
| 代理模型辅助 | 工业: 芯片设计/超参搜索 | 用 GBDT/GP 预测适应度，只有最有希望的个体才做真实评估 |
| 孤岛模型 (Island GA) | 学术+工业 | 多个子种群 GPU 独立进化，定期迁移优秀个体，天然适合多 GPU |
| 混合局部搜索 | 工业 | GA 全局搜索 + 爬山法/模拟退火局部精化 = Memetic Algorithm |
| 自适应变异率 | 工业 | 根据种群多样性动态调整交叉/变异率，避免早熟 |
