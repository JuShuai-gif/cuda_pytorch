# Ant Colony Optimization (ACO) - 蚁群优化

## 算法原理

ACO 模拟蚂蚁觅食行为。蚂蚁在路径上留下信息素，后续蚂蚁倾向于选择信息素浓度高的路径，正反馈机制使群体逐渐收敛到最优路径：

1. **路径构建**: 每只蚂蚁根据信息素浓度和启发式信息 (距离倒数) 概率选择下一城市
2. **信息素更新**: 所有蚂蚁完成巡游后，在路径上沉积信息素 (量与路径长度成反比)
3. **信息素蒸发**: 每轮信息素按比例蒸发，避免过早收敛

选择概率公式：

```
P(i→j) = (τ_ij^α * η_ij^β) / Σ(τ_ik^α * η_ik^β)
```

其中 `τ` 为信息素，`η = 1/d` 为启发式因子，`α, β` 控制信息素和启发式的重要性。

## CUDA 并行化策略

- **蚂蚁巡游构建**: 每个线程块处理一只蚂蚁，使用 shared memory 存储已访问标记
- **信息素沉积**: 每只蚂蚁使用 `atomicAdd` 并行向边上沉积信息素
- **信息素更新**: 每个线程更新一条边，蒸发 + 沉积同步完成
- **全局最优查找**: 块内并行归约找最短巡游

## 适用场景

| 适用 | 不适用 |
|------|--------|
| TSP 及其变体 (VRP, CVRP) | 连续空间优化 |
| 网络路由优化 | 实时性要求高的场景 |
| 机器人路径规划 (离散栅格) | 搜索空间过小 (< 50 节点) |
| 调度问题 (Job Shop Scheduling) | 需要精确最优解 (ACO 是近似算法) |
| 大规模蚂蚁种群 (> 1000) | 信息素维度过高 (> 10000 节点) |

## 实际落地案例

| 场景 | 具体案例 |
|------|----------|
| PCB 钻孔路径 | 电路板数百个钻孔的最短走刀路径，华为/富士康产线在用 |
| 快递末端配送 (CVRP) | 顺丰末端配送：多车 + 容量约束 + 时间窗联合优化 |
| 数据中心网络路由 | Google B4 SDN 用类蚁群算法做实时流量工程 |
| 灾害救援路径 | 地震后多救援队任务分配，动态避开坍塌道路 |
| 药物分子路径 | 计算机辅助药物设计中搜索最优合成路径 |

## 改进方向

| 方向 | 来源 | 说明 |
|------|------|------|
| MAX-MIN Ant System | 学术: Stützle & Hoos (2000) | 信息素上下界限制，防止某条路径过早垄断 |
| 排序蚂蚁系统 (RAS) | 学术: Bullnheimer (1999) | 只让前 k 名蚂蚁沉积信息素，精英策略 |
| 混合 2-opt/3-opt | 工业: 物流调度 | ACO 全局搜索 + 局部 2-opt 边交换精化，大幅提升 TSP 质量 |
| 动态 TSP | 学术+工业 | 城市位置/数量在线变化（实时配送），信息素动态更新 |
| 多蚁群并行 | 学术+GPU 工程 | 多个独立蚁群并行搜索，周期交换最优解，天然适配 GPU |
| 启发式函数学习 | 学术: 强化学习 + ACO | 用 RL 学习信息素更新策略，替代人工调参 |
| 信息素矩阵稀疏化 | 工程 | 大规模问题（>1万节点）剪枝无关边，减少显存占用 |
