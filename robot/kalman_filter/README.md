# Kalman Filter - 卡尔曼滤波 (Batch Parallel)

## 背景

卡尔曼滤波是**状态估计**的基石算法，广泛应用于：
- 自动驾驶多目标跟踪（同时跟踪数百个车辆/行人）
- 雷达/激光雷达传感器融合
- 机器人定位（SLAM 前端）
- 导弹制导、航天器导航
- 金融时间序列预测

核心思想：利用系统动力学模型（预测）+ 传感器观测（更新），递归估计系统状态及其不确定性。

## 三种变体

### 1. 标准卡尔曼滤波 (KF)

**适用**: 线性系统

| 步骤 | 公式 |
|------|------|
| 预测 | x̂ = F·x, P = F·P·Fᵀ + Q |
| 卡尔曼增益 | K = P·Hᵀ·(H·P·Hᵀ + R)⁻¹ |
| 更新 | x = x̂ + K·(z - H·x̂) |
| 协方差更新 | P = (I - K·H)·P |

- **状态转移矩阵 F**: 恒速度模型，x(t+dt) = x(t) + vx·dt
- **观测矩阵 H**: 直接观测位置 (x, y)

### 2. 扩展卡尔曼滤波 (EKF)

**适用**: 非线性观测模型（如雷达）

| 步骤 | 公式 |
|------|------|
| 非线性观测 | z_pred = h(x̂) = [√(x²+y²), atan2(y,x)] |
| 雅可比矩阵 | H = ∂h/∂x = [[px/ρ, py/ρ, 0, 0], [-py/ρ², px/ρ², 0, 0]] |
| 其余同 KF | 用 H_jac 替代线性 H |

### 3. 无迹卡尔曼滤波 (UKF)

**适用**: 强非线性系统（EKF 的雅可比近似不够精确时）

| 步骤 | 说明 |
|------|------|
| Sigma 点生成 | 从均值 x 和协方差 P 生成 2n+1 个采样点（n=状态维度） |
| 传播 | 每个 sigma 点通过非线性函数 F 传播 |
| 重构 | 加权求和重构预测均值 x̂ 和协方差 P̂ |
| 观测传播 | 每个 sigma 点通过观测函数 h 传播 |
| 更新 | 计算互协方差 Pxz 和观测协方差 Pzz，计算 K = Pxz·Pzz⁻¹ |

UKF 比 EKF 精度更高（可达二阶泰勒展开精度），但计算量也更大（需要传播 2n+1 个点）。

## CUDA 并行化策略

**批处理并行**：同时运行 N 个独立的卡尔曼滤波器（每个滤波器跟踪一个目标）

| 滤波器 | CUDA 策略 | 说明 |
|--------|----------|------|
| KF | 每线程一个滤波器 | 每个线程独立完成 predict + update |
| EKF | 每线程一个滤波器 | 每个线程计算雅可比 + predict + update |
| UKF | 每滤波器一个 block，每 sigma 点一个 thread | 9 个 sigma 点的传播完全并行 |

对于 5000 个目标，每个时间步只需一次 kernel launch，所有滤波器同时更新。

## 性能对比

```
5000 个对象 × 100 个时间步

                          CUDA      CPU      加速比    RMSE(位置)
KF  (linear measurement)   0.086s    5.433s   63x      0.590
EKF (radar measurement)    0.006s    5.892s   967x     0.406
UKF (radar, sigma-point)   3.132s   32.888s   10.5x    0.643
```

- KF/EKF 与 CPU 结果一致（RMSE ratio ≈ 1.0）
- UKF 因 GPU 端 Cholesky 简化和 sigma 点生成在 CPU，略有差异
- EKF 在非线性雷达场景下效果优于 KF（RMSE 0.406 vs 0.590）

## 适用场景

| 适用 | 不适用 |
|------|--------|
| 大规模多目标跟踪 (> 100 目标) | 单目标跟踪 (CPU 已足够) |
| 实时雷达/激光雷达数据处理 | 离线数据分析 |
| 多传感器融合 (GPS+IMU+Radar+LiDAR) | 传感器数量少 (< 3) |
| 自动驾驶感知系统 | 简单线性系统 (KF GPU 提升有限) |
| 机器人 SLAM 后端优化 | 小状态维度 (n < 4) |
