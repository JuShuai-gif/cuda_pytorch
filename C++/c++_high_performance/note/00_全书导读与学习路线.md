> 本笔记基于 PDF《C++ High Performance - Boost and optimize the performance of your C++ 17 code》(Packt Publishing, 2018) 编写。
> 全书 PDF 共 **362 页**。正文从 PDF 第 24 页开始。
>
> 页码约定：本书所有引用统一采用 **PDF 页码**（与阅读器显示一致，即 `pdfinfo` 报告的第 N 页）。

## 1. 本书基本信息

| 项目 | 内容 |
|---|---|
| 书名 | C++ High Performance - Boost and optimize the performance of your C++ 17 code |
| 作者 | Viktor Sehr, Bjorn Andrist |
| 出版社 | Packt Publishing |
| 成书日期 | 2018 年 1 月（C++17 发布当年） |
| 全书篇幅 | 362 页（PDF），正文 11 章 + 附录 |
| 适用标准 | C++17（书中大量特性已进入 C++20/23 的后续演进） |

**核心主张（PREFACE + 第 1 章）**：C++ 的"零成本抽象"使它既能保持 C 级别的高性能，又能提供比 C 更安全、更抽象的表达能力。全书围绕"如何写出既抽象又高性能的 C++"展开。

## 6. 四条学习路线

### 路线一：现代 C++ 基础（先修）
```
Chapter 1 → Chapter 2 → Chapter 5 → Chapter 6
```
目标：掌握语言核心（值语义、move、lambda、迭代器、STL 算法），建立"抽象不昂贵"的正确心智。
配套：note 01、02、05、06；src chapter01/02/05/06。

### 路线二：性能工程（主线，与路线一可并行）
```
Chapter 3 → Chapter 4 → Chapter 7 → Benchmark → perf → 汇编分析
```
目标：掌握测量方法论、数据结构选择、内存布局与自定义内存管理，形成"先测量后优化"的工作流。
配套：note 03、04、07、12、13；src common（benchmark 基础设施）、chapter03/04/07。

### 路线三：高级泛型编程（进阶）
```
Chapter 5 → Chapter 6 → Chapter 8 → Chapter 9
```
目标：掌握迭代器抽象、元编程、编译期计算、惰性求值与代理对象。
配套：note 05、06、08、09。

### 路线四：并发与并行（进阶）

## 7. 内容来源三类标注规范

本项目所有笔记内容按以下三类区分，并强制标注：

| 类别 | 标记 | 说明 |
|---|---|---|
| PDF 内容 | `> 来源：PDF 第 XX～XX 页 / 原始章节：Chapter X / 原始小节：…` | 提炼作者观点、保留组织逻辑、中文重新解释，不逐句翻译、不大段复制 |
| 原理解释 | `> 原理补充：以下内容用于帮助理解，不是 PDF 原文。` | 补充编译器/OS/CPU 层面原理（内联、类型擦除、SBO、cache locality、ABI、vtable、copy elision、指令重排、cache coherence、false sharing 等） |
| 现代化补充 | `> 现代补充：以下内容不是原书内容，而是 C++20/C++23 或当前工具链中的对应实现。` | 覆盖 Ranges、Parallel STL 支持现状、concepts、span、jthread、pmr、expected、协程、Boost Compute、OpenCL 等 |
