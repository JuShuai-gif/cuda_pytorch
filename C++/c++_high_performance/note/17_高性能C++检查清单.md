# 17 高性能 C++ 检查清单

> 综合全书的落地检查清单：写高性能 C++ 前、中、后各阶段该检查什么。
> 每项尽量关联本项目实验，供快速定位验证方法。

---

## 1. 编写前：设计层面

- [ ] 用 STL 算法替代手写循环（Chapter 6）→ `src/chapter06_algorithms`
- [ ] 选择正确的容器：`vector`/`array` 优先，避免链表/`map` 默认（Chapter 4）
- [ ] 数据连续存放，关注 cache locality（Chapter 4）→ `chapter01/contiguous_vs_pointer`
- [ ] 避免过早优化：先测量热点（Chapter 3）
- [ ] 用 RAII 管理资源（Chapter 1）→ `chapter01/raii_resource`
- [ ] 类保持值语义 / 明确所有权（Chapter 2）→ `chapter02`

## 2. 编写中：代码层面

### 数据结构与内存
- [ ] 结构体按对齐/填充优化布局（Chapter 4）
- [ ] 预分配容器容量（`reserve`），避免反复扩容（Chapter 4）
- [ ] 减少堆分配：栈、`variant`、SBO（Chapter 4/7）
- [ ] 用 `const` 表达意图（Chapter 1）→ `chapter01/const_correctness`

### 算法与迭代器
- [ ] 用迭代器抽象而非裸指针（Chapter 5）
- [ ] 用 range-based for 或算法，不用下标裸循环（Chapter 6）
- [ ] 检查算法复杂度：O(n²) 是否可换 O(n log n)（Chapter 4/6）

### 元编程与编译期
- [ ] 能用 `constexpr`/编译期计算则用（Chapter 8）
- [ ] 复杂模板代码隐藏在库接口后（Chapter 8）
- [ ] 用 type traits/concept 约束，避免 SFINAE 泥潭（Chapter 8）

## 3. 并发与并行（Chapter 10/11）

- [ ] 共享可变数据有 mutex/atomic 保护（无数据竞争）→ `chapter10/data_race`
- [ ] `std::thread` 必然 join/detach（或用 `std::jthread`）→ `chapter10/threads_basics`
- [ ] 多把锁用 `std::lock` 一次获取（无死锁）→ `chapter10/deadlock`
- [ ] 条件变量等待用 `while` 而非 `if`（spurious wakeup）→ `chapter10/producer_consumer`
- [ ] `shared_ptr` 只把"引用计数"当线程安全 → `chapter10`
- [ ] CPU 密集线程数 ≈ 核数；避免争用与伪共享 → `chapter10/false_sharing`
- [ ] 并行谓词不抛异常、不加锁（`par_unseq`）→ `chapter11/execution_policies`
- [ ] 优先 `std::execution` 策略而非手写并行 → `chapter11/par_transform`
- [ ] GPU：先测数据搬运开销，勿盲信加速比 → `chapter11/boost_compute`

## 6. 反模式快速自查

| 反模式 | 正确做法 |
|---|---|
| 循环里做字符串拼接 | 用 `reserve` + `append`，或 `ostringstream` |
| 频繁 `new/delete` 小块 | 栈/`variant`/对象池（Chapter 7） |
| 大对象按值传参 | `const&` 或 `std::move` 入参 |
| `std::map` 当默认字典 | 数据量小时 `vector<pair>` + 线性查找更快（Chapter 4） |
| 全函数不加 `const` | 能 const 则 const |
| 裸 `delete` | RAII / 智能指针 |
| 全局可变状态 | 尽量不可变 + 显式同步 |
