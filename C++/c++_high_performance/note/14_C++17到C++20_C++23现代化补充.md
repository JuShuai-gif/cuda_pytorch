# 14 C++17 到 C++20/C++23 现代化补充

> 现代补充：以下内容不是原书内容，而是 C++20/C++23 或当前工具链中的对应实现。
> 原书基于 C++17（2018 年出版），本章梳理后续标准对书中各主题的演进。

---

## 1. 为什么需要这份补充

- 书中部分 API 在 C++17 时尚属实验性/第三方（Ranges、`is_detected`、Parallel
  STL 部分）；C++20/C++23 已把它们标准化或演进；
- 本项目以 C++17 为主编写（`CMAKE_CXX_STANDARD 17`），本笔记说明升级路径；
- 用现代写法重写书中示例可更简洁，但**性能结论需要重新实测**。

## 2. 主题演进对照

### 2.1 Ranges（书中 Chapter 6）

> 书中用 Range V3 库演示视图与管道；C++20 已并入标准 `<ranges>`。

```cpp
// C++20 ranges：惰性视图 + 管道（书中 Range V3 写法已内建）
auto odd_positive = std::views::filter([](int v) { return v > 0; })
                  | std::views::filter([](int v) { return (v % 2) == 1; });
```

- `std::views::filter/transform/take` 等惰性视图：**不拷贝、按需求值**；
- 项目 CMake 有 `ENABLE_CPP20_EXAMPLES` 选项，对应 chapter06 的 ranges 实验。

### 2.2 concepts（书中 Chapter 8 模板元编程）

- C++20 `concept` 让约束比 `enable_if_t`/SFINAE 更可读；
- 书中 `is_detected` + `enable_if` 的"按能力分派"，可用 concept 直接表达：

```cpp
template <typename T>
concept HasName = requires(T t) { t.name(); };

void print(HasName auto& t);   // 约束替代 enable_if 样板
```

- 编译错误信息远好于 SFINAE（约束违反直接报概念名）。

### 2.3 编译期计算（书中 Chapter 8 constexpr）

- C++20 `constexpr` 支持更多语法（try、动态分配、虚函数、`std::vector`）；
- `consteval`：**强制**编译期求值（普通 `constexpr` 只在需要时求值）；
- `constinit`：强制常量初始化（静态存储期）：
  ```cpp
  constinit auto hash = hash_function("abc");  // 必须在编译期初始化
  ```

### 2.4 Parallel STL（书中 Chapter 11）

- 书中预测"未来会有 GPU 执行策略"；C++20/23 未增加新内置策略，
  但 `std::execution` 已稳定（`<execution>` + TBB 后端，本项目 chapter11 实测）；
- C++23 `std::views::chunk` / `zip` 等让并行分块更表达性；
- 真正的异构并行仍依赖第三方（Boost.Compute/OpenCL，本项目已集成实测）。

### 2.5 并发（书中 Chapter 10）

- `std::jthread`（C++20）：析构自动 `join`，解决"忘 join 就 abort"的陷阱；
  支持线程取消（`std::stop_token`）；
- `std::atomic` 成员函数补齐：`wait`/`notify`（C++20）；
- `std::latch` / `std::barrier`（C++20）：一次性 / 复用同步屏障；
- `std::counting_semaphore` / `std::binary_semaphore`（C++20）；
- `std::hardware_destructive_interference_size`（C++17，本项目伪共享实验已用）。

### 2.6 内存（书中 Chapter 7）

- `std::pmr`（C++17 已入）：`monotonic_buffer_resource` 等内存池；
  书中的自定义分配器示例可改用 pmr；
- `std::span`（C++20）：非拥有视图，避免裸指针+长度；
- C++23 `std::hazard_pointer` / `std::rcu`：无锁再分配安全回收（新增）；
- `std::shared_ptr` 的 `enable_shared_from_this` 约束更严格（C++17 起）。

### 2.7 错误处理（书中 Chapter 1/2）

- `std::expected`（C++23）：函数式错误处理，比异常/错误码都更可控：

```cpp
std::expected<int, std::error_code> divide(int a, int b);  // C++23
```

- `std::optional` 与异常的选择依然是工程决策（书中 Chapter 1 有对比）。

### 2.8 其它

- 结构化绑定、if/switch init（C++17，书中已覆盖）；
- C++20 三路比较 `<=>` 自动生成比较运算符（替代 Chapter 8 反射 `reflect()` 的
  手写部分）；
- `std::format`（C++20）：`printf`/`cout` 的类型安全替代（本书仍用 `printf` +
   `print_result`，因工具链与简洁性）。

## 3. 本项目里用到的 C++17 特性（现代化改写参考）

| 书中示例 | C++17 写法（本项目） | C++20+ 升级 |
|---|---|---|
| `enable_if` 分派 | `<type_traits>` + `enable_if_t` | `concept` |
| 编译期哈希 | `constexpr` 函数 | `consteval` / `constinit` |
| 伪共享 padding | `alignas(hardware_destructive_interference_size)` | 同 |
| 索引循环并行 | `LinearRange` + `for_each(par)` | `views::iota` + `for_each(par)` |
| 手写 `join` 线程 | `std::thread` + `join` | `std::jthread`（自动 join） |
| Ranges | Range V3（chapter06 可选） | `std::views` |

## 4. 迁移建议

- **先正确后升级**：功能等价再换写法，跑通既有 tests；
- **逐特性验证**：升级到 concept/ranges/jthread 后用项目 tests 回归；
- **性能重测**：标准库实现变化（libstdc++ 版本）可能改变优化结果，
  用 `src/common/benchmark.hpp` 重新测量；
- **注意编译器要求**：C++20/23 特性需较新 GCC/Clang；本项目基线 GCC 13.3
  完整支持 C++20、部分 C++23。
