## 5. 工作原理

### 5.1 迭代器概念与指针语法

> 来源：PDF 第 129～133 页
> 原始小节：The iterator concept / Pointer-mimicking syntax

逻辑上迭代器有三个基本操作：`is_end()`、`read()`、`step_fwd()`（C++ 中没有
这些命名函数，是 PDF 为讲解而设）。C++ 用指针语义实现：

| 逻辑操作 | C++ 运算符 | 示例 |
|---|---|---|
| `step_fwd()` | `operator++` | `++it` |
| `step_bwd()` | `operator--` | `--it` |
| `step(n)` | `operator+=` | `it += 5` |
| `read()` | `operator*` | `auto v = *it` |
| `is_end()` | `!=` 与 end 比较 | `it != end` |

因为模拟指针，任何算法都能同时接受裸指针与迭代器。

### 5.2 迭代器类别

> 来源：PDF 第 130～131 页
> 原始小节：Iterator categories

- input/output：单遍读/写（`*it; ++it`）；
- forward：可多遍；bidirectional：可后退；random access：任意步 O(1)；
- 类别继承：random_access ⊃ bidirectional ⊃ forward ⊃ input。

本书成书时无 contiguous_iterator（C++20 才加入），PDF 中列为特殊情况
（vector/string/array 的迭代器）。

### 5.3 iterator_traits 与五个关联类型

> 来源：PDF 第 134 页
> 原始小节：Iterator traits

自定义迭代器需声明：`difference_type`、`value_type`、`reference`、`pointer`、
`iterator_category`。`std::iterator_traits<Iterator>` 读取它们（裸指针自动适配）。
作者明确：**使用 `std::iterator_traits<Iterator>`，不要直接用
`Iterator::iterator_category`**（PDF 135 页）。

C++17 直接在类内定义这些 using 即可；C++11 需继承已废弃的 `std::iterator`。

### 5.4 按类别分派（iterator_distance）

> 来源：PDF 第 135 页
> 原始小节：Implementing a function using iterator categories

```cpp
if constexpr (is_same_v<Category, random_access_iterator_tag>) {
    return b - a;           // O(1)
} else {
    // 循环计数：O(n)
}
```

`if constexpr` 在编译期选择实现，运行期零开销。

### 5.5 浮点线性范围

> 来源：PDF 第 136～142 页
> 原始小节：Practical example – iterating floating point values

`for (float t=0; t<=1; t+=0.1f)` 到不了 1.0（0.1 不精确）。解法：按索引迭代，
`value = start + step*idx`（`get_linear_value`）。`LinearRangeIterator` 只存
`start_/step_size_/idx_`，`operator*` 返回计算值 → `reference=T`、`pointer=void`。

`LinearRange<T>` 提供 `begin()/end()`，`make_linear_range()` 推导类型。
C++17 的 CTAD 使 `LinearRange{0.0f, 1.0f, 4}` 无需 `make_` 工厂。

## 7. 简单示例

```cpp
// 即时生成 0..4（不占用存储）
class IntIterator {
    int v_;
 public:
    bool operator!=(const IntIterator& o) const { return v_ != o.v_; }
    int& operator*() { return v_; }
    IntIterator& operator++() { ++v_; return *this; }
};
for (auto it = IntIterator{0}; it != IntIterator{5}; ++it) { /* 0 1 2 3 4 */ }
```

## 8. 未优化版本

- `for (float t = 0; t <= 1; t += 0.1f)`：浮点累积误差导致终点不可达（PDF 136 页）。

## 9. 优化版本

- `LinearRange` 按索引计算（`start + step*idx`），无累积误差；
- 用迭代器/范围封装，可用 STL 算法（`std::copy` 到 vector/set）。

## 10. 为什么可能更快（逐维度分析）

| 维度 | 分析 |
|---|---|
| 时间复杂度 | `iterator_distance`：random access O(1) vs 循环 O(n) |
| 空间复杂度 | 生成式迭代器只存状态（O(1)），不存整个序列 |
| 动态内存分配 | 无（不构造容器） |
| Cache Locality | 无数据 → 无缓存问题 |
| 函数调用和内联 | 模板迭代器内联后与手写循环等价 |
| 编译期计算 | `if constexpr` 类别分派零运行期开销 |

## 11. 该优化什么时候可能无效

- **只需一次遍历**：生成式迭代器省内存，但若调用方要反复访问同一元素
  （多遍遍历），forward 类别不支持 → 需存结果；
- **需要引用/写入**：`reference=T`（计算值）不支持 `*it = x` 语义；
- **复杂度**：封装迭代器比直接 for 循环抽象度高，学习成本；
- **依赖实现**：类别标签必须准确，错误标签会让算法走慢路径或 UB。

## 13. 汇编观察点

- 模板迭代器 `-O2` 下内联为指针循环（无函数调用）；
- `if constexpr` 分派无运行期分支；
- `LinearRangeIterator::operator*` 内联为 `fma`/乘加指令。

## 14. 常见错误

- 忘记定义五个关联类型 → `iterator_traits` 不完整，算法编译失败；
- 用 `Iterator::iterator_category` 而非 `iterator_traits`（作者明确反对）；
- `reference`/`pointer` 对生成式迭代器错误定义为 `T&`/`T*`（应为 `T`/`void`）；
- 正向 `std::copy` 用于"反向"区间 → 死循环/坏分配（本实验早期版本踩过）；
- 类别声明错误（如把 bidirectional 声明成 random access）→ 算法走错路径。

## 15. 实践练习

1. **简单**：给 `IntIterator` 加 `operator+=(int n)` 并升级为
   random_access_iterator_tag，验证 `iterator_distance` 走 O(1) 路径；
2. **简单**：写一个 `StepIterator`（每次 `++` 跳 n 步），用于遍历奇数/偶数；
3. **中等**：给 `LinearRange` 加 `operator==` 支持的范围比较，或用它
   做 `std::accumulate`；
4. **中等**：实现一个 `ZipIterator`：同时迭代两个容器，`operator*` 返回
   `std::pair<T&, U&>`；
5. **困难**：实现一个输出迭代器 `OStreamIterator`（写入即打印），
   验证其满足 output_iterator 类别并可配合 `std::copy`。

## 17. 本章总结

- 迭代器是 STL 算法与容器解耦的桥梁：模拟指针语法；
- 类别标签 + `iterator_traits` 让编译器知道迭代器能力，按能力选算法；
- 自定义迭代器声明五个关联类型后即可与标准算法协作；
- 生成式迭代器（按索引算值）解决浮点精度问题，还省内存；
- `LinearRange`/`make_linear_range` 让"数值区间"成为一等公民。
