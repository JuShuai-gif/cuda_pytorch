## 1. 项目概况

笔记 + 可编译运行实验 + 综合实践 + 脚本，覆盖全书 11 章 + 附录。

- 笔记：`note/`（00~19 共 20 篇，含全章节 + 补充 + 术语 + 完成报告）；

- 综合实践：`projects/`（4 个独立工程）；
- 脚本：`scripts/`（构建/运行/benchmark/perf/汇编/sanitizer）；
- 基准结果：`benchmark_results/`（时间戳分目录，可复现）。

## 6. 已知限制与环境说明

- **perf 采样**：`perf_event_paranoid=4`，需 root；脚本检测并提示；
- **TSan 运行**：Ubuntu 24.04 + 新内核 ASLR 导致 `unexpected memory mapping`，
  需 `vm.mmap_rnd_bits=28` 或换 clang（编译可用，运行受限）；
- **Clang**：未安装，`assembly.sh` 自动跳过；
- **GCC 13 libstdc++**：`<execution>` 谓词抛异常直接 `terminate`
  （与书中 GCC 7 行为不同，已记录于 note/11）；
- **OpenCL 头文件**：位于 `/usr/local/cuda-12.8/.../include/CL`，CMake 已自动探测；
- 未初始化 git 仓库跟踪（用户未要求提交）；`.gitignore` 已忽略构建产物。

## 7. 使用方式

```bash
# 构建与测试
./scripts/build.sh                        # Release 构建到 build/
./scripts/run_all.sh                      # 运行全部 example
for t in build/*/*_tests; do ./$t; done   # 全部正确性测试

# 性能
./scripts/benchmark_all.sh                # 全部 benchmark → benchmark_results/<ts>/
./scripts/perf_stat.sh ./build/ch01_zero_cost/ch01_lvc_benchmark

# 汇编
./scripts/assembly.sh src/chapter08_metaprogramming/compile_time_hash/example.cpp

# Sanitizer
./scripts/sanitizer_test.sh               # ASan/UBSan/LSan
./scripts/thread_sanitizer_test.sh        # TSan（本机运行受限）

# 综合项目
cmake -S projects -B build-projects && cmake --build build-projects -j
```
