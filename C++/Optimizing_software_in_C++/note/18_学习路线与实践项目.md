# 18 学习路线与实践项目

> 本笔记为全书综合（无独立 PDF 章节），提供三条学习路线、配套实验顺序与一组综合实践项目，供读者按目标选择学习路径。

## 1. 本章解决什么问题

笔记很多（01-16 + 清单 17），读者容易迷失。本章给出**按目标组织的三条路线**和**由浅入深的综合项目**，并回答"读完后能做什么"。

## 2. 核心概念

- **路线** = 按主题把笔记与实验串成序，直达某个能力目标；
- **项目** = 综合运用多条路线知识的完整练习。

## 3. 工作原理

每条路线遵循本书方法论："先测量，再优化"。先会测量（路线二），再谈吃透 CPU（路线三），而基础（路线一）是任何路线的前置。

## 5. 综合实践项目

三个递进项目，综合运用各路线：

### 项目一：图像亮度调整（入门）

对一张 4096×4096 的 float 灰度图做 `out[i] = clamp(in[i] * gain)`。

- 步骤：基础标量版（路线一）→ 自动向量化版（`-mavx2`，路线三）→ AVX2 intrinsics 版 → CPU dispatch 版。
- 验证：三版结果一致（校验和）；`perf stat` 对比；`-S` 确认向量化。

### 项目二：矩阵乘法优化（进阶）

对 1024×1024 的 float 矩阵做 `C = A * B`。

- 步骤：朴素版（列主序访问慢）→ 行主序优化 → 分块（tiling，PDF 第 108 页）→ 多线程（数据分解 + 局部累加）→ AVX2 向量化。
- 验证：各版结果一致；从"未优化"到最终版记录加速比；`perf stat -e cache-misses` 解释分块收益。

### 项目三：热循环剖析报告（综合）

选一个真实计算热点，产出一份完整报告：

1. 用 `perf record -g` 定位热点（路线二）；
2. 分析瓶颈类型：cache-misses / branch-misses / 依赖链（perf + 汇编）；
3. 实施 2-3 项针对性优化；
4. 用正确的 Benchmark（预热 + 多轮 + 中位数 + Release）前后对比；
5. 用 17 笔记清单复查，写明每项优化的适用性与局限。

## 6. 未优化代码

以项目一为例的起点：

```cpp
// Naive grayscale scaling.
float clampf(float v) { return v < 0.f ? 0.f : (v > 255.f ? 255.f : v); }
void scale(const float *in, float *out, size_t n, float gain) {
    for (size_t i = 0; i < n; ++i) out[i] = clampf(in[i] * gain);
}
```

## 8. 为什么会更快

- 项目一：分支（clamp）用 `_mm256_min_ps/_mm256_max_ps` 无分支向量化；AVX2 一次 8 个 float。
- 项目二：行主序避免列访问的缓存竞争；分块提升 L2/L3 命中率；多线程用数据分解；AVX2 向量化内层。
- 项目三：测量驱动，每步优化都有数据支撑。

## 9. 如何验证

每个项目都用统一验证模板：

```bash
# 编译 Release
cmake -S src -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j

# 运行（内置预热 + 多轮 + 校验和一致性检查）
./build/<project>/<name>

# perf 定位与解释
sudo perf stat -e cycles,instructions,cache-misses,branch-misses ./build/<project>/<name>

# 汇编确认
objdump -d -S ./build/<project>/<name> | grep -E "ymm|vaddps"
```

## 10. 常见误区

- **误区一：三路线都要同时学。** 按目标选一条主线，其他作补充。
- **误区二：做完项目一就够了。** 项目二/三才是真实世界的复杂度（缓存竞争、并行、向量化叠加）。
- **误区三：优化完不写报告。** 记录"为什么改、快了多少、局限在哪"是学习闭环。

## 11. 实践任务

1. 选定一条路线，1-2 周内完成其笔记 + 实验。
2. 完成项目一（独立完成，不看答案）。
3. 完成项目二，记录每一步的加速比与 cache-misses 变化。
4. 给项目三写一份 2 页报告，用 17 笔记清单自查。
5. 选一个你自己代码库中的真实热点，走完整优化流程。

## 12. 本章总结

- 三条路线分别服务：基础写作、性能分析、CPU/SIMD 深入。
- 综合项目把知识串成能力：测量 → 定位 → 优化 → 验证。
- 任何路线/项目的终点都是同一条方法论：**先测量，再优化。**
