## 1. 项目概述

本项目将 Agner Fog 的《Optimizing software in C++》整理成一套可系统学习 C++ 性能优化的中文教程，由三部分组成：

| 部分 | 位置 | 内容 |
|------|------|------|
| 中文技术笔记 | `note/` | 18 篇主题笔记 + 导读 + README，所有观点标注 PDF 页码 |
| 可编译实验 | `src/` | 18 组 C++17 实验，每组含 baseline / optimized / benchmark |
| 自动化脚本 | `scripts/` | 构建、运行、批量 Benchmark、perf 分析 |

核心原则：

1. **先测量，再优化。** 所有优化结论必须能通过编译、运行、Benchmark 或 perf 验证（PDF 第 15～21 页、第 167 页）。
2. **结论优先来源于 PDF。** 每条关键观点都标注页码，例如"来源：PDF 第 92～95 页"。
3. **补充现代背景知识需明确标记。** 本书是跨 2004-2026 的长期修订版本，涉及年代、CPU 型号或编译器版本的结论都注明适用范围，并以下列格式标记补充内容：

> 补充说明：以下内容不是 PDF 原文，而是为了帮助理解增加的现代背景知识。

## 6. 本机验证环境

本教程的代码和验证结论基于当前这台机器，实验中会标注"当前环境实测"或"当前环境未验证"。

| 项目 | 当前环境 | 对实验的影响 |
|------|----------|--------------|
| CPU | Intel Core i9-14900HX（Raptor Lake，P+E 混合架构），32 逻辑线程 | 多线程实验需注意 E 核与 P 核差异 |
| 指令集 | SSE4.2 / AVX / **AVX2**，**无 AVX-512** | AVX2 实验可实测；AVX-512 实验只能编译并通过 CPUID 保护运行 scalar/SSE/AVX2 版本 |
| Cache | L1d 896 KiB（24 实例，每核约 48KB）、L2 32 MiB、L3 36 MiB | 与 PDF 第 92 页的 8KB/512KB 示例差异大，Cache 竞争实验需按本机规模设计 |
| 编译器 | g++ 13.3.0（无 clang） | 以 GCC 为主；笔记中补充 Clang 对应选项 |
| CMake | 4.1.3 | 支持较新特性 |
| perf | 6.17.13，但 `perf_event_paranoid=4` | **perf 需要 root 或降低 paranoid 值**，脚本会检测并提示 |

> 补充说明：`perf_event_paranoid=4` 时普通用户无法读取硬件性能计数器。实验脚本将自动检测，若无法使用会给出 `sudo sysctl kernel.perf_event_paranoid=1` 或 `sudo perf ...` 的提示，这与任务书"提示可能需要修改 perf_event_paranoid"的要求一致。

## 8. 书写规范说明

1. **页码标注**：所有来自 PDF 的观点使用"来源：PDF 第 X 页"或"对应章节：X.Y ..."格式。
2. **补充标记**：非 PDF 原文的现代背景知识，一律用引用块标注"补充说明"。
3. **适用范围**：当结论依赖 CPU 型号、编译器版本、指令集或操作系统时，明确注明"在当前 g++ 13.3 / i9-14900HX 上……"。
4. **未验证标注**：无法在当前机器验证的内容（如 AVX-512 实测）必须写"当前环境未验证，以下为理论分析或待验证实现"。
5. **禁止**：只翻译、只写概念不写代码、编造性能数据、未编译就声称可运行。
