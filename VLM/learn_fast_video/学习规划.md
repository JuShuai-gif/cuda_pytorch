# FastVideo 学习计划：每天 45 分钟，从入门到精通

**一句话定位**：FastVideo 是统一的视频生成后训练与实时推理框架，支持 21 个模型族（Wan/Hunyuan/Cosmos/Flux2 等），提供 DiT 扩散模型的端到端后训练（微调/LoRA/蒸馏）和极速推理（VSA 稀疏注意力、CFG gating、MoE 双专家切换），约 1.8 秒生成 5 秒视频。

**总时长**：约 8 周（35 个学习日），前 7 天可跳过到第 1 周核心。

**重要性说明**：
- ⭐⭐⭐⭐⭐ = 必须掌握（不然后续无法理解）
- ⭐⭐⭐⭐   = 核心理解（面试/开发中常见）
- ⭐⭐⭐     = 重要但可先走读（用到再细看）
- ⭐⭐       = 了解即可（高级/特定场景）

### 1. 推理部署架构

```
┌───────────────────────────────────────────────────────┐
│  在线服务层                                            │
│  FastAPI / Gradio / OpenAI 兼容 API                   │
│  → entrypoints/video_generator.py                     │
└────────────────────┬──────────────────────────────────┘
                     │
┌────────────────────▼──────────────────────────────────┐
│  推理引擎                                             │
│  ComposedPipeline → Denoising → Attention Backend     │
│  单卡 (CFG Gating + MoE offload)                     │

└────────────────────┬──────────────────────────────────┘
                     │
┌────────────────────▼──────────────────────────────────┐
│  CUDA Kernel 层                                       │
│  VSA / FlashAttention-4 / SageAttention               │
│  → H100 Tensor Core 加速                              │
└───────────────────────────────────────────────────────┘
```

### 2. 常见生产坑位

| 常见坑 | 现象 | 原因 | 解决方案 |
|--------|------|------|---------|
| 显存 OOM | CUDA out of memory | VAE decode 时分辨率过高 | 启用 CPU offload 或 tiling decode |
| 生成质量差 | 视频模糊/闪烁 | 去噪步数太少或 CFG scale 不对 | 调大 steps 或 `guidance_scale` |
| 速度不达标 | 推理 > 10 秒 | 没用高性能 backend | 切 VSA 或 flash_attn；开 CFG gating |
| 多卡性能不线性 | 4 卡不如 2 卡快 | all-to-all 通信瓶颈 | 检查 NVLink 带宽；考虑减卡 |
| 模型加载慢 | from_pretrained 很慢 | 重复加载或未预缓存 | 用模型缓存服务（如 `fastvideo serve`） |
| LoRA 合并失败 | 加载 LoRA 后效果变差 | alpha/rank 参数不匹配 | 检查 lora_config 和训练配置一致 |

### 3. 生产环境 Checklist

| 阶段 | Checklist | 工具 |
|------|-----------|------|
| 模型准备 | ✅ 模型兼容性检查 ✅ 量化评估 | `registry.py` 注册检查 |
| 性能评估 | ✅ 单卡推理 FPS ✅ 注意力后端对比 ✅ CFG gating 收益 | `profiler.py` + ncu |
| 多卡扩展 | ✅ SP 配置 ✅ all-to-all 带宽 ✅ 多卡线性度 | nccl-tests |
| 上线 | ✅ GPU 利用率 > 80% ✅ P99 延迟达标 ✅ 有 fallback 策略 | Grafana + Prometheus |

### 4. GPU 选型建议

| GPU | 显存 | 推荐场景 | 限制 |
|-----|------|---------|------|
| H100 80G | 80GB | Wan 14B 单卡推理 + VSA | 成本最高 |
| A100 80G | 80GB | 大模型推理 / 训练 | 无 FP8 支持 |
| L40S 48G | 48GB | Wan 1.3B 推理 + LoRA 训练 | 大模型需多卡 |
| RTX 4090 24G | 24GB | 小模型推理 / 开发调试 | 不支持 NVLink |
